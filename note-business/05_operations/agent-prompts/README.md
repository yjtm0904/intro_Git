# エージェント指示書テンプレート（量産の型）

次回以降の制作サイクルでも同じ品質で量産できるよう、各エージェントへの指示書をテンプレート化したもの。
`{{...}}` を埋めて、事業責任者（Claude）がAgentツールで起動する。

| ファイル | 役割 | 工程 |
|---|---|---|
| writer.md | ライター（企画書から原稿・検証ログを作る） | Do |
| reviewer.md | 編集・コンプラ審査（品質スコア、事実確認、法務） | Check |
| reader-panel.md | 読者パネル（ペルソナとしての購買意向評価） | Check |

## 1サイクルの流れ

1. 編集長が企画書を作る（`03_content/briefs/`）
2. ライターを2〜3体、並行で起動する（1体あたり3〜4本）→ `03_content/articles/` に原稿、`03_content/verification/` に検証ログ
3. 審査担当と読者パネルを並行で起動する → `04_review/`
4. 指摘をライターに戻す（SendMessageで同じライターに続行させると、文脈を保ったまま修正できる）
5. 機械チェック（compliance-lint）でERROR 0件を確認する → オーナーの最終確認（G3）→ 公開

## 運用上の注意

- 利用上限に達したエージェントは、上限のリセット後にSendMessageで続きから再開させる（新しく起動し直さない）。
- 審査担当は、制作したエージェントとは別に起動する（職務分離）。
- WebSearchは全エージェント共有で1ターン200回が上限。noteの一次データは `tools/note-keyword-scan` で取る（1回30ページまで、間隔4秒以上）。
