## 前置きなしで頼むと、19場面すべてに説明や別の案が付いた

前置きなしの短い頼み方は情報が少ないため、AIが補うのは自然なことです。比べているのは、情報を【 】で渡す頼み方の効果です。NG例の19場面では、16場面で入力にない約束・事実・日付・評価などが足されました。16場面で【 】や〇〇の空欄が残り、19場面すべてで文面の前後に説明や別の案が付いています。この記事の依頼文では、20場面の文面すべてで、入力にない数字・曜日の誤り・記号の書き換えが0件でした。読んで確かめた範囲でも、入力にない約束や理由は見つかっていません。体験談ではなく、検証の記録です。

・出力は文面だけにする（【形式】で頼んだものは除く）。前置き・説明・複数の案は書かない
```

最初の版の前置きは、ルールが3つでした。【 】の情報だけを使う、〔 〕の記号を残す、丁寧なビジネス文にする、の3つです。この版で場面1〜5を実行すると、次のことが起きました。

- 5場面すべてで、文面のあとに説明が付いた。「本文は宛名を含めて約246字です」「本日は11月8日なので、11月18日はまだ先の日付です」などで、コピーすると混ざる
- 5場面すべてで差出人の名前が入らず、署名の扱いも場面ごとに違った。何も書かない場面と、「（署名）」とだけ書く場面があった

そこで、文面だけを出すこと、差出人と署名の決まりを足しました。足りない情報を〔要確認〕と書くこと、日付を入力のとおりに書くこと、二重敬語や責める言い方を避けることも、あわせて足しています。直した版で20場面を実行し、全文を読んで確かめ、Pythonでも点検しました。20場面の文面で、入力にない数字・曜日の誤り・記号の書き換えは0件です。

空欄の【 】の右側は、次のように埋めます。

- 会社名・人名・商品名は〔取引先A〕〔担当B〕〔商品Y〕のような記号にする
- 日付には曜日を付け、カレンダーで確かめてから書く
- 決まっていないことは書かない。足りないときは、AIが〔要確認：…〕と返す。検証では場面12・16で返った
- 字数は上限の目安。検証では、字数の上限がある15場面すべてが上限内に収まった
- 件名・項目・順番などの出力の形は、【形式】で決める
- 見出しなどに「**」が付くことがある。チャットの画面では太字の印で、メールに貼って記号が残ったら消す

各場面は、依頼文、出力例、NG例、送る前の確認点の順に載せています。依頼文は入力例を入れた状態です。出力例は出力のままで、直したのは場面18の敬語の誤り1か所だけです。NG例は、前置きなしの短い頼み方を実行した出力から、問題のある行を抜き出しています。

変えた点
1. 「何度も言っていますが」は相手を責める印象になるため削り、原本が必要な理由として「コピーでは精算ができないため」を添えました。
2. 「出してください」「出していません」を「ご提出をお願いいたします」「未提出となっております」に改め、依頼の形にしました。
```

検証では、【形式】を「お願いが任意に読めないようにする」とした版で、元の文にない強調の言葉が足されました。「強調の言葉は足さずに」と加えても同じでした。どちらも1回ずつ試した結果です。そこで、必要なことを理由で伝えるように【形式】を書き換えています。

NG例：前置きなしで「この文をやわらかくして」と、元の文だけを貼った出力の抜粋です。

```
**案1（標準的）**
> 繰り返しのご案内となり恐縮ですが、領収書は原本でのご提出をお願いいたします。コピーでは精算ができませんので、ご了承ください。なお、今月分はまだ3名の方がご提出前となっています。お手すきの際にご対応いただけますと助かります。
**案2（よりやわらかく、社内向け）**
> 何度かお伝えしているところですが、領収書は原本でご提出いただけますと幸いです。コピーですと精算の手続きができないため、ご協力をお願いします。今月分は、まだ3名の方のご提出が確認できていませんので、お心当たりの方はご確認いただけるとうれしいです。
```

問題点

- 意味が変わった：案1は「お手すきの際にご対応いただけますと助かります」、案2は「原本でご提出いただけますと幸いです」で、原本の提出が任意のお願いに読める
- 案が2つ出て、どちらを使うかを選ぶ必要がある

送る前の確認点

- 残すべき条件の原本・コピー不可・未提出が、全部残っているか
- お願いが「できれば」「お手すきの際に」になっていないか

### 場面20 長いメールの要約と返信案

依頼文

```
【場面】取引先からの長いメールを要約し、返信の下書きを作る
【相手】〔取引先A〕の〔担当B〕様
【届いたメール】〔担当B〕様より：いつもお世話になっております。先日お願いした〔商品Y〕の件で、3点ご相談です。1点目、数量を100個から150個に増やしたいので、お見積りを出し直していただけますか。2点目、150個の場合でも、納期は12月18日（金）に間に合いますか。社内の予定があるため、できれば早めに知りたいです。3点目、12月分からは、請求書の宛先を〔部署G〕に変えてください。お手数ですが、よろしくお願いいたします。
【返信の方針】受け取ったことを伝える。見積と納期は、11月27日（金）までに回答する。請求書の宛先の変更は承知した
【形式】最初に要約を3行で。そのあとに返信の下書き（件名つき、本文250字以内）。納期に間に合うかどうかは書かない
```

出力例

```
**要約**
1. 〔商品Y〕の数量を100個から150個に増やしたいため、見積りの出し直しを依頼。
2. 150個の場合も納期12月18日（金）に間に合うかを確認したい（社内予定のため、できれば早めに）。
3. 12月分から、請求書の宛先を〔部署G〕に変更してほしい。

---

**件名**：Re: 〔商品Y〕の件（ご相談3点を承りました）

〔取引先A〕
〔担当B〕様

いつもお世話になっております。〔自社〕の〔氏名〕です。
〔商品Y〕の件でご連絡をいただき、ありがとうございます。ご相談の3点、確かに承りました。

数量を150個に変更した場合のお見積りと、12月18日（金）の納期につきましては、11月27日（金）までにご回答いたします。

また、12月分からの請求書の宛先を〔部署G〕に変更する件、承知いたしました。

今後ともよろしくお願いいたします。

〔自社〕
〔氏名〕
```

検証の1回では、この文面の前に、AIの作業メモ（英語の指示の確認や下書き）が出ました。ここには最後の文面だけを載せています。メモが出たときは、最後の文面だけを使ってください。

NG例：前置きなしで「このメールを要約して、返信を書いて」と、届いたメールだけを貼った出力の抜粋です。

```
承知いたしました。150個でのお見積りを作成し、〔○月○日（○）〕までにお送りいたします。
（中略）
現在、社内で生産・在庫の状況を確認しております。
（中略）
※お見積りより先に判明した場合は、納期のみ先にお知らせいたします。
（中略）
念のため、ご担当者様のお名前や送付先のご住所に変更があれば、お知らせいただけますと幸いです。
```

問題点

- 足された：していない作業「現在、社内で生産・在庫の状況を確認しております」と、約束「納期のみ先にお知らせいたします」
- 空欄：見積りと納期を回答する日が〔○月○日（○）〕のまま

送る前の確認点

- 返信で約束していること（期限・対応）が、社内で確認済みか
- 要約に、相手の依頼が全部入っているか。数えて照らし合わせる

## 自社用に改造する依頼文の全文

職場の決まりに合わせて、20場面の依頼文を直すための依頼文です。共通の前置きは付けずに、これだけを貼ります。

```
次の依頼文を、私の職場で使いやすい形に直してください。

【職場のこと】
・業種と人数：
・よく送る相手：
・文の決まり：（例：社内の連絡はチャット。件名の付け方）
・いつも入れる一文：
・入れてはいけない情報：（例：社員名は〔社員C〕のような記号にする）
【直し方】
・【 】の見出しは残す。職場で毎回書く情報があれば、見出しを足してよい
・共通の前置きのルール（情報を足さない、〔要確認〕と書く、〔 〕の記号を残す）に反する指示は入れない
・直した依頼文だけを出し、そのあとに変えた点を3つまで書く
【直す依頼文】
（20場面のどれかを貼る）
```

直った依頼文は、元の依頼文と同じく、共通の前置きのあとに貼って使います。直したら、一度は架空の入力で試し、出力の形を確かめてください。

## 送る前に確かめる10項目と、AIに入れない情報の早見表

### 送る前に確かめる10項目

- □ 宛先：To・CC・BCCが正しいか。社外への一斉送信はBCC
- □ 宛名：会社名・部署・名前・敬称が正しいか
- □ 記号：〔 〕を元の名前に戻したか。「〔」で検索して0件か
- □ 要確認：〔要確認：…〕が残っていないか
- □ 日付と曜日：カレンダーで確かめたか
- □ 数字：金額・件数・時刻が、元の資料と同じか。AIに計算させていないか
- □ 約束：電話する、再発防止など、入力にない約束が入っていないか
- □ 言い方：相手を責める・急がせる言い方になっていないか
- □ 添付：ファイルが付いているか、正しいファイルか
- □ 社外秘：社外に出せない情報が入っていないか

### AIに入れない情報の早見表

置き換えずに、入れないもの

- マイナンバー、給与・賞与、人事評価、健康や家族の情報
- 銀行口座・カードの番号、パスワード・ID・認証コード
- 未発表の数字や社内の決定、交渉中の条件、取引先から預かった資料

記号に置き換えて使うもの

- 会社名・取引先名 → 〔取引先A〕
- 人名 → 〔担当B〕〔社員C〕
- 電話番号・メールアドレス・社内のURL → 〔電話番号〕〔メールアドレス〕〔社内URL〕
- 金額 → 文面だけなら〔金額〕、表の相談なら「X,XXX円」の形

貼る直前に確かめること

- □ 勤務先が使ってよいと決めたAIか
- □ 〔 〕の記号以外に、名前・連絡先・番号が残っていないか
- □ 会社名・金額・口座・未発表の数字が残っていないか
- □ パスワード・ID・社内のURLが、貼る文や画像に入っていないか
- □ 置き換えの対応表（置換表）や元のファイルを、そのまま貼っていないか

置換表の作り方と、置き換えの漏れを検索で探す方法は、次の記事にあります。
