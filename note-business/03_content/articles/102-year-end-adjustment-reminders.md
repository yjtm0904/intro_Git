## 結論：回収は「管理表」と「段階別の文例」で回す

年末調整の書類を配ったあと、期限が近いのに未提出の人が残り、1人ずつ声をかけている総務・経理の方向けの記事です。提出状況は「社員番号と日付だけ」の管理表にまとめ、関数で未提出の人数と一覧を出します。催促は、期限の前・期限の後・給与計算の締め前・不備の差し戻しの4段階の文例で送り分けます。文例は、自社の期限と提出方法を入れてAIに作り直させるプロンプトつきです。

【検証情報】検証日：2026-11-08／使ったツール：Claude（2026年11月時点）、LibreOffice Calc 24.2、Python 3.13
検証方法：架空の20名分の提出状況で関数を計算し、Pythonの集計と一致を確認。FILTERは検証に使った表計算ソフトが未対応のため、Pythonの期待値を載せています【オーナー確認待ち：GoogleスプレッドシートでFILTERの表示を確認】。文例は、執筆とは別の新しい実行でプロンプトを2回動かした1回目の出力です（2回とも日付・曜日・字数をPythonで点検）

回収の流れは次の4段階です（日付は架空の例。社内の期限を11月27日（金）とした場合）。

- 期限の3日前（11月24日（火））：未提出の人に文例1
- 期限の翌営業日（11月30日（月））：まだの人に文例2
- 給与計算の締め前（12月3日（木）の朝）：まだの人に文例3
- 不備が見つかったとき：その人に文例4

文例だけを使う方は「催促と差し戻しの文例」へ。

## この記事で扱うこと・扱わないこと（控除の判断・税額の計算はしない）

扱うのは、社内の回収と催促の段取りだけです。

扱わないこと
- 控除を受けられるかどうかの判断、申告書の書き方の正誤、税額の計算、改正点の解説
- 提出期限の法的な扱い（この記事の「期限」は、会社が社内向けに決める日です）

控除や書き方の質問は、その場で判断せず、社内の担当窓口や顧問の税理士などの専門家に確かめてから答えます。制度そのものは、国税庁の[年末調整がよくわかるページ（令和8年分）](https://www.nta.go.jp/users/gensen/nencho/index.htm)で確かめてください（確認日：2026-11-08）。

年末調整のクラウドサービスを使う会社は、管理表の代わりにサービスの提出状況の画面を使い、文例だけを使えば足ります。

## 提出状況の管理表を作る

### 列の構成（社員番号・書類ごとの提出日・不備の有無）

1行に1人、列は次の7つです。**氏名と申告の中身（家族・所得・マイナンバーなど）は入れません。**誰の行かは、社員名簿と照らし合わせます（社員番号がない会社は、名簿の行番号でかまいません）。

- A列：社員番号（例：E001）
- B列：扶養控除等申告書の提出日
- C列：基礎控除申告書など（兼用様式）の提出日
- D列：保険料控除申告書の提出日
- E列：不備の有無（確認して「あり」か「なし」。確認前は空欄）
- F列：最後に連絡した日
- G列：状況（関数で表示）

書類の列は、会社が配布した書類ごとに作ります。翌年分の扶養控除等申告書を同じ時期に配る場合は、本年分と列を分けます。列名は、国税庁の令和8年分の様式名を短くしたものです。本人から「この書類は出さない」と連絡があったら、日付の代わりに「提出なし」と入れます（出す・出さないの判断は、この表では行いません）。

G列（状況）の式です。G2に入れて、G21までコピーします。

```
=IF(COUNTBLANK(B2:D2)>0,"未提出",IF(E2="あり","差し戻し",IF(E2="なし","完了","確認待ち")))
```

架空の20名で作った表の一部です（11月30日時点の想定）。

```

E001,11/12,11/12,11/12,なし,,完了
E002,11/13,11/13,提出なし,なし,,完了
E003,,,,,11/24,未提出
E004,11/16,11/16,11/16,あり,11/18,差し戻し
E005,11/17,11/17,11/20,,,確認待ち
```

### 未提出者を一覧にする関数

```
未提出の人数：=COUNTIF(G2:G21,"未提出")
差し戻しの人数：=COUNTIF(G2:G21,"差し戻し")
扶養控除等申告書の空欄の数：=COUNTBLANK(B2:B21)
```

未提出の人の社員番号を一覧にするのがFILTERです。Googleスプレッドシートは3つ目の引数を「該当なし」の表示に使えないため、IFERRORで包みます。

```
Excel（Microsoft 365）
=FILTER(A2:A21,G2:G21="未提出","該当なし")

Googleスプレッドシート
=IFERROR(FILTER(A2:A21,G2:G21="未提出"),"該当なし")
```

Excel 2019以前にはFILTERがなく、入れると#NAME?になります。G列にフィルター（データ→フィルター）をかけて「未提出」だけを表示するか、次の補助列の式を使います。H列に1・2・3…の通し番号が付き、J列に未提出の人の社員番号が上から並びます。

```
H2（H21までコピー）
=IF(G2="未提出",COUNTIF($G$2:G2,"未提出"),"")

J2（J21までコピー）
=IFERROR(INDEX($A$2:$A$21,MATCH(ROWS($J$2:J2),$H$2:$H$21,0)),"")
```

架空の20名での結果です。FILTER以外は表計算ソフトで計算し、Pythonの集計と一致しました。

- 状況：完了9名、未提出5名、差し戻し3名、確認待ち3名
- 未提出の一覧：E003、E006、E009、E014、E017（FILTERの欄はPythonで求めた期待値）

よくあるつまずきと直し方
- 空欄に見えるセルにスペースが入っていると、空欄として数えられません。セルを選び、Deleteキーで消します。
- FILTERの結果を出すセルの下に文字があると、Excelでは#SPILL!、Googleスプレッドシートでは#REF!になります。下のセルを空けておきます。

## 自社の期限と提出方法を入れて文例を作るプロンプト

【条件】の6行を自社の内容に書き換えて貼ります（下は、上の4通を作ったときの架空の入力例）。

```
あなたは従業員30名ほどの会社の総務担当です。年末調整の書類を社員から回収しています。
下の【条件】を使って、社内向けメールの文例を4つ作ってください。

【作る文例】
1. 期限の3日前のリマインド（まだ出していない人へ）
2. 期限を過ぎた人への1回目の連絡
3. 給与計算の締め前の最終確認
4. 記入漏れ・添付漏れの差し戻し

【条件】
- 提出期限：11月27日（金）
- 期限後の提出のお願い：12月2日（水）まで
- 最終の受付：12月3日（木）17時
- 差し戻した書類の再提出：12月2日（水）まで
- 提出方法：記入した申告書を、総務の窓口に手渡しか、2階の回収箱へ
- 問い合わせ先：総務 年末調整担当（内線100）

【書き方】
- 1通ごとに件名と本文をつける。本文は200〜300字。です・ます調で、相手を責める言い方はしない。
- 日付と曜日は【条件】のものだけを使う。新しい日付や数字を足さない。
- 税金・控除・確定申告の説明と、提出しなかった場合の扱いは書かない。
- 申告書の中身（家族、所得、マイナンバー、保険など）には触れない。文例4の不備の箇所は【　】の空欄にする。
- 書き方の質問は問い合わせ先へ案内し、「内容によっては確認してからお答えします」と添える。
- 宛名は「〇〇さん」、最後の署名は「総務 年末調整担当」にする。
```

条件を付けない最初の依頼文を新しい実行で2回動かすと、2回とも文例3に「その場合、ご自身で確定申告をしていただく必要があります。」のような、税の扱いを言い切る文が入りました。文例4には申告書の中身（マイナンバーの欄、控除証明書）が補われたため、【書き方】の条件を足しています。

Claudeで検証しました。ChatGPT・Gemini・Copilotでも同じ依頼文を使えますが、出力は異なります（未検証）。

## AIに入れてはいけない年末調整の情報

先に、勤務先のAI利用ルールを確かめます。そのうえで、次の情報はAIに入れません。

- 社員の氏名・社員番号・住所（管理表そのものも入れない）
- 本人と家族のマイナンバー、扶養親族や配偶者の氏名・所得
- 保険料や住宅ローンなど、申告書に書く金額と内容

置き換えの例：「見本花子さん（E014）の扶養控除等申告書が未提出」→「〇〇さんの書類のうち1通が未提出」（中身は入れない）

置き換えのやり方は、別の記事「生成AIに入力してはいけない情報と、マスキングのやり方」で詳しく扱います。

## 送る前のチェックリスト

- 宛先は本人だけか。複数人に送るときはBCCにしたか
- 宛名の「〇〇さん」を書き換えたか
- 管理表の「状況」を見て、提出済みの人に送っていないか
- 期限・再提出の期限・最終の受付の日付と曜日を、カレンダーで確かめたか
- 提出方法と問い合わせ先（窓口・内線）が、今年の運用と合っているか
- 文例4の【　】に、確かめてほしい箇所を書いたか（申告の中身や番号は書かない）
- 税金・控除・確定申告の扱いを書き足していないか
- 責める言い方や、不安をあおる言い方になっていないか
- AIに入れた文面に、氏名・社員番号・申告書の中身が入っていなかったか
- 送った日を、管理表のF列に記入したか

## まとめ：1月の源泉徴収票の配布案内は「総務文書30場面」へ

1月の源泉徴収票の配布案内など、12月〜4月の社内文書は、有料の記事「総務文書30場面（年末年始〜年度末）」（980円）で扱います。仕事納めの段取りや入社予定者への入社案内など、30場面のプロンプトと完成例を収めています。
