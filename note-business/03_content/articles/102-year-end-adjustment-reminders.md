年末調整の書類の期限まで、あと3日。まだ出していない人が残っていて、1人ずつ声をかけている。

そんなときは、提出状況を「社員番号と日付だけ」の管理表にまとめると、未提出の人数と一覧を関数で出せます。催促は、期限の前・期限の後・給与計算の締め前・不備の差し戻しの4段階で、文例を送り分けます。文例は、自社の期限と提出方法を入れてAIに作り直させるプロンプトつきです。

【検証情報】2026-11-08に、架空の20名分の表で関数を確かめました。LibreOffice Calc 24.2で計算した結果は、Python 3.13で数えた結果と全項目で一致しています。この版はFILTERに対応していません。FILTERの欄はPythonで求めた一覧です【オーナー確認待ち：GoogleスプレッドシートでFILTERの表示を確認】。
文例はClaude（2026年11月時点）で作り、記事を書いた会話とは別の新しい会話で試しました。書き方の指定なしで頼むと、2回とも文例3に確定申告の説明が入ったため、税金や控除に触れない指定を足しています。AIの出力は毎回少しずつ変わります。試したAIはClaudeだけで、ChatGPT・Gemini・Copilotでの結果は確かめていません。

回収の流れは次の4段階です。日付は、社内の期限を11月27日（金）とした架空の例です。

- 11月24日（火）、期限の3日前：未提出の人に文例1
- 11月30日（月）、期限の翌営業日：まだの人に文例2
- 12月3日（木）の朝、給与計算の締め前：まだの人に文例3
- 不備が見つかったとき：その人に文例4

文例だけを使う方は「催促と差し戻しの文例」へ。

## 扱うのは社内の回収と催促の段取りだけ

扱わないこと
- 控除を受けられるかどうかの判断、申告書の書き方の正誤、税額の計算、改正点の解説
- 提出期限の法的な扱い。この記事の「期限」は、会社が社内向けに決める日です
- 本人が書類を出すかどうかの判断

控除や書き方の質問は、その場で判断せず、社内の担当窓口や顧問の税理士などの専門家に確かめてから答えます。制度そのものは、国税庁の[年末調整がよくわかるページ（令和8年分）](https://www.nta.go.jp/users/gensen/nencho/index.htm)で確かめてください（確認日：2026-11-08）。

年末調整のクラウドサービスを使う会社は、管理表の代わりにサービスの提出状況の画面を使い、文例だけを使えば足ります。

## 社員番号と日付だけの管理表を作る

### 列の構成

1行に1人、列は次の7つです。**氏名と、家族・所得・マイナンバーなどの申告の中身は入れません。**誰の行かは社員名簿と照らし合わせ、社員番号がない会社は名簿の行番号を使います。

- A列：社員番号
- B列：扶養控除等申告書の提出日
- C列：基礎控除申告書などを1枚にした兼用様式の提出日
- D列：保険料控除申告書の提出日
- E列：不備の有無。確認して「あり」か「なし」を入れ、確認前は空欄にする
- F列：最後に連絡した日
- G列：状況。関数で表示する

書類の列は、会社が配布した書類ごとに作ります。翌年分の扶養控除等申告書を同じ時期に配る場合は、本年分と列を分けます。列名は、国税庁の令和8年分の様式名を短くしたものです。本人から「この書類は出さない」と連絡があったら、日付の代わりに「提出なし」と入れます。

G列の状況を出す式です。G2に入れて、G21までコピーします。

```
=IF(COUNTBLANK(B2:D2)>0,"未提出",IF(E2="あり","差し戻し",IF(E2="なし","完了","確認待ち")))
```

架空の20名で作った表の一部で、11月30日時点を想定しています。

```
社員番号,扶養控除等,基礎控除など,保険料控除,不備,連絡した日,状況
E001,11/12,11/12,11/12,なし,,完了
E002,11/13,11/13,提出なし,なし,,完了
E003,,,,,11/24,未提出
E004,11/16,11/16,11/16,あり,11/18,差し戻し
E005,11/17,11/17,11/20,,,確認待ち
```

### 未提出者を一覧にする関数

```
未提出の人数：=COUNTIF(G2:G21,"未提出")
差し戻しの人数：=COUNTIF(G2:G21,"差し戻し")
扶養控除等申告書の空欄の数：=COUNTBLANK(B2:B21)
```

未提出の人の社員番号を一覧にするのがFILTERです。Googleスプレッドシートは3つ目の引数を「該当なし」の表示に使えないため、IFERRORで包みます。

```
Excel（Microsoft 365）
=FILTER(A2:A21,G2:G21="未提出","該当なし")

Googleスプレッドシート
=IFERROR(FILTER(A2:A21,G2:G21="未提出"),"該当なし")
```

Excel 2019以前にはFILTERがなく、入れると#NAME?になります。その場合は、「データ」→「フィルター」でG列を絞り込んで「未提出」だけを表示するか、次の補助列の式を使ってください。H列に1・2・3…の通し番号が付き、J列に未提出の人の社員番号が上から並びます。

```
H2（H21までコピー）
=IF(G2="未提出",COUNTIF($G$2:G2,"未提出"),"")

J2（J21までコピー）
=IFERROR(INDEX($A$2:$A$21,MATCH(ROWS($J$2:J2),$H$2:$H$21,0)),"")
```

架空の20名での結果です。FILTER以外は表計算ソフトで計算し、Pythonの集計と一致しました。

- 状況：完了9名、未提出5名、差し戻し3名、確認待ち3名
- 未提出の一覧：E003、E006、E009、E014、E017

よくあるつまずきと直し方
- 空欄に見えるセルにスペースが入っていると、空欄として数えられません。セルを選び、Deleteキーで消します。
- FILTERの結果を出すセルの下に文字があると、Excelでは#SPILL!、Googleスプレッドシートでは#REF!になります。下のセルを空けておきます。

#NAME?・#SPILL!・#REF!の直し方は、「Excel・スプレッドシートのエラーをAIに聞く方法」【オーナー確認待ち：103の公開URL】で扱います。

## 催促と差し戻しの文例

下の4通は、次の節のプロンプトを2回動かしたうちの1回目です。2回とも、日付と曜日は条件どおりで、本文は指定の200〜300字に収まり、税の説明は入りませんでした。日付・提出方法・内線番号は架空の例です。

### 文例1：期限の3日前のリマインド

BCCで一斉に送るときは、宛名を「年末調整の書類をまだ提出していない方へ」にします。

```
件名：【ご提出のお願い】年末調整の申告書（期限：11月27日（金））

〇〇さん

お疲れさまです。総務の年末調整担当です。
年末調整の申告書について、提出期限の11月27日（金）が近づいてまいりましたので、ご案内いたします。
まだご提出がお済みでない場合は、記入した申告書を総務の窓口に手渡しいただくか、2階の回収箱へお入れください。
書き方でご不明な点があれば、総務 年末調整担当（内線100）までお気軽にお問い合わせください。内容によっては確認してからお答えします。
すでにご提出いただいている場合は、行き違いのご連絡となり失礼いたしました。
どうぞよろしくお願いいたします。

総務 年末調整担当
```

## 自社の期限と提出方法を入れて文例を作るプロンプト

【条件】の6行を自社の内容に書き換えて貼ります。下は、上の4通を作ったときの架空の入力例です。

```
あなたは従業員30名ほどの会社の総務担当です。年末調整の書類を社員から回収しています。
下の【条件】を使って、社内向けメールの文例を4つ作ってください。

【作る文例】
1. 期限の3日前のリマインド（まだ出していない人へ）
2. 期限を過ぎた人への1回目の連絡
3. 給与計算の締め前の最終確認
4. 記入漏れ・添付漏れの差し戻し

【条件】
- 提出期限：11月27日（金）
- 期限後の提出のお願い：12月2日（水）まで
- 最終の受付：12月3日（木）17時
- 差し戻した書類の再提出：12月2日（水）まで
- 提出方法：記入した申告書を、総務の窓口に手渡しか、2階の回収箱へ
- 問い合わせ先：総務 年末調整担当（内線100）

【書き方】
- 1通ごとに件名と本文をつける。本文は200〜300字。です・ます調で、相手を責める言い方はしない。
- 日付と曜日は【条件】のものだけを使う。新しい日付や数字を足さない。
- 税金・控除・確定申告の説明と、提出しなかった場合の扱いは書かない。
- 申告書の中身（家族、所得、マイナンバー、保険など）には触れない。文例4の不備の箇所は【　】の空欄にする。
- 書き方の質問は問い合わせ先へ案内し、「内容によっては確認してからお答えします」と添える。
- 宛名は「〇〇さん」、最後の署名は「総務 年末調整担当」にする。
```

【書き方】の指定がない最初の依頼文で2回作ると、2回目の文例3には「その場合、ご自身で確定申告をしていただく必要があります。」と入りました。1回目にも同じ趣旨の文がありました。文例4には2回とも控除証明書の話が補われ、1回目にはマイナンバーの欄も出てきたため、【書き方】の条件を足しています。

## AIに入れてはいけない年末調整の情報

先に、勤務先のAI利用ルールを確かめます。そのうえで、次の情報はAIに入れません。

- 社員の氏名・社員番号・住所。管理表そのものも入れない
- 本人と家族のマイナンバー、扶養親族や配偶者の氏名・所得
- 保険料や住宅ローンなど、申告書に書く金額と内容

置き換えの例：「E014の見本花子さんは扶養控除等申告書が未提出」→「〇〇さんの書類のうち1通が未提出」

置き換えのやり方は、別の記事「生成AIに入力してはいけない情報と、マスキングのやり方」で詳しく扱います。

## 送る前に確かめる10項目

- 宛先は本人だけか。複数人に送るときはBCCにしたか
- 宛名の「〇〇さん」を書き換えたか
- 管理表の「状況」を見て、提出済みの人に送っていないか
- 期限・再提出の期限・最終の受付の日付と曜日を、カレンダーで確かめたか
- 提出方法と、窓口・内線の問い合わせ先が、今年の運用と合っているか
- 文例4の【　】に書いたのは確かめてほしい箇所だけで、申告の中身や番号を書いていないか
- 税金・控除・確定申告の扱いを書き足していないか
- 責める言い方や、不安をあおる言い方になっていないか
- AIに入れた文面に、氏名・社員番号・申告書の中身が入っていなかったか
- 送った日を、管理表のF列に記入したか

## 1月の源泉徴収票の案内も続けて作るなら

1月の源泉徴収票の配布案内など、12月〜4月の社内文書は、980円の有料記事「総務文書30場面（年末年始〜年度末）」で扱います。仕事納めの段取りや入社予定者への入社案内など、30場面のプロンプトと完成例を収めています。
