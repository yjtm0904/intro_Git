請求書のメールや顧客リストをAIに貼る前に、どこまで入れてよいか迷っている事務・経理・総務の方へ。AIに入れてはいけない情報を、事務の具体例15で示します。固有名詞を記号に置き換える「マスキング」の手順と、置換表のテンプレート、プロンプト2本も載せます。

## 結論：入れる前に「誰の・どこの・いくら」を置き換える

AIに貼る前に、人の名前（誰の）、会社名や住所（どこの）、金額や口座（いくら）を記号に置き換えます。マイナンバーやパスワードのように、置き換えても使い道がない情報は、最初から貼りません。

手順は「置換表を作る→置き換える→残りを検索で確かめる」の3段階です。架空の文書3種で試すと、1回目は76か所が残りました。置換表を直し、要らない列と社外秘の文を人が消した2回目で、0か所になっています。**最後の検索までを、1つの作業として扱ってください。**

この手順は、情報が漏れるリスクを下げるためのもので、漏えいを防げると保証するものではありません。

【検証情報】検証日：2026-11-08／使ったツール：Claude（2026年11月時点）、Python 3（検索）
検証方法：架空の文書3種（請求メール・顧客リスト・議事録）に置換表を当て、残りをPythonで検索しました。プロンプト2本は、新しい会話（Claude）で各2回実行しています。

## まず勤務先のルールを確かめる（確認する5項目）

社内ルールがない、または抽象的な場合は、次の5項目を上長や情報システムの担当に確かめてください。

1. 使ってよいツール：会社が契約したAIだけか、個人のアカウントでもよいか
2. 入れてよい情報の範囲：社外秘・個人情報・取引先の情報を、どこまで入れてよいか
3. 学習に使われる設定：入力がAIの学習に使われるか、その設定を誰が管理しているか
4. 記録の保存期間：会話の履歴がどこに、いつまで残るか。共有される設定はないか
5. 相談窓口：迷ったときと、誤って入力したときに、誰に連絡するか

入力の扱いはサービスやプランで異なり、変わることもあります。使う前に、公式ヘルプか利用規約で確かめてください（この記事では各社を比べません）。

個人情報保護委員会は2023年6月2日に「生成AIサービスの利用に関する注意喚起等」を公表しました。事業者には、個人情報を含むプロンプトを入れる場合、利用目的の達成に必要な範囲内かを十分に確認するよう求めています（要旨。[同委員会のページ](https://www.ppc.go.jp/news/careful_information/230602_AI_utilize_alert/)、確認日：2026-11-08）。違法かどうかの判断は、この記事では行いません。

## 入力してはいけない情報：事務・経理・総務の具体例15

社内ルールで認められていない限り、そのままAIに入れない情報です。「→置き換える」は記号にすれば使えるもの、「→入れない」は人が作業するものです。

### 個人に関する情報（氏名・住所・マイナンバー・給与・評価・健康）

- ①氏名（社員・顧客・取引先の担当者）：立替精算の一覧の社員名 →置き換える
- ②住所・電話番号・個人のメールアドレス：緊急連絡先の一覧 →置き換える（使わない列は消す）
- ③マイナンバー：年末調整で集めた書類の番号 →入れない
- ④給与・賞与・控除の金額：給与明細や賃金台帳の数字 →入れない
- ⑤人事評価・面談の記録：評価コメントの言い直し →入れない（一般的な文にして頼む）
- ⑥健康・家族の情報：休職や産休の連絡、扶養親族の内容 →入れない（必要なら「私用のため」と言い換える）

### 取引に関する情報（顧客名・単価・契約条件・口座番号）

- ⑦顧客名・取引先名：請求書の宛名、問い合わせメールの署名 →置き換える
- ⑧単価・見積額・値引きの条件：取引先別の単価表 →置き換えるか、形だけ残す
- ⑨契約の条件・交渉中の内容：支払条件の変更を相談しているメール →入れない
- ⑩銀行口座・カードの番号：振込先の口座、法人カードの番号 →入れない（文面は〔振込先〕で作れる）
- ⑪取引先から預かった資料：相手の会社の図面・名簿 →入れない（秘密保持の取り決めがあることもある）

### 会社の情報（未発表の数字・社内システム・パスワード）

- ⑫未発表の数字：月次の試算表、来期の予算案 →入れない
- ⑬未発表の社内の決定：発表前の人事異動・組織変更 →入れない
- ⑭社内システムの情報：社内システムのURL、画面の画像、エラーの記録 →置き換える（URLや名前を消す）
- ⑮パスワード・ID・認証コード：エラーの相談で貼った記録の中のログインID →入れない（貼る前に消す）

## マスキングのやり方

作業は、AIに貼る文章のコピーで行います。元のファイルは触りません。

［図解：マスキングの3段階／①置換表を作る（元の語→〔記号〕、長い語から並べる）②置き換える（検索と置換）③残りを検索する（名字・略称・＠・数字の並び）］

### 置換表を作り、固有名詞を記号に置き換える

最初に、住所の列や署名の連絡先、振込名義の列など、AIの作業に使わない部分を消します。次に、残った文章から会社名と人名を書き出して置換表にします。テンプレートはスプレッドシートに貼れます。

```
元の語,置き換え後,種類,使う文書
株式会社サンプル商事,〔取引先A〕,会社名,請求メール・顧客リスト
サンプル商事,〔取引先A〕,会社名（略称）,議事録
山田　太郎,〔担当A〕,人名（取引先）,請求メール
山田,〔担当A〕,人名（名字だけ）,請求メール・議事録
佐藤　花子,〔社員1〕,人名（自社）,請求メール・議事録
森部長,〔社員4〕部長,人名（1字の名字は役職つき）,議事録
```

- 記号は〔 〕で囲む。AIに「〔 〕は変えずに残して」と頼めて、戻し忘れも「〔」の検索で探せる
- 同じ相手には、どの文書でも同じ記号を使う
- 名字だけ、略称、「さん」「様」つきの呼び方も、別の行で入れる
- 1字の名字は「森部長」のように役職や敬称つきで入れる
- 長い語から順に置き換える（「=LEN(A2)」の列を足して並べ替える）

置き換えには「検索と置換」を使います（Windowsでは多くのソフトでCtrl+H）。検証では、短い語から置き換えると「〔担当A〕　太郎」のように下の名前が7か所残りました。

### 数字は桁と形だけ残す（金額・日付・電話番号）

表の整理や関数の相談なら、AIには桁と区切りが分かれば足ります。

- 金額：1,234,200円 → X,XXX,XXX円（メールの文面だけなら〔金額〕）
- 電話番号：03-0000-1111 → XX-XXXX-XXXX
- 口座番号・メールアドレス・URL：〔振込先〕〔メールアドレス〕〔社内URL〕にする
- 日付：締切や請求日はそのままでよい。生年月日など人に結びつく日付は「YYYY/MM/DD」にする

計算を試すときは、架空の数字を使います。

### 置き換えた後に残っていないか確かめる

AIに貼る前に、次の3種類を検索します。

1. 置換表の「元の語」と、その一部（名字、社名の中心部分。例：「山田」「サンプル」）
2. 形：Googleドキュメントやスプレッドシートの「検索と置換」では、正規表現での検索を選べます。電話番号は `\d{2,4}-\d{2,4}-\d{3,4}`、メールは `@`、URLは `http` で探します。正規表現が使えないソフトでは、「@」「-」「〒」「http」で検索します
3. 人が読んで判断するもの：健康・家族・評価・未発表の数字・パスワード

検証の1回目は、宛名・署名・参加者欄の表記だけで置換表を作りました。名字や略称、振込名義の半角カナ、連絡先、金額などが76か所残っています。2回目の途中でも、消したつもりの一文が作業の誤りで残っていて、最後の検索で見つかっています。

補助として、AIに作業の前に確認させる前置きも使えます。ただし、AIに貼った時点で文章はサービスに送られています。**この前置きは送信を防ぐものではなく、置き換えの漏れに気づくための補助です。**

```
これから貼る文章について、作業の前に確認をお願いします。
次の情報が含まれていないかを確かめてください。
・個人の氏名、住所、電話番号、メールアドレス、生年月日
・マイナンバー、口座番号、カード番号、ID、パスワード
・給与、人事評価、健康、家族についての情報
・会社名、取引先名、金額、契約の条件、社外に出ていない数字や計画、社内システムのURL

見つかった場合は、作業をしないで、該当する箇所と理由を一覧にしてください。
見つからなかった場合は「確認しました：該当なし」と書いてから、作業をしてください。
〔 〕で囲んだ語は、置き換え済みの記号です。確認の対象から外してください。

作業：（例：社内に配る議事録の形に整えてください）
文章：
（ここに貼る）
```

入力例は、1回目の置換表で置き換えた議事録（14か所が残った文書）の一部です。

```
・サンプル商事さんの10月分 1,234,200円が未入金。先方の山田さんへ、佐藤から電話で確認する（03-0000-2001）。
・テスト電機の高橋さんが12月から産休に入るため、先方の窓口が変わる予定。
```

出力例（2回目の実行。抜粋）です。

```
該当する情報が見つかったため、作業は行っていません。該当箇所と理由は次のとおりです。
（中略）
| 3 | 山田さん | 個人の氏名 | 取引先の担当者名です |
（中略）
| 8 | 12月から産休に入る | 健康・家族についての情報 | 特定の個人の産休（妊娠・出産）に関する情報です |
（以下、13番まで続く）
```

この前置きでは、2回とも14か所すべてを挙げ、作業を止めました。「個人情報が含まれていたら指摘して。そのうえで整えて」という最初の版では、2回とも指摘のあと議事録の整形まで進み、取引先名と未入金の金額が残りました。

出力例はClaudeで生成。AIの出力は毎回少しずつ変わります。Claudeで検証しました。ChatGPT・Gemini・Copilotでも同じ依頼文を使えますが、出力は異なります（未検証）。

## 架空のサンプルデータをAIに作らせるプロンプト

関数を試すときや、AIに表の整理を頼む練習には、実データの代わりに架空のデータを使います。

```
業務の練習に使う、架空のサンプルデータを作ってください。

・内容：取引先の一覧を10行
・列：顧客コード、会社名、担当者、電話番号、メールアドレス、前月請求額、支払期日
・会社名：「株式会社サンプル商事」「テスト電機株式会社」のように、架空と分かる語（サンプル・テスト・見本・ダミーなど）を入れる
・担当者：「担当A」「担当B」のような記号にする
・電話番号：「03-0000-」で始まる形にする
・メールアドレス：「@example.com」で終わる形にする
・前月請求額：10,000〜500,000円の範囲の、1,000円単位の数字（カンマと「円」は付けない）
・支払期日：「2026/11/30」か「2026/12/31」のどちらか
・出力：1行目を見出しにして、タブ区切りのテキストで出す（スプレッドシートに貼れる形）
・実在する会社名・人名・住所・番号は使わない
```

出力例（1回目の実行。先頭の2行）です。

```
顧客コード	会社名	担当者	電話番号	メールアドレス	前月請求額	支払期日
C001	株式会社サンプル商事	担当A	03-0000-0001	sample-shoji@example.com	128000	2026/11/30
C002	テスト電機株式会社	担当B	03-0000-0002	test-denki@example.com	345000	2026/12/31
```

2回とも10行すべてが指定どおりでした（Pythonで確認）。「実在の会社名や人名は使わない」とだけ頼んだ版では、2回とも金額が「¥1,250,000」のような文字になりました。支払期日も6〜7種類に分かれたため、形まで指定しています。

「03-0000-」は、一般の電話番号では使われない形です。example.comは例示用に予約されたドメインです。社名は架空でも実在の会社と重なることがあるので、使う前に検索して確かめます。

## AIの答えを元に戻すときの注意（置換表は外に出さない）

- 置換表は、自分のPCか社内の決められた場所に保存する。AIのチャットには貼らない
- 戻すときは、AIの出力をコピーして手元の置換表で戻す。AIに「元の社名に戻して」と頼まない
- 戻したあと「〔」と「X」で検索し、戻し忘れを探す。名字だけだった所がフルネームに戻ることがあるので、最後に読み直す
- 文面のあとにAIの説明が付いていたら、コピーするときに外す

検証では、AIに2回整えてもらい、残った〔 〕の記号はどちらも書き換えられませんでした。1回は、記号を含む1文が省かれています。

## 入力前の5項目チェックリスト

AIに貼る直前に、次の5つを確かめます。

- □ このAIは、勤務先が使ってよいと決めたものか
- □ 人の名前・連絡先・番号が、〔 〕の記号以外で残っていないか
- □ 会社名・金額・口座・未発表の数字が残っていないか
- □ パスワード・ID・社内のURLが、貼る記録や画像に入っていないか
- □ 置換表や元のファイルを、そのまま貼ったり添付したりしていないか

誤って入れてしまったときは、勤務先のルールに沿って相談窓口に連絡してください。
