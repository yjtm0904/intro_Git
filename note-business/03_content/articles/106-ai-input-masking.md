請求書のメールや顧客リストをAIに貼る前に、どこまで入れてよいか迷っている事務・経理・総務の方へ。この記事では、AIに入れてはいけない情報を、事務の具体例15で示します。固有名詞を記号に置き換える「マスキング」の手順と、置換表のテンプレート、プロンプト2本も載せます。架空の文書3種で置き換えを試し、残りを検索した結果も紹介します。

## 結論：入れる前に「誰の・どこの・いくら」を置き換える

AIに文章を貼る前に、人の名前（誰の）、会社名や住所（どこの）、金額や口座（いくら）を記号に置き換えます。マイナンバーやパスワードのように、置き換えても使い道がない情報は、最初から貼りません。

手順は「置換表を作る→置き換える→残りを検索で確かめる」の3段階です。検証では、1回目の置換表で77か所が残り、表を直した2回目で0か所になりました。**最後の検索までを、1つの作業として扱ってください。**

この手順は、情報が漏れるリスクを下げるためのものです。漏えいを防げると保証するものではありません。

【検証情報】検証日：2026-11-08／使ったツール：Claude（2026年11月時点）、Python 3（検索）
検証方法：架空の文書3種（請求書の送付メール、顧客リスト10行、議事録の抜粋）に置換表を当てました。元の語と、電話番号・メールアドレス・口座番号などの形が残っていないかを、Pythonの正規表現で検索しています。プロンプト2本はClaudeで実行し、出力を確かめました。

## まず勤務先のルールを確かめる（確認する5項目）

AIの使い方のルールは、会社ごとに違います。社内ルールがない、または抽象的な場合は、次の5項目を上長や情報システムの担当に確かめてください。

1. 使ってよいツール：会社が契約したAIだけか、個人のアカウントでもよいか
2. 入れてよい情報の範囲：社外秘・個人情報・取引先の情報を、どこまで入れてよいか
3. 学習に使われる設定：入力がAIの学習に使われるか、その設定を誰が管理しているか
4. 記録の保存期間：会話の履歴がどこに、いつまで残るか。共有される設定はないか
5. 相談窓口：迷ったときと、誤って入力したときに、誰に連絡するか

入力の扱い（学習に使われるか、どれだけ保存されるか）は、サービスやプランによって異なることがあります。個人向けと法人向けで違う場合もあり、変更されることもあります。使う前に、そのサービスの公式ヘルプか利用規約で確かめてください。この記事では、各社の設定を比べたり、安全性を判断したりはしません。

個人情報保護委員会は2023年6月2日に「生成AIサービスの利用に関する注意喚起等」を公表しました。事業者には、個人情報を含むプロンプトを入れる場合、利用目的の達成に必要な範囲内かを十分に確認するよう求めています（要旨。[同委員会のページ](https://www.ppc.go.jp/news/careful_information/230602_AI_utilize_alert/)、確認日：2026-11-08）。違法かどうかの判断は、この記事では行いません。

## 入力してはいけない情報：事務・経理・総務の具体例15

次の15項目は、社内ルールで認められていない限り、そのままAIに入れない情報です。「→置き換える」は記号にすれば使えるもの、「→入れない」は置き換えずに人が作業するものです。

### 個人に関する情報（氏名・住所・マイナンバー・給与・評価・健康）

- ①氏名（社員・顧客・取引先の担当者）：立替精算の一覧に並ぶ社員の名前 →置き換える
- ②住所・電話番号・個人のメールアドレス：緊急連絡先の一覧 →置き換える（使わない列は消す）
- ③マイナンバー：年末調整で集めた書類の番号 →入れない
- ④給与・賞与・控除の金額：給与明細や賃金台帳の数字 →入れない
- ⑤人事評価・面談の記録：評価コメントの言い直しを頼む文章 →入れない（人と出来事が分からない一般的な文にする）
- ⑥健康・家族の情報：休職や産休の連絡、扶養親族の内容 →入れない（必要なら「私用のため」と言い換える）

### 取引に関する情報（顧客名・単価・契約条件・口座番号）

- ⑦顧客名・取引先名：請求書の宛名、問い合わせメールの署名 →置き換える
- ⑧単価・見積額・値引きの条件：取引先別の単価表、見積書の明細 →置き換えるか、形だけ残す
- ⑨契約の条件・交渉中の内容：支払条件の変更を相談しているメール →入れない
- ⑩銀行口座・カードの番号：振込先の口座、法人カードの番号 →入れない（文面は〔振込先〕で作れる）
- ⑪取引先から預かった資料：相手の会社の図面・名簿・見積書 →入れない（秘密保持の取り決めがあることもある）

### 会社の情報（未発表の数字・社内システム・パスワード）

- ⑫未発表の数字：月次の試算表、来期の予算案、決算前の売上 →入れない
- ⑬未発表の社内の決定：発表前の人事異動・組織変更・新商品 →入れない
- ⑭社内システムの情報：社内システムのURL、画面の画像、エラーの記録 →置き換える（URLや名前を消す）
- ⑮パスワード・ID・認証コード：エラーの相談で貼った記録の中のログインID →入れない（貼る前に消す）

## マスキングのやり方

マスキングは、AIに貼る文章のコピーで行います。元のファイルは触りません。

［図解：マスキングの3段階／①置換表を作る（元の語→〔記号〕、長い語から並べる）②置き換える（検索と置換）③残りを検索する（名字・略称・＠・数字の並び・半角カナ）］

### 置換表を作り、固有名詞を記号に置き換える

最初に、作業に要らない部分を消します。住所の列や署名の連絡先など、AIの作業に使わないものは、置き換えるより消すほうが残りが出ません。

次に、残った文章から会社名と人名を書き出し、置換表にします。列は「元の語・置き換え後・種類・使う文書」の4つです。下のテンプレートをスプレッドシートに貼れば、文書ごとに使い回せます（例はすべて架空です）。

```
元の語,置き換え後,種類,使う文書
株式会社サンプル商事,〔取引先A〕,会社名,請求メール・顧客リスト
サンプル商事,〔取引先A〕,会社名（略称）,議事録
山田　太郎,〔担当A〕,人名（取引先）,請求メール
山田,〔担当A〕,人名（名字だけ）,請求メール・議事録
佐藤　花子,〔社員1〕,人名（自社）,請求メール・議事録
森部長,〔社員4〕部長,人名（1字の名字は役職つき）,議事録
```

- 記号は〔 〕で囲む。AIに「〔 〕は変えずに残して」と頼めて、戻し忘れも「〔」の検索で探せる
- 同じ相手には、どの文書でも同じ記号を使う
- 名字だけ、略称、「さん」「様」つきの呼び方も、別の行で入れる
- 1字の名字は「森部長」のように役職や敬称つきで入れる（ほかの語に当たらないように）
- 長い語から順に置き換える。「=LEN(A2)」の列を足して、長い順に並べ替えておく

置き換えには、文書作成ソフトや表計算ソフトの「検索と置換」を使います（Windowsでは多くのソフトでCtrl+H）。検証では、同じ置換表を短い語から当てると、「〔担当A〕　太郎」のように下の名前が7か所残りました。長い語からなら0か所でした。

### 数字は桁と形だけ残す（金額・日付・電話番号）

表の整理や関数の相談なら、AIには桁と区切りが分かれば足ります。

- 金額：1,234,200円 → X,XXX,XXX円（メールの文面だけなら〔金額〕）
- 電話番号：03-0000-1111 → XX-XXXX-XXXX
- 口座番号：普通 0001234 → 普通 XXXXXXX（文面だけなら〔振込先〕）
- メールアドレス・URL：〔メールアドレス〕〔社内URL〕にする
- 日付：締切や請求日はそのままでよい。生年月日など人に結びつく日付は「YYYY/MM/DD」にする

計算を試したいときは、架空の数字を使います（後の章のプロンプト）。

### 置き換えた後に残っていないか確かめる

置き換えたら、AIに貼る前に、次の3種類を検索します。

1. 置換表の「元の語」と、その一部（名字、社名の中心部分。例：「山田」「サンプル」）
2. 形：「@」、「-」でつながった数字、「〒」、「http」、半角カナ
3. 人が読んで判断するもの：健康・家族・評価・未発表の数字・パスワード

検証の1回目は、宛名・署名・参加者欄にある会社名と人名だけで置換表を作りました（26語）。置き換えたあとにPythonで検索すると、3文書で77か所が残りました。本文の名字や略称10、振込名義の半角カナ11、連絡先35、金額13、口座・健康・社外秘の情報8です。

2回目は、置換表に名字と略称を足し（33語）、連絡先と金額を形だけにしました。要らない列を消し、社外秘の文は人が消して、残りは0か所です。その途中でも、消したつもりの一文が作業の誤りで残っていて、最後の検索で見つかりました。

補助として、AIに「個人情報らしきものがあれば、作業の前に指摘して」と頼む前置きも使えます。ただし、AIに貼った時点で、文章はそのサービスに送られています。**この前置きは送信を防ぐものではなく、置き換えの漏れに気づくための補助です。**

```
これから貼る文章について、作業の前に確認をお願いします。
次の情報が含まれていないかを確かめてください。
・個人の氏名、住所、電話番号、メールアドレス、生年月日
・マイナンバー、口座番号、カード番号、ID、パスワード
・給与、人事評価、健康、家族についての情報
・会社名、取引先名、金額、契約の条件、社外に出ていない数字や計画、社内システムのURL

見つかった場合は、作業をしないで、該当する箇所と理由を一覧にしてください。
見つからなかった場合は「確認しました：該当なし」と書いてから、作業をしてください。
〔 〕で囲んだ語は、置き換え済みの記号です。確認の対象から外してください。

作業：（例：社内に配る議事録の形に整えてください）
文章：
（ここに貼る）
```

入力例には、1回目の置換表で置き換えた議事録（検索で15か所が残った文書）を使いました。一部を示します。

```
・サンプル商事さんの10月分 1,234,200円が未入金。先方の山田さんへ、佐藤から電話で確認する（03-0000-2001）。
・テスト電機の高橋さんが12月から産休に入るため、先方の窓口が変わる予定。
```

出力例（抜粋）です。

```
作業の前に確認したところ、次の情報が含まれていました。依頼のとおり、議事録の整理はまだ行っていません。
【個人の氏名】
1. 「山田さん」（1．未入金の確認）…取引先の担当者の名字です
（中略）
【健康・家族についての情報】
8. 「12月から産休に入る」（1．未入金の確認）…高橋さんの健康・家族に関わる情報です
（以下、会社名・金額・社外に出ていない数字・社内システムのURLが続く）
```

最初に試した前置き（「個人情報が含まれていたら指摘して。そのうえで整えて」）は、人名や電話番号など8か所だけを指摘しました。取引先名・金額・社外秘の予算・社内のURLの7か所は指摘せず、そのまま議事録に整えています。上の直した版は15か所すべてを挙げ、作業を止めました。

どちらも1回ずつの実行の結果です。AIの指摘に頼らず、検索と目視を先に行ってください。出力例はClaudeで生成。AIの出力は毎回少しずつ変わります。ChatGPTやGeminiでも同じ形で使える構成です（動作は未確認）。

## 架空のサンプルデータをAIに作らせるプロンプト

関数を試すときや、AIに表の整理を頼む練習をするときは、実データの代わりに、AIに作らせた架空のデータを使います。

```
業務の練習に使う、架空のサンプルデータを作ってください。

・内容：取引先の一覧を10行
・列：顧客コード、会社名、担当者、電話番号、メールアドレス、前月請求額、支払期日
・会社名：「株式会社サンプル商事」「テスト電機株式会社」のように、架空と分かる語（サンプル・テスト・見本・ダミーなど）を入れる
・担当者：「担当A」「担当B」のような記号にする
・電話番号：「03-0000-」で始まる形にする
・メールアドレス：「@example.com」で終わる形にする
・前月請求額：10,000〜500,000円の範囲の、1,000円単位の数字（カンマと「円」は付けない）
・支払期日：「2026/11/30」か「2026/12/31」のどちらか
・出力：1行目を見出しにして、タブ区切りのテキストで出す（スプレッドシートに貼れる形）
・実在する会社名・人名・住所・番号は使わない
```

出力例（先頭の3行）です。タブ区切りなので、そのままスプレッドシートに貼れます。

```
顧客コード	会社名	担当者	電話番号	メールアドレス	前月請求額	支払期日
C001	株式会社サンプル商事	担当A	03-0000-1001	a.sample@example.com	128000	2026/11/30
C002	テスト電機株式会社	担当B	03-0000-1002	b.test@example.com	342000	2026/12/31
C003	見本物産株式会社	担当C	03-0000-1003	c.mihon@example.com	86000	2026/11/30
```

最初は「実在の会社名や人名は使わない」とだけ書いて試しました。すると、実在してもおかしくない社名や、実際の番号と同じ形の電話番号、実在しうるドメインのメールアドレスが出ました。そこで形まで指定しています。

「03-0000-」は、市外局番のあとが0で始まる、一般の電話番号では使われない形です。example.comは、例示用に予約されたドメインです。直した版の出力は、10行すべてが指定どおりでした（Pythonで確認）。

## AIの答えを元に戻すときの注意（置換表は外に出さない）

置換表は、元の語と記号の対応そのものです。AIに貼ると、置き換えた意味がなくなります。

- 置換表は、自分のPCか社内の決められた場所に保存する。AIのチャットには貼らない
- 戻すときは、AIの出力をコピーして手元の置換表で戻す。AIに「元の社名に戻して」と頼まない
- 戻したあと、「〔」と「X」で検索して、戻し忘れを探す
- 名字だけだった所がフルネームに戻ることがあるので、最後に読み直す

検証では、置き換えたメールをAIに整えてもらい、置換表で戻しました。AIは〔 〕の記号13個を、すべて変えずに残しました。一方で、置換表にない〔振込先〕などの記号と、Xで伏せた金額・電話番号は、置換表では戻りません。元の書類を見て、人が入れる必要がありました。「山田様」のように名字だけだった所は、フルネームに戻りました。

## 入力前の5秒チェックリスト

AIに貼る直前に、次の5つを確かめます。

- □ このAIは、勤務先が使ってよいと決めたものか
- □ 人の名前・連絡先・番号が、〔 〕の記号以外で残っていないか
- □ 会社名・金額・口座・未発表の数字が残っていないか
- □ パスワード・ID・社内のURLが、貼る記録や画像に入っていないか
- □ 置換表や元のファイルを、そのまま貼ったり添付したりしていないか

誤って入れてしまったときは、勤務先のルールに沿って、相談窓口に連絡してください。

## まとめ：各テンプレ集にこのチェックを入れています

AIに入れてはいけないのは、「誰の・どこの・いくら」が分かる情報と、置き換えても使えない情報です。置換表で記号にし、数字は形だけ残し、最後に検索で残りを確かめます。

公開を予定しているテンプレ集も、依頼文は〔 〕の記号で置き換えて使う前提です。対象は、事務のAI依頼文20場面、請求書のGASパック、年末年始〜年度末の総務文書キットです。各記事の「安全」の節に、このチェックリストの要約を入れます。公開後、ここにリンクを追記します。
