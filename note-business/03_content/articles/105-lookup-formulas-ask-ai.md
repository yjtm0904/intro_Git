## 結論：表の形・Excelの版・見つからないときの表示をAIに伝える

取引先コードから社名を引く、商品コードから単価を引く。こうした数式をAIに頼むときは、表の列と範囲、使っているExcelの版、見つからないときの表示の3つを伝えます。この記事では、頼み方のテンプレートと、請求の表でよく使う逆引き8例を、検算した結果つきで載せます。

【検証情報】検証日：2026-11-08／使ったツール：Claude（2026年11月時点）、LibreOffice Calc 24.2、Python 3.13
検証方法：架空の取引先マスタ10社・商品マスタ10件・請求明細20行で、8例の数式をLibreOfficeで計算し、Pythonで別に求めた期待値と照合（239セルすべて一致）。XLOOKUPとFILTERはLibreOffice 24.2では計算できないため、期待値はPythonで求めたもの。Excel（Microsoft 365）とGoogleスプレッドシートでの表示は【オーナー確認待ち：XLOOKUPとFILTERの式の実機確認の日付】

## AIへの頼み方テンプレート

次の入力例の（ ）の中や例の値を、自分の表に書き換えて使います。

```
次の条件で、Excelの数式を作ってください。

【やりたいこと】
請求明細のD列に、C列の取引先コードに対応する取引先名を表示したい

【表の列】（列名と例の値）
- 取引先マスタ（A2:D11、10社）：A列 取引先コード（例：C-001）、B列 取引先名（例：株式会社サンプル商事）、C列 部署（例：経理部）、D列 メール（例：sample-shoji@example.com）
- 請求明細（2行目から下）：C列 取引先コード（例：C-003）、D列 取引先名（ここに数式を入れる）

【探す値の場所】
請求明細のC2（下の行にもコピーする）

【見つからないときの表示】
「未登録」と表示する

【使うソフトと版】
Excel 2019（XLOOKUPは使えない）

【出してほしいもの】
D2に入れる数式1つと、下の行へコピーするときの注意、数式の読み方を短く
```

AIに入れない情報は、次の3つです。

- 取引先名・担当者名・メールアドレスの実際の値
- 金額・口座番号などの実データ
- 会社のファイルそのもの

置き換え例：「株式会社〇〇（実在）」→「株式会社サンプル商事」、「担当：〇〇様」→ 削る。詳しくは「生成AIに入力してはいけない情報と、マスキングのやり方」（［リンク：106の記事］）にあります。勤務先のAI利用ルールも先に確かめてください。

### テンプレートで頼んだ例

上の入力例で頼んだときの出力例（抜粋）です。

```
D2に入れる数式
=IFERROR(VLOOKUP(C2,取引先マスタ!$A$2:$B$11,2,FALSE),"未登録")

下の行へコピーするときの注意
- マスタの範囲は $ で固定する：$A$2:$B$11 のままにしてください。
- C2 には $ を付けない：行ごとに C3、C4…と自動で変わる必要があるためです。
（以下、空欄の行の扱いと、数式の読み方が続く）
```

出力例はClaudeで生成しています。AIの出力は毎回少しずつ変わります。Claudeで検証しました。ChatGPT・Gemini・Copilotでも同じ依頼文を使えますが、出力は異なります（未検証）。返ってきた式は、サンプルの20行で期待する結果になりました。

テンプレートあり・なしで2回ずつ頼んで比べると、なしの4回はAIが表の位置やシート名を仮に決め、Excel 2019の依頼でもXLOOKUPの式が先に返りました。ありの4回は、書いた版で使える式を自分の表の範囲のまま返しました（見つからないときの処理は、どちらもIFERROR）。

### 先に確かめる：自分のExcelでXLOOKUPは使えるか

XLOOKUPは、Microsoft 365・Excel 2021以降・Googleスプレッドシートで使えます。Microsoftのサポートページには、Excel 2016とExcel 2019では使えないと書かれています（出典：[Microsoft サポート「XLOOKUP 関数」](https://support.microsoft.com/ja-jp/excel/functions/xlookup-function)、[Google ドキュメント エディタ ヘルプ「XLOOKUP 関数」](https://support.google.com/docs/answer/12405947?hl=ja)。確認日：2026-11-08）。

空いているセルに「=XLO」と入れて候補にXLOOKUPが出るか、式が #NAME? にならないかで確かめます。ファイルを渡す相手が2019以前なら、例7の書き換えを使います。

## 事務の逆引き8例

8例とも同じ架空のサンプルで、列は107とGAS請求書パックにそろえています。

- 取引先マスタ（A2:D11）：A 取引先コード／B 取引先名／C 部署／D メール。C-001 株式会社サンプル商事（sample-shoji@example.com）、C-003 株式会社見本デザイン、C-005 株式会社テスト食品（test-foods@example.com）、C-010 株式会社サンプル企画など10社（コード順）
- 商品マスタ（A2:D11）：A 商品コード／B 品目／C 単価／D 税率。P-06 お弁当（軽減税率）864円など10件
- 請求明細（2〜21行目）：C 取引先コード／E 商品コード／G 数量など。15行目はマスタにない取引先 C-011、19行目はマスタにない商品 P-11
- 送付記録（2〜11行目）：C 対象月／D 取引先コード／G 合計（税込）。2026-10と2026-11の5社分

式の印は次のとおりです。XとFILTERの式の表計算ソフトでの表示は【オーナー確認待ち：Excel（Microsoft 365）とスプレッドシートでの表示】。

- V：どの版のExcelでも、スプレッドシートでも使える式（IFNAを使う式はExcel 2013以降）
- X：Microsoft 365・Excel 2021以降・スプレッドシートで使える式

### 取引先コードから社名を表示したい

```
V：=VLOOKUP(C2,取引先マスタ!$A$2:$D$11,2,FALSE)
X：=XLOOKUP(C2,取引先マスタ!$A$2:$A$11,取引先マスタ!$B$2:$B$11)
```

- 期待する結果：4行目（C-003）は「株式会社見本デザイン」
- つまずき：範囲に $ を付けないと、下の行にコピーしたときに範囲がずれます

### 取引先コードから請求書の送り先メールを引きたい

```
V：=VLOOKUP(C2,取引先マスタ!$A$2:$D$11,4,FALSE)
X：=XLOOKUP(C2,取引先マスタ!$A$2:$A$11,取引先マスタ!$D$2:$D$11)
```

- 期待する結果：2行目（C-001）は「sample-shoji@example.com」
- つまずき：Vの「4」は範囲の左から数えた列の番号で、マスタに列を足すとずれます。Xは返す列を直接指すので、ずれません

### 商品コードから単価を引き、金額を計算したい

```
V（単価・H2）：=VLOOKUP(E2,商品マスタ!$A$2:$D$11,3,FALSE)
V（金額・J2）：=G2*H2
X（単価）：=XLOOKUP(E2,商品マスタ!$A$2:$A$11,商品マスタ!$C$2:$C$11)
```

- 期待する結果：7行目（P-06・数量5）は単価864、金額4,320。金額の合計は149,670円（19行目を除く）
- つまずき：19行目（未登録の P-11）は、単価も金額も #N/A。合計が #N/A になったら、未登録のコードを探します

### 見つからないときは「未登録」と表示したい

```
V：=IFNA(VLOOKUP(C2,取引先マスタ!$A$2:$D$11,2,FALSE),"未登録")
X：=XLOOKUP(C2,取引先マスタ!$A$2:$A$11,取引先マスタ!$B$2:$B$11,"未登録")
```

- 期待する結果：15行目（C-011）は「未登録」
- つまずき：IFNAは #N/A だけを置き換えます。IFERRORはほかのエラーも置き換えるため、範囲の誤りに気づきにくくなります（出典：[Microsoft サポート「IFNA 関数」](https://support.microsoft.com/ja-jp/excel/functions/ifna-function)、確認日：2026-11-08）

### 左側の列の値を引きたい

受け取ったメールのアドレス（A2）から、取引先コードを調べます。メールの列（D列）より左にあるコードは、VLOOKUPでは引けません。

```
V：=IFNA(INDEX(取引先マスタ!$A$2:$A$11,MATCH(A2,取引先マスタ!$D$2:$D$11,0)),"未登録")
X：=XLOOKUP(A2,取引先マスタ!$D$2:$D$11,取引先マスタ!$A$2:$A$11,"未登録")
```

- 期待する結果：test-foods@example.com は「C-005」、マスタにないアドレスは「未登録」
- つまずき：MATCHの最後の「0」を省くと、完全一致になりません

### VLOOKUPで違う行の値が返ってくる

4番目の引数（FALSE）を省くと、表が並べ替え済みとみなされ、近い値で探します。スプレッドシートも同じです。

```
誤り：=VLOOKUP(C2,取引先マスタ!$A$2:$D$11,2)
正しい：=VLOOKUP(C2,取引先マスタ!$A$2:$D$11,2,FALSE)
```

- 期待する結果：15行目（未登録のC-011）は、誤りの式だと #N/A にならず、C-010の「株式会社サンプル企画」が返ります。正しい式なら #N/A
- つまずき：エラーが出ないので、気づきにくい誤りです

### 相手のExcelが2019以前のときに書き換えたい

```
書き換える前（X）：=XLOOKUP(C2,取引先マスタ!$A$2:$A$11,取引先マスタ!$B$2:$B$11,"未登録")
書き換えた後（V）：=IFNA(INDEX(取引先マスタ!$B$2:$B$11,MATCH(C2,取引先マスタ!$A$2:$A$11,0)),"未登録")
```

- 期待する結果：20行とも書き換える前と同じ表示（15行目は「未登録」）
- AIに頼むとき：「相手のExcelは2019です。XLOOKUPを使わない式に書き換えてください」と書き、元の式を貼ります
- つまずき：XLOOKUPがない環境では #NAME? になります。検証に使ったLibreOffice 24.2でも #NAME? でした

### 取引先と月の2つの条件で引きたい

対象月（D2）と取引先コード（E2）の両方が合う行の合計を、送付記録から引きます。取引先の月ごとの請求額を見比べるときに使います。

```
Excel（Microsoft 365・2021以降）：
=XLOOKUP(1,(送付記録!$C$2:$C$11=D2)*(送付記録!$D$2:$D$11=E2),送付記録!$G$2:$G$11,"未登録")

スプレッドシート：
=IFNA(FILTER(送付記録!$G$2:$G$11,送付記録!$C$2:$C$11=D2,送付記録!$D$2:$D$11=E2),"未登録")

Excel（2019以前）：
=IFNA(INDEX(送付記録!$G$2:$G$11,MATCH(1,INDEX((送付記録!$C$2:$C$11=D2)*(送付記録!$D$2:$D$11=E2),0),0)),"未登録")

合う行が1件だけか確かめる式（すべて共通）：
=SUMPRODUCT((送付記録!$C$2:$C$11=D2)*(送付記録!$D$2:$D$11=E2))
```

- 期待する結果：2026-10・C-003 は14,850、2026-11・C-004 は37,378、2026-12・C-001 は「未登録」。件数の式は1・1・0
- つまずき：同じ組み合わせが2行あると、XLOOKUPとINDEX/MATCHは上の行だけを返し、FILTERは下のセルにも結果を出します（下のセルは空けておく）。件数の式が1でなければ、元の表を直します

## AIが出した数式を確かめる手順

AIが返した式は、本番の表に広げる前に次の5つで試します（手順の式もサンプルで検算済み）。

1. 端の行：マスタの最初（C-001）と最後（C-010）を引いて、正しく出るか
2. 未登録のコード：マスタにないコード（C-011）で「未登録」か #N/A になるか。違う社名が出たら、4番目のFALSEを確かめる
3. 重複したコード：マスタに同じコードが2行あると、上の行が返ります。次の式が1かを確かめる

```
=COUNTIF(取引先マスタ!$A$2:$A$11,C2)
```

4. 空白：探す値が空欄の行を空欄のままにしたいときは、次の式に変える

```
=IF(C2="","",IFNA(VLOOKUP(C2,取引先マスタ!$A$2:$D$11,2,FALSE),"未登録"))
```

5. コピーのずれ：下の行にコピーしたあと、範囲の $ が残っているかを見て、2〜3行はマスタと目で照らし合わせる
