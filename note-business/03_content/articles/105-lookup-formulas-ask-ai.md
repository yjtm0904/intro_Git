## 結論：表の形・Excelの版・見つからないときの表示をAIに伝える

取引先コードから社名を引く、商品コードから単価を引く。こうした数式をAIに頼むときは、次の3つを伝えます。表の列と範囲、使っているExcelの版、見つからないときの表示です。

検証では、この3つを書かずに頼むと、AIが表の形を仮に決めた式や、Excel 2019では使えないXLOOKUPの式が先に返ってきました。書いて頼むと、自分の表の範囲のまま貼れる式が返りました。この記事では、頼み方のテンプレートと、請求の表でよく使う逆引き8例を、検算した結果つきで載せます。

【検証情報】検証日：2026-11-08／使ったツール：Claude（2026年11月時点）、LibreOffice Calc 24.2、Python 3.13
検証方法：架空の取引先マスタ10社・商品マスタ10件・請求明細20行で、8例の数式をLibreOfficeで計算し、Pythonで別に求めた期待値と照合（239セルすべて一致）。XLOOKUPとFILTERはLibreOffice 24.2では計算できないため、Pythonで期待値を求めたうえで、Excel（Microsoft 365）とGoogleスプレッドシートで表示を確認（確認日：【実機確認後に記入】）。頼み方は、テンプレートあり・なしで2回ずつClaudeに頼んで比べた

## AIへの頼み方テンプレート

次のテンプレートの（ ）を、自分の表に合わせて書き換えて使います。例の値は、実在の取引先名ではなく「株式会社サンプル商事」「C-001」のような架空の値にします。AIに入れてはいけない情報は、「生成AIに入力してはいけない情報と、マスキングのやり方」（［リンク：106の記事］）にまとめています。勤務先のAI利用ルールも先に確かめてください。

```
次の条件で、（Excel 2019／Microsoft 365のExcel／Googleスプレッドシート）の数式を作ってください。

【やりたいこと】
（例：請求明細のD列に、C列の取引先コードに対応する取引先名を表示したい）

【表の列】（列名と例の値）
- （表の名前と範囲）：A列 （列名）（例：…）、B列 （列名）（例：…）
- （数式を入れる表）：（列名と、数式を入れる列）

【探す値の場所】
（例：請求明細のC2。下の行にもコピーする）

【見つからないときの表示】
（例：「未登録」と表示する）

【使うソフトと版】
（例：Excel 2019（XLOOKUPは使えない））

【出してほしいもの】
数式1つと、下の行へコピーするときの注意、数式の読み方を短く
```

### テンプレートで頼んだ例

入力例（テンプレートを埋めたもの）：

```
【やりたいこと】請求明細のD列に、C列の取引先コードに対応する取引先名を表示したい
【表の列】取引先マスタ（A2:D11、10社）：A列 取引先コード（例：C-001）、B列 取引先名（例：株式会社サンプル商事）、C列 部署（例：経理部）、D列 メール（例：sample-shoji@example.com）
請求明細（2行目から下）：C列 取引先コード（例：C-003）、D列 取引先名（ここに数式を入れる）
【探す値の場所】請求明細のC2（下の行にもコピーする）
【見つからないときの表示】「未登録」と表示する
【使うソフトと版】Excel 2019（XLOOKUPは使えない）
【出してほしいもの】D2に入れる数式1つと、下の行へコピーするときの注意、数式の読み方を短く
```

出力例（抜粋。太字の記号などは省いています）：

```
D2に入れる数式
=IFERROR(VLOOKUP(C2,取引先マスタ!$A$2:$B$11,2,FALSE),"未登録")

下の行へコピーするときの注意
- マスタの範囲は $ で固定する：$A$2:$B$11 のままにしてください。$ がないと、コピーしたときに範囲が下にずれて、正しく見つからなくなります。
- C2 には $ を付けない：行ごとに C3、C4…と自動で変わる必要があるためです。
- C列が空欄の行も「未登録」になる：空欄の行を空白のままにしたい場合は、次の数式を使ってください。
  =IF(C2="","",IFERROR(VLOOKUP(C2,取引先マスタ!$A$2:$B$11,2,FALSE),"未登録"))
（以下、数式の読み方が続く）
```

出力例はClaudeで生成しています。AIの出力は毎回少しずつ変わります。返ってきた式は、サンプルの20行で期待する結果になることを確かめました。ChatGPT・Gemini・Copilotでも同じ形で頼めますが、筆者が出力を確かめたのはClaudeだけです。

テンプレートあり・なしで2回ずつ頼んで比べると、次の差が出ました。

- 版を書くと、その版で使える式が返った。Excel 2019と書いた2回はVLOOKUPだけ、Microsoft 365とスプレッドシートと書いた2回はXLOOKUPが返った
- 表の列と範囲を書くと、自分の表の範囲とセルのまま貼れる式が返った。書かずに頼んだ4回は、どれもAIが表の位置やシート名を仮に決めていた
- 書かないと、例の社名やメールアドレスをAIが仮に作った。実在しそうな名前だったので、記事や資料にそのまま使わないようにします
- どちらの頼み方でも、VLOOKUPやINDEX/MATCHの式では、見つからないときの処理にIFERRORが使われた。IFNAにしたいときは、そう書いて頼みます（違いは例4）

### 先に確かめる：自分のExcelでXLOOKUPは使えるか

XLOOKUPは、Microsoft 365・Excel 2021以降・Googleスプレッドシートで使えます。MicrosoftのサポートページにはExcel 2016とExcel 2019では使えないと書かれています（出典：[Microsoft サポート「XLOOKUP 関数」](https://support.microsoft.com/ja-jp/excel/functions/xlookup-function)、[Google ドキュメント エディタ ヘルプ「XLOOKUP 関数」](https://support.google.com/docs/answer/12405947?hl=ja)。確認日：2026-11-08）。

確かめ方は2つです。

- 空いているセルに「=XLO」と入れて、候補にXLOOKUPが出るかを見る
- XLOOKUPの式を入れて #NAME? と表示されたら、その版では使えない

請求書のファイルを取引先や他部署と共有するときは、相手の版でも同じです。相手が2019以前なら、例8の書き換えを使います。

## 事務の逆引き8例

8例とも、同じ架空のサンプルを使います。列の構成は、請求書の自動作成の記事（107・202）と同じです。

- 取引先マスタ（A2:D11）：A 取引先コード／B 取引先名／C 部署／D メール。C-001 株式会社サンプル商事（sample-shoji@example.com）、C-003 株式会社見本デザイン、C-005 株式会社テスト食品（test-foods@example.com）、C-010 株式会社サンプル企画など10社。コードの順に並んでいる
- 商品マスタ（A2:D11）：A 商品コード／B 品目／C 単価／D 税率。P-01 月額保守サービス 33,000円、P-06 お弁当（軽減税率）864円など10件
- 請求明細（2〜21行目）：C 取引先コード／E 商品コード／G 数量など。15行目はマスタにない取引先 C-011、19行目はマスタにない商品 P-11
- 送付記録（2〜11行目）：C 対象月／D 取引先コード／G 合計（税込）。2026-10と2026-11の5社分

Excel版とスプレッドシート版の式が同じ場合は、1つだけ載せています。

### 取引先コードから社名を表示したい

請求明細のD2に入れ、下の行にコピーします。

```
Excel（すべての版）・スプレッドシート：
=VLOOKUP(C2,取引先マスタ!$A$2:$D$11,2,FALSE)

Excel（Microsoft 365・2021以降）・スプレッドシート：
=XLOOKUP(C2,取引先マスタ!$A$2:$A$11,取引先マスタ!$B$2:$B$11)
```

- 期待する結果：4行目（C-003）は「株式会社見本デザイン」
- つまずき：範囲に $ を付けないと、下の行にコピーしたときに範囲がずれます

### 取引先コードから請求書の送り先メールを引きたい

```
Excel（すべての版）・スプレッドシート：
=VLOOKUP(C2,取引先マスタ!$A$2:$D$11,4,FALSE)

Excel（Microsoft 365・2021以降）・スプレッドシート：
=XLOOKUP(C2,取引先マスタ!$A$2:$A$11,取引先マスタ!$D$2:$D$11)
```

- 期待する結果：2行目（C-001）は「sample-shoji@example.com」
- つまずき：VLOOKUPの「4」は、範囲の左から数えた列の番号です。マスタに列を足すと、番号がずれて部署などを返します。XLOOKUPは返す列を直接指すので、列を足しても同じ列を返します

### 商品コードから単価を引き、金額を計算したい

単価をH2、金額をJ2に入れます。

```
Excel（すべての版）・スプレッドシート：
H2：=VLOOKUP(E2,商品マスタ!$A$2:$D$11,3,FALSE)
J2：=G2*H2

Excel（Microsoft 365・2021以降）・スプレッドシート（単価）：
=XLOOKUP(E2,商品マスタ!$A$2:$A$11,商品マスタ!$C$2:$C$11)
```

- 期待する結果：7行目（P-06・数量5）は単価864、金額4,320。20行の金額の合計は149,670円（19行目を除く）
- つまずき：19行目（未登録の商品 P-11）は、単価も金額も #N/A になります。合計が #N/A になったら、未登録のコードがないかを見ます

### 見つからないときは「未登録」と表示したい

```
Excel（2013以降）・スプレッドシート：
=IFNA(VLOOKUP(C2,取引先マスタ!$A$2:$D$11,2,FALSE),"未登録")

Excel（Microsoft 365・2021以降）・スプレッドシート：
=XLOOKUP(C2,取引先マスタ!$A$2:$A$11,取引先マスタ!$B$2:$B$11,"未登録")
```

- 期待する結果：15行目（C-011）は「未登録」。ほかの行は社名
- つまずき：IFNAは #N/A のときだけ置き換えます。IFERRORはほかのエラーもすべて置き換えるため、範囲の誤りなどに気づきにくくなります（出典：[Microsoft サポート「IFNA 関数」](https://support.microsoft.com/ja-jp/excel/functions/ifna-function)、確認日：2026-11-08）

### 左側の列の値を引きたい

受け取ったメールのアドレス（A2）から、取引先コードを調べます。メールの列（D列）より左にあるコード（A列）は、VLOOKUPでは引けません。

```
Excel（すべての版）・スプレッドシート：
=IFNA(INDEX(取引先マスタ!$A$2:$A$11,MATCH(A2,取引先マスタ!$D$2:$D$11,0)),"未登録")

Excel（Microsoft 365・2021以降）・スプレッドシート：
=XLOOKUP(A2,取引先マスタ!$D$2:$D$11,取引先マスタ!$A$2:$A$11,"未登録")
```

- 期待する結果：test-foods@example.com は「C-005」、sample-kikaku@example.com は「C-010」、マスタにないアドレスは「未登録」
- つまずき：MATCHの最後の「0」を省くと、完全一致になりません

### 取引先と月の2つの条件で引きたい

送付記録から、対象月（D2）と取引先コード（E2）の両方が合う行の合計を引きます。

```
Excel（Microsoft 365・2021以降）：
=XLOOKUP(1,(送付記録!$C$2:$C$11=D2)*(送付記録!$D$2:$D$11=E2),送付記録!$G$2:$G$11,"未登録")

スプレッドシート：
=IFNA(FILTER(送付記録!$G$2:$G$11,送付記録!$C$2:$C$11=D2,送付記録!$D$2:$D$11=E2),"未登録")

Excel（2019以前）：
=IFNA(INDEX(送付記録!$G$2:$G$11,MATCH(1,INDEX((送付記録!$C$2:$C$11=D2)*(送付記録!$D$2:$D$11=E2),0),0)),"未登録")

合う行が1件だけか確かめる式（すべて共通）：
=SUMPRODUCT((送付記録!$C$2:$C$11=D2)*(送付記録!$D$2:$D$11=E2))
```

- 期待する結果：2026-10・C-003 は14,850、2026-11・C-004 は37,378、2026-12・C-001 は「未登録」。件数の式は1・1・0
- つまずき：同じ組み合わせが2行あると、XLOOKUPとINDEX/MATCHは上の行だけを返します（FILTERは両方を返します）。件数の式が1でないときは、元の表を直します。対象月が文字と日付で混ざっていても合いません

### VLOOKUPで違う行の値が返ってくる

VLOOKUPの4番目の引数（FALSE）を省くと、表が並べ替え済みとみなされ、近い値で探します（近似一致）。

```
誤り（4番目を省いた）：
=VLOOKUP(C2,取引先マスタ!$A$2:$D$11,2)

正しい（完全一致）：
=VLOOKUP(C2,取引先マスタ!$A$2:$D$11,2,FALSE)
```

- 期待する結果：15行目（未登録のC-011）は、誤りの式だと #N/A にならず、C-010の「株式会社サンプル企画」が返ります。正しい式なら #N/A です
- つまずき：エラーが出ないので、気づきにくい誤りです。スプレッドシートのVLOOKUPも、4番目を省くと同じ扱いになります

### 相手のExcelが2019以前のときに書き換えたい

XLOOKUPの式を、Excel 2019以前でも動く形に書き換えます。

```
書き換える前（XLOOKUP）：
=XLOOKUP(C2,取引先マスタ!$A$2:$A$11,取引先マスタ!$B$2:$B$11,"未登録")

書き換えた後（Excel 2013以降・スプレッドシート）：
=IFNA(INDEX(取引先マスタ!$B$2:$B$11,MATCH(C2,取引先マスタ!$A$2:$A$11,0)),"未登録")
```

- 期待する結果：20行とも、書き換える前と同じ表示（15行目は「未登録」）
- AIに頼むとき：「相手のExcelは2019です。XLOOKUPを使わない式に書き換えてください」と書き、元の式を貼ります
- つまずき：XLOOKUPに対応していない環境では #NAME? になります。検証に使ったLibreOffice 24.2でも、XLOOKUPは #NAME? になりました

## AIが出した数式を確かめる手順

AIが返した式は、本番の表に広げる前に、次の5つで試します。検証では、この手順の式もサンプルで計算して確かめました。

1. 端の行：マスタの最初（C-001）と最後（C-010）を引いて、正しく出るか
2. 未登録のコード：マスタにないコード（C-011）で「未登録」か #N/A になるか。違う社名が出たら、4番目のFALSEを確かめる
3. 重複したコード：マスタに同じコードが2行あると、上の行が返ります。次の式が1になるかを確かめる

```
=COUNTIF(取引先マスタ!$A$2:$A$11,C2)
```

4. 空白：探す値が空欄の行が「未登録」になって困るときは、空欄のままにする式に変える

```
=IF(C2="","",IFNA(VLOOKUP(C2,取引先マスタ!$A$2:$D$11,2,FALSE),"未登録"))
```

5. コピーのずれ：下の行にコピーしたあと、数式を開いて、範囲の $ が残っているかを見る。2〜3行は、マスタを目で見て照らし合わせる

エラーが出て直し方が分からないときは、エラーをAIに聞く方法の記事を準備しています（公開後にリンクを追記します）。
