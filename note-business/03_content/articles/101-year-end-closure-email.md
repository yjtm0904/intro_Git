## 結論：休業案内は4つの文面と曜日の確認でそろう

取引先に年末年始の休業を伝える文面は、4つでそろいます。休業案内メール、年始の挨拶、Webサイトと署名の告知、休み中の自動返信です。この記事では4つの文例を件名つきで載せ、休業期間を入れれば自社用に作り直せるAIプロンプトを2本付けます。毎年、前年のメールを探して日付と曜日を直している場合は、プロンプトの【条件】を書き換えるだけで済みます。最後に、曜日の食い違いなどを送る前に見つけるチェックリストを付けます。

【検証情報】検証日：2026-11-08／使ったツール：Claude（2026年11月時点）、Python 3.13
検証方法：プロンプト2本をClaudeで実行し、出力の日付と曜日を2026年12月・2027年1月のカレンダーとPythonで照合。依頼文にない日付・連絡先・サービス内容が入っていないかも機械的に点検

## 休業案内に入れる項目

### 休業期間・営業開始日・休み中の連絡先

この記事の文例は、休業期間を「2026年12月29日（火）〜2027年1月4日（月）」、営業開始日を「2027年1月5日（火）」とした例です。休業期間は会社ごとに違うので、自社の日付に置き換えてください。

- 休業期間：初日と最終日を、年と曜日つきで書く
- 営業開始日：休業の最終日の翌日になっているか確かめる
- 休み中の問い合わせの扱い：営業開始後に順次返信する、など
- 休み中の連絡先：緊急の窓口を設ける場合だけ書く。設けないなら書かない
- 差出人：会社名・部署・担当者

### 送る時期と送り方（一斉送信はBCC）

送る時期は、一般的な目安として次のように考えます。

- 休業案内メール：取引先が年内の発注・納品・支払いの段取りを決める前に届くよう、12月の早い時期に送る
- Webサイトと署名の告知：休業案内メールと同じ日に載せ、営業開始後に外す
- 自動返信：休業の初日から最終日までの期間で設定する
- 年始の挨拶：営業開始日以降に送る

複数の取引先に送るときは、宛先をBCCに入れ、To（宛先）には自社のアドレスを入れます。**ほかの取引先のメールアドレスが互いに見えないようにするためです。**

## 文例3：Webサイト・メール署名に載せる告知文

Webサイトのお知らせ欄と、メール署名の上に入れる短い告知です。署名の告知は、休業案内を送る日からふだんのメールに付けておくと、案内を見落とした相手にも伝わります。

```

見出し：年末年始休業のお知らせ

平素は格別のお引き立てを賜り、誠にありがとうございます。
誠に勝手ながら、弊社では下記の期間を年末年始休業とさせていただきます。

・休業期間：2026年12月29日（火）〜2027年1月4日（月）
・営業開始：2027年1月5日（火）

休業期間中にいただいたお問い合わせには、1月5日（火）以降、順次お返事いたします。
ご不便をおかけいたしますが、ご理解を賜りますようお願い申し上げます。

〔会社名〕

【メール署名用】
【年末年始休業のお知らせ】
12月29日（火）〜1月4日（月）は休業いたします。1月5日（火）より営業いたします。
```

## 文例4：休み中の自動返信（不在通知）

休業期間中に届いたメールへ自動で返す文面です。件名に【自動返信】と入れ、手動の返信と区別できるようにしています。

```
件名：【自動返信】年末年始休業のお知らせ

メールをお送りいただき、ありがとうございます。
誠に勝手ながら、弊社は2026年12月29日（火）〜2027年1月4日（月）を年末年始休業とさせていただいております。
いただいたメールは、2027年1月5日（火）以降、順次確認してお返事いたします。
緊急のご用件は、お手数ですが〔緊急連絡先のメールアドレス〕までご連絡ください。
ご不便をおかけいたしますが、よろしくお願い申し上げます。

〔会社名〕〔部署名〕
```

Gmailの場合、パソコンでは設定（歯車のアイコン）→「すべての設定を表示」→「全般」タブの「不在通知」を開き、期間・件名・メッセージを入れて保存します。連絡先にだけ返信する設定もあります。画面は変わることがあるので、[Gmailヘルプ「不在時に自動返信を送信する」](https://support.google.com/mail/answer/25922?hl=ja)で確かめてください（確認日：2026-11-08）。ほかのメールソフトは、そのソフトのヘルプで「自動応答」「不在通知」を調べます。

## 自社用の文面をAIで作るプロンプト

### 条件を埋めて文面を作る

【条件】の5行を自社の内容に書き換えて貼ります。会社名・担当者名・連絡先は〔　〕のまま入れ、出力をメールに貼ってから書き換えます（理由は後の節）。下の【条件】は、文例1〜4を作ったときの入力例です。

```
あなたは中小企業の総務担当です。取引先に送る年末年始の休業案内を作ります。
下の【条件】を使って、次の4つの文面を作ってください。

【作る文面】
1. 取引先への休業案内メール
2. 年始の挨拶と営業開始のお知らせメール
3. Webサイトに載せる告知文と、メール署名に入れる告知
4. 休み中の自動返信（不在通知）

【条件】
- 休業期間：2026年12月29日（火）〜2027年1月4日（月）
- 営業開始日：2027年1月5日（火）
- 休み中の連絡先：緊急の場合は〔緊急連絡先のメールアドレス〕へ
- 相手との関係：継続して取引のある会社
- 差出人：〔会社名〕〔部署名〕〔担当者名〕

【書き方】
- 1・2・4は件名、3のWeb告知は見出しをつける。本文は200〜350字。署名の告知は1〜2行。
- 件名も含め、日付には曜日をつける。日付と曜日は【条件】のものだけを使う。
- 「本日」「明日」は使わず、日付で書く。
- 【条件】にない連絡先・電話番号・サービス内容（注文・発送など）を足さない。〔　〕はそのまま残す。
- 取引先に失礼のない、標準的なビジネスメールの言い回しにする。不安をあおる言い方はしない。
- 文面だけを出力し、送る時期などの助言は付けない。
```

【書き方】の条件は、検証で実際に起きたことをもとに足しました。条件を付けない最初の依頼文では、次の4つが出ました。

- 文例1の件名だけ、日付に曜日がない（「12月29日〜1月4日」）
- Web告知に、依頼文にない「ご注文」が入る
- 文例2が「本日1月5日（火）より」となり、営業開始日に送る前提になる
- 文面の後の助言に、根拠のない「休業開始の1〜2週間前までに」が入る

条件を足した後は、4つとも出ませんでした。日付と曜日は、最初の依頼文でも誤りはありませんでした。ChatGPTやGeminiでも同じ形で使える構成です（動作を確かめたのはClaudeだけです）。

### 言い回しを自社に合わせる

作った文面を、自社の言い回しに直すときのプロンプトです。【自社の書き方】の3行を書き換え、【文面】に直したい文面を貼ります。

```
次の【文面】を、【自社の書き方】に合わせて直してください。

【自社の書き方】
- 「弊社」ではなく「当社」を使う
- 「お引き立て」ではなく「ご愛顧」を使う
- 全体をもう少し短く、1文を短くする

【守ること】
- 日付・曜日・連絡先・〔　〕の部分は変えない。新しい内容を足さない。
- 取引先向けの丁寧さは元の文面と同じに保つ（「いたします」を「します」に崩さない）。
- 直した文面のあとに、変えた箇所を箇条書きで3つまで示す。

【文面】
（ここに文例1などを貼る）
```

文例1を貼って実行した出力例です（出力例はClaudeで生成。AIの出力は毎回少しずつ変わります）。日付と〔　〕は元の文面と同じでした。

```
件名：年末年始休業のお知らせ（12月29日（火）〜1月4日（月））

〔取引先会社名〕
〔ご担当者名〕様

いつもお世話になっております。〔会社名〕〔部署名〕の〔担当者名〕です。
誠に勝手ながら、当社は下記の期間を年末年始休業とさせていただきます。

・休業期間：2026年12月29日（火）〜2027年1月4日（月）
・営業開始：2027年1月5日（火）

休業中のお問い合わせには、1月5日（火）以降、順次お返事いたします。
緊急のご用件は、〔緊急連絡先のメールアドレス〕までご連絡ください。
本年も格別のご愛顧を賜り、ありがとうございました。来年もよろしくお願い申し上げます。

〔署名〕

（変えた箇所）
- 「弊社では」を「当社は」に、「お引き立て」を「ご愛顧」に変えました。
- 「いつも大変お世話になっております」を「いつもお世話になっております」に、「休業期間中に」を「休業中に」に短くしました。
- 長い文を2つに分け、結びを「来年もよろしくお願い申し上げます」にまとめました。
```

【守ること】を付けない最初の依頼文では、日付と〔　〕は保たれました。ただし「順次お返事いたします」が「順次お返事します」に崩れ、どこを変えたかの説明もありませんでした。丁寧さを保つ条件と、変えた箇所を示す条件は、そのために足しています。

## 送る前のチェックリスト（曜日はカレンダーで確かめる）

- 休業期間の初日と最終日の曜日を、カレンダーで確かめたか（12月と1月で年が変わる）
- 営業開始日が、休業の最終日の翌日になっているか
- 文例1〜4で、日付と曜日がすべて同じか
- 年の書き間違い（2026年と2027年）がないか
- 〔　〕をすべて書き換えたか（会社名・担当者名・署名）
- 休み中の連絡先を書いた場合、アドレスや番号に誤りがないか
- 一斉送信の宛先はBCCに入れ、To（宛先）を自社のアドレスにしたか
- 署名の会社名・部署・電話番号が最新か
- 自動返信の開始日と終了日を、休業期間に合わせたか
- Webサイトと署名の告知を外す日（営業開始後）を決めたか

## AIに入れない情報（社名・担当者名は置き換える）

先に、勤務先のAI利用ルール（使ってよいツール、入れてよい情報の範囲）を確かめます。休業案内は定型の文面なので、AIに実在の情報を入れなくても作れます。

入れない情報
- 自社と取引先の会社名、担当者の氏名
- 電話番号・メールアドレス（緊急の連絡先を含む）
- 取引の内容（注文・金額・納期）
- 休業の理由など、社外にまだ出していない社内の事情

置き換えの例
- 入れる前：株式会社サンプル商事 営業部 見本一郎、緊急時は090-0000-0000
- 置き換えた後：〔会社名〕〔部署名〕〔担当者名〕、緊急時は〔緊急連絡先〕

出力をメールに貼ってから、〔　〕を自分で書き換えます。

## まとめ：社内向けの連絡は文書キットへ

- 社外向けは、休業案内・年始の挨拶・Webと署名の告知・自動返信の4つでそろう
- 作成用のプロンプトで4つをまとめて作り、調整用のプロンプトで自社の言い回しに直す
- 送る前に、曜日・年・営業開始日・BCC・〔　〕の書き換えをチェックリストで確かめる

この記事は社外向けに絞っています。仕事納めの段取りや休み中の社内の連絡体制など、社内向けの文書は、別の記事「年末年始〜年度末の総務文書キット」で扱います。
