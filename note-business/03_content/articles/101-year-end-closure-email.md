取引先に年末年始の休みを知らせる時期になった。去年のメールを探し出して、日付と曜日を1か所ずつ直している。

休業の連絡に要る文面は、4つでそろいます。休業案内メール、年始の挨拶、Webサイトと署名の告知、休み中の自動返信です。4つの文例と、休業期間を書き換えれば自社用に作り直せるAIプロンプトを2本載せました。日付を書き換えたら、送る前に曜日をカレンダーで確かめます。

【検証情報】2026-11-08に、プロンプト2本を、記事を書いた会話とは別の新しい会話で2回ずつ試しました。載せたのは1回目の出力です。2回とも、日付と曜日をPython 3.13で2026年12月・2027年1月のカレンダーと照合しました。依頼文にない日付・連絡先・サービス内容が入っていないかも確かめています。
文例はClaude（2026年11月時点）で作りました。書き方の指定なしで頼むと、2回とも件名の日付に曜日がなく、年始の挨拶には「本日1月5日（火）より」と入りました。そこで、日付は曜日つきで書き、「本日」を使わない指定を足しています。AIの出力は毎回少しずつ変わります。試したAIはClaudeだけで、ChatGPT・Gemini・Copilotでの結果は確かめていません。

## 休業案内に入れる項目

### 休業期間・営業開始日・休み中の連絡先

この記事の文例は、休業期間を「2026年12月29日（火）〜2027年1月4日（月）」、営業開始日を「2027年1月5日（火）」とした例です。休業期間は会社ごとに違うので、自社の日付に置き換えてください。

- 休業期間：初日と最終日を、年と曜日つきで書く
- 営業開始日：休業の最終日の翌日になっているか確かめる
- 休み中の問い合わせの扱い：営業開始後に順次返信する、など
- 休み中の連絡先：緊急の窓口を設ける場合だけ書く
- 差出人：会社名・部署・担当者

### 送る時期と送り方

送る時期は、一般的な目安として次のように考えます。

- 休業案内メール：取引先が年内の段取りを決める前に届くよう、12月の早い時期に送る
- Webサイトと署名の告知：休業案内メールと同じ日に載せ、営業開始後に外す
- 自動返信：休業の初日から最終日までの期間で設定する
- 年始の挨拶：営業開始日以降に送る

文例1・2の宛名「お取引先各位」は、宛先をBCCに入れて一斉に送る形です。1社ずつ送るときは、〔取引先会社名〕〔ご担当者名〕様に替えます。

## 文例1：取引先への休業案内メール

文例1〜4は、後の節の作成用プロンプトで作った出力です。試した2回とも、日付は【条件】の3つだけで曜日も合い、本文は指定の字数に収まりました。〔　〕は自社の情報に書き換えます。

```
件名：年末年始休業のお知らせ（2026年12月29日（火）〜2027年1月4日（月））

お取引先各位

平素より格別のお引き立てを賜り、厚く御礼申し上げます。
誠に勝手ながら、弊社では下記の期間を年末年始休業とさせていただきます。

休業期間：2026年12月29日（火）〜2027年1月4日（月）
営業開始日：2027年1月5日（火）

休業期間中にいただいたご連絡につきましては、2027年1月5日（火）以降、順次対応させていただきます。
緊急のご用件の場合は、〔緊急連絡先のメールアドレス〕までご連絡くださいますようお願い申し上げます。
ご不便をおかけいたしますが、何卒ご理解賜りますようお願い申し上げます。

本年も格別のご愛顧を賜り、誠にありがとうございました。
来年も変わらぬお付き合いのほど、よろしくお願い申し上げます。

〔会社名〕

```

## 文例3：Webサイト・メール署名に載せる告知文

Webサイトのお知らせ欄と、メール署名の上に入れる短い告知です。署名の告知は、休業案内を送る日からふだんのメールに付けておくと、案内を見落とした相手にも伝わります。

```

見出し：年末年始休業のお知らせ

平素より格別のお引き立てを賜り、誠にありがとうございます。
誠に勝手ながら、弊社では下記の期間を年末年始休業とさせていただきます。

休業期間：2026年12月29日（火）〜2027年1月4日（月）
営業開始日：2027年1月5日（火）

休業期間中にいただいたお問い合わせにつきましては、2027年1月5日（火）以降、順次対応させていただきます。
緊急のご用件は、〔緊急連絡先のメールアドレス〕までご連絡ください。
ご不便をおかけいたしますが、何卒ご理解賜りますようお願い申し上げます。

〔会社名〕

【メール署名用告知】
【年末年始休業のお知らせ】2026年12月29日（火）〜2027年1月4日（月）は休業いたします。
2027年1月5日（火）より通常どおり営業いたします。
```

## 文例4：休み中の自動返信（不在通知）

休業期間中に届いたメールへ自動で返す文面です。件名に【自動返信】、本文の最後に自動送信であることを入れ、手動の返信と区別できるようにしています。

```
件名：【自動返信】年末年始休業のお知らせ（2027年1月5日（火）より営業開始）

メールをお送りいただき、誠にありがとうございます。

誠に勝手ながら、弊社では2026年12月29日（火）〜2027年1月4日（月）を年末年始休業とさせていただいております。
いただいたメールは受信しておりますので、内容を確認のうえ、2027年1月5日（火）以降、順次ご返信いたします。

緊急のご用件の場合は、お手数ですが〔緊急連絡先のメールアドレス〕までご連絡くださいますようお願いいたします。
ご不便をおかけいたしますが、何卒ご了承くださいますようお願い申し上げます。

※このメールは自動送信です。

〔会社名〕
〔部署名〕
〔担当者名〕
```

Gmailの場合、パソコンでの設定の場所は、歯車のアイコン→「すべての設定を表示」→「全般」タブの「不在通知」です。期間・件名・メッセージを入れて保存します。連絡先にだけ返信する設定もあります。手順は[Gmailヘルプ「不在時に自動返信を送信する」](https://support.google.com/mail/answer/25922?hl=ja)で確かめてください（確認日：2026-11-08）。ほかのメールソフトは、そのソフトのヘルプで「自動応答」「不在通知」を調べます。

## 自社用の文面をAIで作るプロンプト

AIを使わない方は、文例をコピーして、送る前の確認へ進んでください。

### 条件を埋めて文面を作る

【条件】の5行を自社の内容に書き換えて貼ります。試した2回とも、出力の曜日は【条件】の曜日のままでした。【条件】の曜日は、貼る前にカレンダーで確かめます。会社名・担当者名・連絡先は〔　〕のまま入れ、出力を貼ってから書き換えます。下の【条件】は、文例1〜4を作ったときの入力例です。

```
あなたは中小企業の総務担当です。取引先に送る年末年始の休業案内を作ります。
下の【条件】を使って、次の4つの文面を作ってください。

【作る文面】
1. 取引先への休業案内メール
2. 年始の挨拶と営業開始のお知らせメール
3. Webサイトに載せる告知文と、メール署名に入れる告知
4. 休み中の自動返信（不在通知）

【条件】
- 休業期間：2026年12月29日（火）〜2027年1月4日（月）
- 営業開始日：2027年1月5日（火）
- 休み中の連絡先：緊急の場合は〔緊急連絡先のメールアドレス〕へ
- 相手との関係：継続して取引のある会社
- 差出人：〔会社名〕〔部署名〕〔担当者名〕

【書き方】
- 1・2・4は件名、3のWeb告知は見出しをつける。本文は200〜350字。署名の告知は1〜2行。
- 件名も含め、日付には曜日をつける。日付と曜日は【条件】のものだけを使う。
- 「本日」「明日」は使わず、日付で書く。
- 【条件】にない連絡先・電話番号・サービス内容（注文・発送など）を足さない。〔　〕はそのまま残す。
- 取引先に失礼のない、標準的なビジネスメールの言い回しにする。不安をあおる言い方はしない。
- 文面だけを出力し、送る時期などの助言は付けない。
```

【書き方】の指定がない最初の依頼文で2回作ると、2回とも件名の日付に曜日がなく、文例2には「本日1月5日（火）より」と入りました。依頼文にない「ご注文」や、「遅くとも休業の2週間前」のような送る時期の目安も足されています。【書き方】の条件は、これを防ぐために足しています。

### 言い回しを自社に合わせる

作った文面を、自社の言い回しに直すときのプロンプトです。【自社の書き方】の3行を書き換え、【文面】に直したい文面を貼ります。「弊社」を当社・当事務所・当教室などに替えるときも、ここに書きます。

```
次の【文面】を、【自社の書き方】に合わせて直してください。

【自社の書き方】
- 「弊社」ではなく「当社」を使う
- 「お引き立て」ではなく「ご愛顧」を使う
- 全体をもう少し短く、1文を短くする

【守ること】
- 日付・曜日・連絡先・〔　〕の部分は変えない。新しい内容を足さない。
- 取引先向けの丁寧さは元の文面と同じに保つ（「いたします」を「します」に崩さない）。
- 直した文面のあとに、変えた箇所を箇条書きで3つまで示す。

【文面】
（ここに文例1などを貼る）
```

文例1を貼って試した1回目の出力から、変わった文と、変えた箇所の説明を抜き出しました。2回とも、日付と〔　〕は元の文面のままで、取引先向けの丁寧さも保たれていました。

```
平素より格別のご愛顧を賜り、厚く御礼申し上げます。
誠に勝手ながら、当社は下記の期間を年末年始休業といたします。
休業期間中のご連絡には、2027年1月5日（火）以降、順次対応いたします。
緊急のご用件は、〔緊急連絡先のメールアドレス〕までご連絡をお願いいたします。
ご不便をおかけいたしますが、何卒ご理解のほどお願い申し上げます。
本年も誠にありがとうございました。

（変えた箇所）
- 「弊社では」を「当社は」に、冒頭の「お引き立て」を「ご愛顧」に変えました。
- 「させていただきます」を「いたします」に変えました（2か所）。「いただいたご連絡につきましては」は「のご連絡には」に、「くださいますようお願い申し上げます」は「ご連絡をお願いいたします」に縮めました。
- 冒頭を「ご愛顧」にしたため、末尾の「格別のご愛顧を賜り」が重複します。そこで末尾は「本年も誠にありがとうございました。」に縮めました。
```

【守ること】を付けない最初の依頼文では、2回とも本文の日付から年が省かれました。「ご不便をおかけいたしますが」も、「ご不便をおかけしますが」に崩れています。年と曜日、取引先向けの丁寧さを保つ条件は、そのために足しています。

## 送る前に、曜日と年をカレンダーで確かめる

- 休業期間の初日と最終日の曜日を、カレンダーで確かめたか（12月と1月で年が変わる）
- 営業開始日が、休業の最終日の翌日になっているか
- 文例1〜4で、日付と曜日がすべて同じか
- 2026年と2027年を書き間違えていないか
- 会社名・担当者名・署名の〔　〕を、すべて書き換えたか
- 休み中の連絡先を書いた場合、アドレスや番号に誤りがないか
- 一斉送信の宛先はBCCに入れ、Toの欄を自社のアドレスにしたか
- 署名の会社名・部署・電話番号が最新か
- 自動返信の開始日と終了日を、休業期間に合わせたか
- 営業開始後に、Webサイトと署名の告知を外す日を決めたか

## 社名や連絡先は、〔　〕に置き換えてからAIに貼る

先に、勤務先のAI利用ルールを確かめます。そのうえで、次の情報はAIに入れません。

- 自社と取引先の会社名、担当者の氏名
- 電話番号・メールアドレス（緊急の連絡先を含む）
- 取引の内容や、社外にまだ出していない社内の事情

置き換えの例：「株式会社サンプル商事 営業部 見本一郎、緊急時は090-0000-0000」→「〔会社名〕〔部署名〕〔担当者名〕、緊急時は〔緊急連絡先〕」

置き換えのやり方は、別の記事「生成AIに入力してはいけない情報と、マスキングのやり方」で詳しく扱います。

## 社内への年末年始の連絡も作るなら

仕事納めの段取りや休み中の社内の連絡体制など、社内向けの文書は、980円の有料記事「総務文書30場面（年末年始〜年度末）」で扱います。源泉徴収票の配布や入社予定者への入社案内まで、12月〜4月の30場面のプロンプトと完成例を収めています。
