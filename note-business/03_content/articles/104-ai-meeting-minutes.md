会議の記録係を任され、手元の箇条書きメモから議事録を清書している事務・総務の方へ。この記事では、メモを配れる形の議事録にするプロンプトを含め、3本を全文で載せます。文字起こしから決定事項とToDoを抜き出す依頼文と、配る前の点検をさせる依頼文です。社内で使う前の確認点と、配る前のチェックリストもまとめました。架空の会議で実行し、AIがメモにないことを書き足した例と、その防ぎ方も示します。

## 結論：AIに任せるのは清書と整理、確かめるのは人

AIに任せるのは、メモの清書と、決定事項・ToDo・保留事項への整理です。何が決まったか、誰がいつまでにやるかを確かめるのは、記録係と司会です。

検証では、見出しだけを指定した依頼文で作った議事録に、メモにない記述が3か所入りました。「メモにないことは書かない」「期限はメモの言葉のまま」などの指示を足すと、0か所になりました。**AIの議事録は、配る前に元のメモと照らし合わせてください。**

【検証情報】検証日：2026-11-08／使ったツール：Claude（2026年11月時点）、Python 3（照合）
検証方法：架空の会議「備品購入ルールの見直し」（30分、参加者A〜D）で、3本のプロンプトを実行しました。入力はメモ約530字と、文字起こし約1,900字です。出力をメモと1行ずつ照合し、日付と曜日、入力にない数字をPythonで確かめています。

## 使う前に社内で確かめること

### 録音・文字起こし・AI利用の可否と、参加者への伝え方

AIで議事録を作る前に、次の5つを確かめます。

- □ 会議の内容をAIに入れてよいか（勤務先のAI利用ルール）
- □ 録音や文字起こしをしてよいか（社内ルールと、会議の主催者の方針）
- □ 録音・文字起こし・AIでの整理を、参加者に会議の前に伝えたか
- □ 社外の人が参加する会議か（取引先の情報が入るなら、より慎重に扱う）
- □ 議事録の保存場所と、配る範囲は決まっているか

録音や文字起こしの可否は、まず勤務先のルールと、参加者への説明で決めます。この記事では、法律上の判断はしません。迷うときは上長に確認してください。

この記事は、録音をしない職場を想定し、手元のメモから作る方法を中心にしています。文字起こしの道具の比較や紹介はしません。

### AIに入れない情報（社外秘・個人の評価・未発表の数字）

- 社外秘の内容：未発表の数字、取引の条件、交渉中の話
- 個人の評価や人事：評価、異動の予定、健康や家族の事情
- 参加者や取引先の名前：A・Bなどの記号か、役職に置き換える

メモを貼る前に、人名や社名を〔 〕の記号に置き換えます。手順と置換表のテンプレートは、次の記事にまとめています。

## 議事録の型（そのまま使える見出し）

```
議事録：（議題）
■日時：
■参加者：（役職か記号。例：A（総務課長・司会）、B（経理））
■目的：
■決定事項：
■ToDo（担当・期限）：
■保留事項：
■報告・共有：
■次回：
```

要点は、決定事項・ToDo・保留事項を分けることです。決まったこと、やること、まだ決まっていないことが混ざると、配った後に「決まったはず」の食い違いが起きやすくなります。

「報告・共有」は、検証の結果で足した見出しです。決定の印がない報告（例：締め日は変えない）の置き場がないと、AIがそれを決定事項に入れることがありました。

## プロンプト1：箇条書きメモから議事録を作る

```
次の会議メモを、社内に配る議事録に整えてください。

【見出し】日時／参加者／目的／決定事項／ToDo（担当・期限）／保留事項／報告・共有／次回
【守ること】
・メモに書かれていないこと（目的・理由・数字・期限・担当・方針）は書かない
・目的は、メモの議題と現状の言葉で書く
・決定事項には、メモで「決定」「合意」とあるものだけを入れる。それ以外の報告や発言は「報告・共有」に入れる
・期限はメモの言葉のまま書く（「来週中」を日付に直さない）
・参加者は、メモの記号と役職のまま書く。日付には、メモにある曜日をそのまま付ける
・最後に「メモから読み取れなかった点」を箇条書きで添える（なければ「なし」）

【メモ】
（ここにメモを貼る）
```

入力例（メモの抜粋。全文は約530字）です。

```
・5,000円以上（税込）の事前申請 → 決定。12/1（火）から
・消耗品（文房具・コピー用紙）は総務が月1回まとめて発注 → 決定
　発注日は未定。D案は毎月第2水曜
・今年度の備品予算の残りは約12万円（B）
・営業部の消耗品の使用量は、Cが来週中にまとめる
```

出力例（抜粋）です。

```
■決定事項
1. 1件5,000円以上（税込）の備品は、購入前に申請する。12月1日（火）から始める。
（中略）
5. 消耗品（文房具・コピー用紙）は、総務が月1回まとめて発注する。
■ToDo（担当・期限）
・C：営業部の消耗品の使用量をまとめる（来週中）
■保留事項
・消耗品の発注日（未定。D案は毎月第2水曜）
■報告・共有
・今年度の備品予算の残りは約12万円（B）
■メモから読み取れなかった点
・Cの「来週中」の具体的な日付
```

出力例はClaudeで生成。AIの出力は毎回少しずつ変わります。ChatGPTやGeminiでも同じ形で使える構成です（動作は未確認）。

最初は、見出しだけを指定して試しました。すると、目的に「経費管理の適正化を図る」、備考に「予算の範囲内で運用する」という、メモにない文が入りました。Cさんの期限「来週中」は「11月20日（金）」に書き換えられ、決定の印がない報告が決定事項に入りました。上の【守ること】は、これらを防ぐために足した指示です。

## プロンプト2：文字起こしから決定事項とToDoを抜き出す

オンライン会議の文字起こしなど、長い記録から要点を抜き出すときに使います。社内ルールで認められ、参加者に伝えてある場合だけにしてください。

```
次の会議の文字起こしから、決定事項・ToDo・保留事項・報告・共有を抜き出してください。

【守ること】
・決定事項は、その場で決まった内容だけにする。司会のまとめがあれば、それと照らし合わせる
・ToDoは「担当：内容（期限）」の形にする。期限は発言の言葉のまま書く。期限の発言がなければ「期限なし」と書く
・保留事項には、「まだ決まっていない」「考えさせて」「あとで決める」とされた内容を入れる
・各項目の最後に、根拠の発言を「（話者：発言の一部）」の形で添える
・議題と関係のない話は、最後に「議題外」として1行で書く
・文字起こしにないことは書かない

（ここに文字起こしを貼る）
```

入力例（文字起こしの抜粋。全文は約1,900字）です。

```
A：3,000円……いや、3,000円だと申請が多すぎますね。5,000円以上でどうでしょう。
B：税込みで5,000円以上、ですね。
（中略）
D：毎月第2水曜はどうでしょう。
A：うーん、締め日との関係もあるので、そこはもう少し考えさせてください。
```

出力例（抜粋）です。

```
■決定事項
1. 税込み5,000円以上（送料を含む支払いの合計）の備品は、購入前に申請する。12月1日から始める（A：税込み5,000円以上は事前申請…ということで決定にします／A：送料も入れた、支払いの合計で考えましょう）
（中略）
■保留事項
・消耗品の発注日（D案：毎月第2水曜）（A：そこはもう少し考えさせてください）
■議題外
・会議室のプロジェクターの不具合は、Dが業者に見てもらう予定（C・D）
```

根拠の発言が添えてあると、人が文字起こしと照らし合わせやすくなります。言い直し（3,000円→5,000円）も、正しく5,000円で抜き出されました。

最初の依頼文（「決定事項とToDoを抜き出して」だけ）では、保留の3件が抜けました。司会のまとめにない「締め日は従来どおり」「予算の範囲内で運用する」も、決定事項に入りました。議題外のプロジェクターの話は、ToDoに入っています。

## プロンプト3：配る前に抜けと食い違いを点検させる

```
元の記録と議事録の案を比べて、配る前の点検をしてください。

【点検すること】
1. 元の記録にない記述（目的・理由・数字・期限・担当・方針）
2. 元の記録にあるのに、議事録の案にない決定事項・ToDo・保留事項
3. 決定事項と、提案・報告の取り違え
4. 数字・日付・曜日の食い違い
5. ToDoの担当と期限の抜け
【出し方】
・食い違いごとに「該当箇所」「元の記録では」「直し方の案」を書く
・問題がない観点は「問題なし」と書く
・議事録の書き直しはしない

【元の記録】
（メモか文字起こしを貼る）
【議事録の案】
（議事録の案を貼る）
```

入力例は、メモと、最初の依頼文で作った議事録の案（メモにない記述が入った版）です。出力例（抜粋）を示します。

```
【1. 元の記録にない記述】
・該当箇所：目的「経費管理の適正化を図る」
　元の記録では：目的の記載はなく、議題（備品購入ルールの見直し）と現状（重複購入・領収書の紛失）のみ
　直し方の案：「備品購入ルールの見直し（現状：重複購入と領収書の紛失が多い）」のように、メモの言葉で書く
（中略）
【4. 数字・日付・曜日の食い違い】
・該当箇所：ToDo「C：営業部の消耗品の使用量をまとめる（期限：11月20日（金））」
　元の記録では：「来週中」
　直し方の案：「来週中」と書く。日付にする場合は、Cに確認してから
```

点検の依頼文は、目視で見つけた6か所をすべて挙げました。内訳は、メモにない文2、年の補足、項目案の抜け、決定の取り違え、期限の書き換えです。直した版の議事録は、5つの観点とも「問題なし」でした。

ただし、点検もAIの出力で、1回の結果では見落としがないとは言えません。最後は、次のチェックリストで人が確かめます。

## 配る前のチェックリスト

- □ 発言者：発言と担当者の名前（記号）が、メモと合っているか
- □ 決定と提案：決定事項に、提案や報告が混ざっていないか
- □ 数字：金額・件数・日付がメモと同じか（「約」が消えていないか）
- □ 期限：「来週中」などが、勝手に日付に直されていないか。曜日はカレンダーで確かめたか
- □ 担当：すべてのToDoに担当と期限があるか（ないものは「未定」と書いてあるか）
- □ メモにない文：目的・方針・まとめの文に、誰も言っていないことが入っていないか
- □ 記号と配る範囲：〔 〕の記号を元の名前に戻し、配る相手を確かめたか

## まとめ：メール・報告・依頼の頼み方は20場面のテンプレ集へ

議事録は、AIに清書と整理を任せ、決定・期限・担当を人が確かめると、配れる形になります。3本の依頼文は、メモと文字起こしのどちらにも使えます。

議事録のあとには、ToDoの依頼メールや報告が続きます。会議後の依頼や日報、トラブルの第一報など、事務の20場面の依頼文集を準備しています。公開後、ここにリンクを追記します。
