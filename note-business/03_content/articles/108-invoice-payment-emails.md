請求書の送付メールを毎月1通ずつ書き、入金がない取引先への連絡は、言い方に迷って後回しになっている。そんな経理・事務の方に向けて、請求の流れに沿ったメールの文例6つを、件名つきで載せます。送付・再送・訂正のお詫び・入金の確認2回・お礼までをそろえました。催促の前に自社側で確かめる6項目と、文面を自社用に整えるAIプロンプト2本も紹介します。

## 結論：催促の前に自社側を確かめ、段階ごとに文面を変える

入金がないときは、相手に連絡する前に、入金の記録・振込名義・請求書の中身・送付の記録を確かめます。行き違いや自社の誤りだったときに、相手を責める連絡をしないためです。

連絡は段階ごとに文面を変えます。1回目は状況とご予定を尋ね、2回目は回答の期限を示します。**どちらも、相手を責める言い方や、遅延損害金・法的な手続きには触れません。**

文例は、〔 〕の中を自社の内容に置き換えて使います。AIで整えるときは、入力にない約束や強い言い回しが足されていないかを確かめてください。検証では、最初の依頼文で「改めてお電話で確認します」という、入力にない約束が入りました。

【検証情報】検証日：2026-11-08／使ったツール：Claude（2026年11月時点）、Python 3（照合）
検証方法：文例6つの日付と曜日、金額（税抜×1.1）、字数をPythonで照合しました。プロンプト2本は架空の取引先・金額・日付で実行し、入力にない約束や強い表現が足されていないかを確かめています。

## 文例1：請求書の送付（PDF添付）

毎月の送付メールです。請求書番号・金額・期日を本文にも書いておくと、相手が添付を開く前に確認できます。

```
件名：10月分ご請求書送付のご案内（〔自社名〕）

〔取引先名〕
〔ご担当者名〕様

いつもお世話になっております。〔自社名〕の〔氏名〕です。
10月分のご請求書をPDFにてお送りいたします。

・請求書番号：〔INV-2610-012〕
・ご請求金額：165,000円（税込）
・お支払期日：2026年11月30日（月）

ご査収のほど、よろしくお願いいたします。
PDFが開けない場合や、内容にご不明な点がございましたら、お知らせください。

（署名）
```

## 文例2：請求書の再送（届いていないと言われたとき）

相手から「届いていない」と連絡があったときの再送です。原因が分からないうちは、どちらの不手際とも書かず、同じPDFを送り直します。送付先の変更がないかも確かめます。

```
件名：【再送】10月分ご請求書の送付について（〔自社名〕）

〔取引先名〕
〔ご担当者名〕様

いつもお世話になっております。〔自社名〕の〔氏名〕です。
10月分のご請求書が届いていないとのご連絡をいただき、ありがとうございます。
10月30日（金）にお送りしたものと同じPDFを、あらためて添付いたします。

・請求書番号：〔INV-2610-012〕
・ご請求金額：165,000円（税込）
・お支払期日：2026年11月30日（月）

お手数をおかけしますが、ご確認をお願いいたします。
送付先のアドレスに変更がございましたら、お知らせいただけますと幸いです。

（署名）
```

## 文例3：請求書の訂正・再発行のお詫び

自社の請求書に誤りがあったときです。訂正前と訂正後の金額を並べ、支払期日が変わるかどうかを書きます。訂正の方法（差し替えるか、別に発行するか）は、社内の経理のルールに合わせてください。

```
件名：10月分ご請求書の訂正と再発行のお詫び（〔自社名〕）

〔取引先名〕
〔ご担当者名〕様

いつもお世話になっております。〔自社名〕の〔氏名〕です。
10月30日（金）にお送りした10月分のご請求書に、数量の誤りがございました。
大変申し訳ございません。訂正した請求書を添付いたします。

・訂正前のご請求金額：176,000円（税込）
・訂正後のご請求金額：165,000円（税込）
・請求書番号：〔INV-2610-012〕（訂正版）
・お支払期日：2026年11月30日（月）（変更はございません）

お手数ですが、訂正前の請求書は破棄していただけますでしょうか。
今後は、送付前の確認を徹底いたします。

（署名）
```

## 入金がないときに、先に自社側で確かめること

期日を過ぎても入金が確認できないときは、連絡の前に次の6つを確かめます。

- □ 入金の記録：期日の翌日以降の入金明細まで見たか。ほかの請求とまとめて振り込まれていないか
- □ 振込名義の違い：社名と違う名義（親会社、略称、カナの表記）で入っていないか
- □ 請求書の中身：宛名・金額・支払期日・振込先に誤りがないか。訂正前の請求書で払われていないか
- □ 送付の記録：送った日、送り先のアドレス、届いたことが分かるやり取りがあるか
- □ 相手からの連絡：支払日の変更や問い合わせを見落としていないか（迷惑メール、ほかの担当あても見る）
- □ 社内の事情：営業の担当など、相手と話している人が事情を聞いていないか

自社側の誤りが分かったときは、文例2か文例3で連絡します。長く入金がない場合や、相手と連絡が取れない場合は、上長や顧問の専門家に相談してください。この記事では、督促状などの法的な対応は扱いません。

## 文例4：入金予定の確認（1回目）

1回目は、入金を確認できていない事実を伝え、状況とご予定を尋ねるだけにします。行き違いの可能性に触れ、請求書の再送を申し出ます。

```
件名：10月分ご請求のお支払い状況のご確認（〔自社名〕）

〔取引先名〕
〔ご担当者名〕様

いつもお世話になっております。〔自社名〕の〔氏名〕です。
10月分のご請求（請求書番号：〔INV-2610-012〕、165,000円）について、
11月30日（月）のお支払期日の時点で、ご入金を確認できておりませんでした。

行き違いでしたら、大変失礼いたしました。
お手数ですが、お支払いの状況とご予定をお知らせいただけますでしょうか。
請求書がお手元にない場合は、すぐに再送いたします。

どうぞよろしくお願いいたします。

（署名）
```

## 文例5：2回目の確認（回答の期限を示す）

1回目に返信がないときです。回答の期限を日付と曜日で示し、期限を設ける理由（経理の締めなど）を1つ添えます。支払い済みの場合への一言も残します。

```
件名：【再度のご確認】10月分ご請求のお支払いについて（〔自社名〕）

〔取引先名〕
〔ご担当者名〕様

いつもお世話になっております。〔自社名〕の〔氏名〕です。
12月2日（水）にお送りした、10月分のご請求（165,000円）のお支払いについてのご連絡です。
本日12月9日（水）の時点でも、ご入金とご返信を確認できておりません。

経理の締めの都合がございますので、
12月11日（金）までに、お支払いのご予定をお知らせいただけますでしょうか。
すでにお手続きいただいている場合は、お振込日を教えていただけますと幸いです。

お忙しいところ恐れ入りますが、よろしくお願いいたします。

（署名）
```

## 文例6：入金確認のお礼

入金を確認したら、短くお礼を送ります。確認の連絡を何度かした相手には、手間をかけたことへの一言を添えます。

```
件名：ご入金確認のお礼（〔自社名〕）

〔取引先名〕
〔ご担当者名〕様

いつもお世話になっております。〔自社名〕の〔氏名〕です。
10月分のご請求（請求書番号：〔INV-2610-012〕）について、
12月14日（月）に、165,000円のご入金を確認いたしました。

このたびは、お支払いの状況について何度もご連絡を差し上げ、
お手数をおかけいたしました。ご対応いただき、ありがとうございました。

今後とも、どうぞよろしくお願いいたします。

（署名）
```

文例の日付は2026年の例です。使うときは、日付と曜日をカレンダーで確かめてください。

## AIで自社用に整えるプロンプト

AIに貼る前に、取引先名と担当者名を〔取引先A〕〔担当B〕のような記号に置き換えます。金額や請求書番号を入れてよいかは、勤務先のAI利用ルールで確かめてください。迷うときは〔金額〕のまま作らせ、送る前に請求書を見ながら入れます。

置き換えの手順は、次の記事にまとめています。
「生成AIに入力してはいけない情報と、マスキングのやり方」（［リンク：106の記事］）

### 条件を入れて文面を作る

```
請求に関するメールの下書きを作ってください。

【段階】（送付／再送／訂正のお詫び／入金予定の確認／2回目の確認／入金のお礼 から1つ）
【相手】（例：〔取引先A〕の〔担当B〕様）
【請求書】（何月分／請求書番号／金額／お支払期日と曜日）
【これまでの経緯】（送った日、期日、相手からの連絡の有無）
【伝えたいこと】（お願いしたいこと、回答の期限）
【差出人】（例：〔自社〕の〔氏名〕）

【守ること】
・件名をつけ、本文は300字以内にする
・【 】に書いたことだけを使い、日付・金額・経緯・約束を足さない
・相手を責める言い方をしない。遅延損害金・法的な手続き・取引の見直し・支払条件の変更には触れない
・〔 〕の記号は変えずにそのまま残す
・入金の確認では、行き違いで支払い済みの場合への一言を入れる
```

入力例（空欄に入れた内容）です。

```
【段階】2回目の確認（回答の期限を示す）
【相手】〔取引先A〕の〔担当B〕様
【請求書】10月分／請求書番号〔INV-2610-012〕／165,000円（税込）／お支払期日 2026年11月30日（月）
【これまでの経緯】12月2日（水）に1回目の確認メールを送ったが、返信も入金もない
【伝えたいこと】12月11日（金）までに、お支払いの予定を知らせてほしい
【差出人】〔自社〕の〔氏名〕
```

出力例です。

```
件名：【再度のご確認】10月分ご請求のお支払いについて（〔自社〕）

〔取引先A〕
〔担当B〕様

いつもお世話になっております。〔自社〕の〔氏名〕です。

12月2日（水）に、10月分のご請求（請求書番号：〔INV-2610-012〕、165,000円（税込））についてご連絡いたしましたが、現時点でご入金とご返信を確認できておりません。お支払期日は2026年11月30日（月）でした。

お手数をおかけしますが、12月11日（金）までに、お支払いのご予定をお知らせいただけますでしょうか。

行き違いでお支払いがお済みの場合は、ご容赦ください。
どうぞよろしくお願いいたします。

〔自社〕〔氏名〕
```

出力例はClaudeで生成。AIの出力は毎回少しずつ変わります。ChatGPTやGeminiでも同じ形で使える構成です（動作は未確認）。

【守ること】がない版で試すと、入力にない約束が足されました。

- 2回目の確認：「改めてお電話にてご確認させていただきます」
- 訂正のお詫び：「確認体制を見直し、再発防止に努めてまいります」

直した版では、どちらも足されませんでした。

再発防止の一言を入れるかどうかは、自社で決めて【伝えたいこと】に書きます。遅延損害金や法的措置に触れる表現は、この依頼文では出ませんでした。

### 相手との関係と段階に合わせて言い回しを直す

```
次のメールの言い回しを、相手との関係と段階に合わせて直してください。

【相手との関係】（例：取引3年目。これまでは期日どおりに入金があった）
【段階】（例：2回目の確認）
【直したい方向】（例：きっぱりと。ただし丁寧さは保つ）
【守ること】
・金額・日付・請求書番号・お願いごとは変えない
・強さは言い回しで調整する。新しい条件や結果（取引の見直し、法的な手続き、遅延損害金、支払条件の変更）は足さない
・入力にない約束や、急がせる言葉（【至急】など）を足さない
・〔 〕の記号はそのまま残す
・直した文面のあとに、変えた箇所を3つまで箇条書きで示す

【メール】
（ここに貼る）
```

入力例は、文例5を記号に置き換えたものです。関係と方向は、上の（例）のとおりにしました。出力例（抜粋）です。

```
経理の締めの都合がございますので、12月11日（金）までに、お支払いのご予定をお知らせくださいますよう、お願いいたします。
すでにお手続きいただいている場合は、お振込日をお知らせください。
（中略）
変えた箇所
・お願いの文を「お知らせいただけますでしょうか」から「お知らせくださいますよう、お願いいたします」にし、はっきり頼む形にした
・最初の文を「〜のお支払いの件です」と短くし、用件を先に出した
・結びの「お忙しいところ恐れ入りますが」を省いた
```

「もう少しきっぱりした言い方に直して」とだけ頼むと、次の一文が入りました。
「今後のお取引について社内で検討させていただくことになります」
件名には「【至急】」が付き、冒頭のあいさつも消えています。取引の見直しは入力にない条件で、相手との関係を損ねるおそれがあります。上の依頼文は、こうした文を足さないように指示しています。

## まとめ：送付メールを毎月自動で下書きするには

請求のメールは、送付・再送・訂正・確認2回・お礼の6段階で文面を変えます。催促の前に自社側を確かめ、AIで整えた文面は、足された約束や強い言い回しがないかを読み直してから送ります。

毎月の送付メールは、Googleスプレッドシートの請求データから自動で下書きする方法もあります。PDFの作成からメールの下書きまでを、まとめて行う仕組みです。仕組みの全体像の記事と、Google Apps Scriptで作る業務パックを準備しています。お詫びやお断りなど、ほかの言いにくいメールの依頼文は、事務の依頼文20場面のテンプレ集にまとめる予定です。公開後、ここに各記事へのリンクを追記します。
