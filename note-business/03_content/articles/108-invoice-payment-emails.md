請求書の送付メールを毎月1通ずつ書き、入金がない取引先への連絡は、言い方に迷って後回しになっている。そんな経理・事務の方に向けて、請求の流れに沿ったメールの文例6つを、件名つきで載せます。催促の前に自社側で確かめる7項目と、文面を自社用に整えるAIプロンプト2本も紹介します。

## 結論：催促の前に自社側を確かめ、段階ごとに文面を変える

入金がないときは、相手に連絡する前に、入金の記録・振込名義・請求書の中身・送付の記録を確かめます。行き違いや自社の誤りだったときに、相手を責める連絡をしないためです。

連絡は段階ごとに文面を変えます。1回目は状況とご予定を尋ね、2回目は回答の期限を示します。**どちらも、相手を責める言い方や、遅延損害金・法的な手続きには触れません。**

AIで整えるときは、入力にない約束が足されていないかを確かめてください。検証では、条件を付けない依頼文で「改めてお電話にてご確認させていただきます」などの一文が、2回とも足されました。

【検証情報】検証日：2026-11-08／使ったツール：Claude（2026年11月時点）、Python 3（照合）
検証方法：文例6つの日付と曜日、金額（税抜×1.1）、字数をPythonで照合しました。プロンプト2本は、架空の取引先・金額・日付で、新しい会話で各2回実行しています。

## 文例1：請求書の送付（PDF添付）

毎月の送付メールです。請求書番号・金額・期日を本文にも書いておくと、相手が添付を開く前に確認できます。

```
件名：10月分ご請求書送付のご案内（〔自社名〕）

〔取引先名〕
〔ご担当者名〕様

いつもお世話になっております。〔自社名〕の〔氏名〕です。
10月分のご請求書をPDFにてお送りいたします。

・請求書番号：〔INV-2610-012〕
・ご請求金額：165,000円（税込）
・お支払期日：2026年11月30日（月）

ご査収のほど、よろしくお願いいたします。
PDFが開けない場合や、内容にご不明な点がございましたら、お知らせください。

（署名）
```

## 文例2：請求書の再送（届いていないと言われたとき）

相手から「届いていない」と連絡があったときの再送です。原因が分からないうちは、どちらの不手際とも書かず、同じPDFを送り直します。

```
件名：【再送】10月分ご請求書の送付について（〔自社名〕）

〔取引先名〕
〔ご担当者名〕様

いつもお世話になっております。〔自社名〕の〔氏名〕です。
10月分のご請求書が届いていないとのご連絡をいただき、ありがとうございます。
10月30日（金）にお送りしたものと同じPDFを、あらためて添付いたします。

・請求書番号：〔INV-2610-012〕
・ご請求金額：165,000円（税込）
・お支払期日：2026年11月30日（月）

お手数をおかけしますが、ご確認をお願いいたします。
送付先のアドレスに変更がございましたら、お知らせいただけますと幸いです。

（署名）
```

## 文例3：請求書の訂正・再発行のお詫び

自社の請求書に誤りがあったときです。訂正前と訂正後の金額を並べ、支払期日が変わるかどうかを書きます。訂正の方法と、適格請求書（インボイス）の記載事項を訂正するときの書き方は、社内の経理責任者に確かめてください。最後の1文は、社内で再発防止の対応を決めた場合だけ残します。

```
件名：10月分ご請求書の訂正と再発行のお詫び（〔自社名〕）

〔取引先名〕
〔ご担当者名〕様

いつもお世話になっております。〔自社名〕の〔氏名〕です。
10月30日（金）にお送りした10月分のご請求書に、数量の誤りがございました。
大変申し訳ございません。訂正した請求書を添付いたします。

・訂正前のご請求金額：176,000円（税込）
・訂正後のご請求金額：165,000円（税込）
・請求書番号：〔INV-2610-012〕（訂正版）
・お支払期日：2026年11月30日（月）（変更はございません）

訂正前の請求書は、お手数ですが訂正版に差し替えてご処理いただけますでしょうか。
今後は、送付前の確認を徹底いたします。

（署名）
```

## 入金がないときに、先に自社側で確かめること

期日を過ぎても入金が確認できないときは、連絡の前に次の7つを確かめます。

- □ 入金の記録：期日の翌日以降の入金明細まで見たか。ほかの請求とまとめて振り込まれていないか
- □ 入金額の違い：振込手数料の分だけ少ない、一部だけ入っている、などの差がないか
- □ 振込名義の違い：社名と違う名義（親会社、略称、カナの表記）で入っていないか
- □ 請求書の中身：宛名・金額・支払期日・振込先に誤りがないか。訂正前の請求書で払われていないか
- □ 送付の記録：送った日、送り先のアドレス、届いたことが分かるやり取りがあるか
- □ 相手からの連絡：支払日の変更や問い合わせを見落としていないか（迷惑メール、ほかの担当あても見る）
- □ 社内の事情：営業の担当など、相手と話している人が事情を聞いていないか

自社側の誤りが分かったときは、文例2か文例3で連絡します。長く入金がない場合や連絡が取れない場合は、上長や顧問の専門家に相談してください。この記事では、督促状などの法的な対応は扱いません。

## 文例4：入金予定の確認（1回目）

1回目は、入金を確認できていない事実を伝え、状況とご予定を尋ねるだけにします。行き違いの可能性に触れ、請求書の再送を申し出ます。

```
件名：10月分ご請求のお支払い状況のご確認（〔自社名〕）

〔取引先名〕
〔ご担当者名〕様

いつもお世話になっております。〔自社名〕の〔氏名〕です。
10月分のご請求（請求書番号：〔INV-2610-012〕、165,000円）について、
11月30日（月）のお支払期日の時点で、ご入金を確認できておりませんでした。

行き違いでしたら、大変失礼いたしました。
お手数ですが、お支払いの状況とご予定をお知らせいただけますでしょうか。
請求書がお手元にない場合は、すぐに再送いたします。

どうぞよろしくお願いいたします。

（署名）
```

## 文例5：2回目の確認（回答の期限を示す）

1回目に返信がないときです。回答の期限を日付と曜日で示し、期限を設ける理由（経理の締めなど）を1つ添えます。支払い済みの場合への一言も残します。

```
件名：【再度のご確認】10月分ご請求のお支払いについて（〔自社名〕）

〔取引先名〕
〔ご担当者名〕様

いつもお世話になっております。〔自社名〕の〔氏名〕です。
12月2日（水）に、10月分のご請求（請求書番号：〔INV-2610-012〕、165,000円）のお支払いについてご連絡いたしましたが、
本日12月9日（水）の時点でも、ご入金とご返信を確認できておりません。

経理の締めの都合がございますので、
12月11日（金）までに、お支払いのご予定をお知らせいただけますでしょうか。
すでにお手続きいただいている場合は、お振込日を教えていただけますと幸いです。

お忙しいところ恐れ入りますが、よろしくお願いいたします。

（署名）
```

## 文例6：入金確認のお礼

入金を確認したら、短くお礼を送ります。確認の連絡を何度かした相手には、手間をかけたことへの一言を添えます。

```
件名：ご入金確認のお礼（〔自社名〕）

〔取引先名〕
〔ご担当者名〕様

いつもお世話になっております。〔自社名〕の〔氏名〕です。
10月分のご請求（請求書番号：〔INV-2610-012〕）について、
12月14日（月）に、165,000円のご入金を確認いたしました。

このたびは、お支払いの状況について何度もご連絡を差し上げ、
お手数をおかけいたしました。ご対応いただき、ありがとうございました。

今後とも、どうぞよろしくお願いいたします。

（署名）
```

文例の日付は2026年の例です。使うときは、日付と曜日をカレンダーで確かめてください。

## AIで自社用に整えるプロンプト

AIには、次の情報を入れません。

- 取引先名・担当者名：〔取引先A〕〔担当B〕のような記号に置き換える
- 口座番号や、交渉中の支払条件：入れない（文面には〔振込先〕と書けば足りる）
- 金額・請求書番号：入れてよいかは勤務先のAI利用ルールで確かめる。迷うときは〔金額〕のまま作らせる

置き換えの例：「株式会社サンプル商事　山田様」→「〔取引先A〕　〔担当B〕様」。手順は次の記事にまとめています。
「生成AIに入力してはいけない情報と、マスキングのやり方」（【オーナー確認待ち：106の記事URL】）

### 条件を入れて文面を作る

```
請求に関するメールの下書きを作ってください。

【段階】（送付／再送／訂正のお詫び／入金予定の確認／2回目の確認／入金のお礼 から1つ）
【相手】（例：〔取引先A〕の〔担当B〕様）
【請求書】（何月分／請求書番号／金額／お支払期日と曜日）
【これまでの経緯】（送った日、期日、相手からの連絡の有無）
【伝えたいこと】（お願いしたいこと、回答の期限）
【差出人】（例：〔自社〕の〔氏名〕）

【守ること】
・件名をつけ、本文は300字以内にする
・【 】に書いたことだけを使い、日付・金額・経緯・約束を足さない
・相手を責める言い方をしない。支払いの遅れに対する損害金・法的な手続き・取引の見直し・支払条件の変更には触れない
・〔 〕の記号は変えずにそのまま残す
・【段階】が入金予定の確認か2回目の確認のときは、行き違いで支払い済みの場合への一言を入れる
・出力は件名と本文だけにする（説明やあとがきは付けない）
```

入力例（空欄に入れた内容）です。

```
【段階】訂正のお詫び
【相手】〔取引先A〕の〔担当B〕様
【請求書】10月分／請求書番号〔INV-2610-012〕／訂正前 176,000円（税込）→ 訂正後 165,000円（税込）／お支払期日 2026年11月30日（月）（変更なし）
【これまでの経緯】10月30日（金）に送った請求書の数量に誤りがあった。訂正した請求書を添付する
【伝えたいこと】訂正前の請求書は、訂正版に差し替えて処理してほしい
【差出人】〔自社〕の〔氏名〕
```

出力例（1回目の実行）です。

```
件名：【訂正】10月分ご請求書（請求書番号〔INV-2610-012〕）のお詫び

〔取引先A〕
〔担当B〕様

いつもお世話になっております。〔自社〕の〔氏名〕です。

10月30日（金）にお送りした10月分の請求書（請求書番号〔INV-2610-012〕）で、数量に誤りがございました。ご迷惑をおかけし、誠に申し訳ございません。

訂正した請求書を添付いたしましたので、ご確認をお願いいたします。
・訂正前：176,000円（税込）
・訂正後：165,000円（税込）
・お支払期日：2026年11月30日（月）（変更なし）

お手数をおかけしますが、訂正前の請求書は、訂正版に差し替えてご処理いただけますようお願い申し上げます。

〔自社〕
〔氏名〕
```

【守ること】がない版では、2回とも入力にない約束と依頼（「送付前の確認を徹底してまいります」「破棄していただき」）が足されました。文面のあとの説明や、訂正への「行き違い」の一言も出たため、最後の2行を足しています。

出力例はClaudeで生成。AIの出力は毎回少しずつ変わります。Claudeで検証しました。ChatGPT・Gemini・Copilotでも同じ依頼文を使えますが、出力は異なります（未検証）。

### 相手との関係と段階に合わせて言い回しを直す

```
次のメールの言い回しを、相手との関係と段階に合わせて直してください。

【相手との関係】（例：取引3年目。これまでは期日どおりに入金があった）
【段階】（例：2回目の確認）
【直したい方向】（例：きっぱりと。ただし丁寧さは保つ）
【守ること】
・金額・日付・請求書番号・お願いごとは変えない
・強さは言い回しで調整する。新しい条件や結果（取引の見直し、法的な手続き、遅れに対する損害金、支払条件の変更）は足さない
・入力にない約束を足さない。件名や本文に、急がせる言葉を足さない
・〔 〕の記号はそのまま残す
・直した文面のあとに、変えた箇所を3つまで箇条書きで示す

【メール】
（ここに貼る）
```

入力例は、文例5を記号に置き換えたものです。関係と方向は、上の（例）のとおりにしました。出力例（2回目の実行。抜粋）です。

```
12月2日（水）に、10月分のご請求（請求書番号：〔INV-2610-012〕、165,000円）のお支払いについてご連絡いたしましたが、
本日12月9日（水）の時点で、ご入金とご返信のいずれもまだ確認できておりません。
これまで期日どおりにお支払いいただいておりましたので、行き違いがないか確かめたく、改めてご連絡いたしました。
（中略）
12月11日（金）までに、お支払いのご予定をお知らせくださいますようお願いいたします。
（以下、結びと「変えた箇所」3つが続く）
```

「もう少しきっぱりした言い方に直して」とだけ頼むと、2回とも「期日までにご連絡をいただけない場合は、改めてお電話にてご確認させていただきます」が足されました。入力にない次の対応を約束する文なので、上の依頼文では足さないように指示しています。

## まとめ：送付メールを毎月自動で下書きするには

請求のメールは、送付・再送・訂正・確認2回・お礼の6段階で文面を変えます。AIで整えた文面は、足された約束や強い言い回しがないかを読み直してから送ります。

毎月の送付メールは、Googleスプレッドシートの請求データから、PDFの作成とメールの下書きまでを自動にする方法もあります。仕組みの全体像の記事と、Google Apps Scriptで作る「GAS請求書パック」を準備しています（Googleスプレッドシートが前提で、Excelでは動きません）。お詫びやお断りなどの依頼文は「事務のAI依頼文20場面」にまとめます。
