## 限界

- 各プロンプトとも1回ずつの実行。AIの出力は毎回少しずつ変わる
- 作成と点検を同じモデル（ライターA）が行ったため、点検の独立性には限界がある。記事では「点検の依頼文に頼らず、配る前のチェックリストを人が確かめる」と書いた
- 録音・文字起こし・AI利用の可否は、法的な判断をせず、勤務先のルールと参加者への事前の説明を確認事項にした。文字起こしツールの比較・推薦はしていない（企画書 §5）
