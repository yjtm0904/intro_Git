【ルール】
S1 1文目は場面から書く。「〜向けの記事です」「この記事では〜を紹介します」と記事が自分を説明しない
S2 見出しは結論の文にする。「結論：」「まとめ：」のラベルと、全記事共通の骨組みを使わない

S5 丸かっこの補足は1段落に1つまで。曜日・関数の引数を除き、1,000字あたり4つ以下を目安にする
S6 範囲の宣言（「この記事では〜しません」）は「扱わないこと」の1か所に集める
S7 「ないこと」の宣言を「あること」の事実に置き換える
S8 「〜ことがあります」「可能性があります」は、検証で起きた回数に置き換える（例：「16回中12回で」）
S9 1文は60字以内。80字を超えたら切る（URLは数えない）
S10 見出しの丸かっこ補足は記事全体で2つまで
S11 判断の足跡（試したこと→起きたこと→変えたこと）を前半に1つ置く。検証ログにある事実だけ
S12 検証情報と開示は「AIが何を作り、人が何をどう確かめたか」を具体的に書く
S13 定番のAI表現（「〜することが重要です」「いかがでしたか」「〜と言えるでしょう」などの決まり文句）を使わない
S14 同じ文末は3文まで。4文目は形を変える
S15 文例・プロンプト（コードブロック）は、実務の文書として自然かどうかで判断する。過剰な敬語と念押しだけを直す

# 議事録をAIで作る手順と、社内で使う前の確認点｜メモから作るプロンプト3つ

会議の記録係を任され、手元の箇条書きメモから議事録を清書している事務・総務の方へ。メモを配れる形にする依頼文を含め、プロンプト3本と配る前のチェックリストを載せます。架空の会議で、AIがメモにないことを書き足した例と、その防ぎ方も示します。

## 結論：AIに任せるのは清書と整理、確かめるのは人

AIに任せるのは、メモの清書と、決定事項・ToDo・保留事項への整理です。何が決まったか、誰がいつまでにやるかを確かめるのは、記録係と司会です。

見出しだけを指定した依頼文で2回作ると、メモと食い違う箇所が8か所と6か所出ました。「メモにないことは書かない」「期限はメモの言葉のまま」などの指示を足すと、2回とも1か所以下に減っています。**AIの議事録は、配る前に元のメモと照らし合わせてください。**

【検証情報】検証日：2026-11-08／使ったツール：Claude（2026年11月時点）、Python 3（照合）
検証方法：架空の会議「備品購入ルールの見直し」（参加者A〜D）で、3本のプロンプトを新しい会話で各2回実行しました。入力はメモ約530字と文字起こし約1,900字です。出力をメモと1行ずつ照合し、日付と曜日、入力にない数字をPythonで確かめています。

## 使う前に社内で確かめること

### 録音・文字起こし・AI利用の可否と、参加者への伝え方

AIで議事録を作る前に、次の5つを確かめます。ルールが分からないときは、上長か情報システムの担当に、この5つを聞いてください。

- □ 会議の内容をAIに入れてよいか（勤務先のAI利用ルール）
- □ 録音や文字起こしをしてよいか（社内ルールと、会議の主催者の方針）
- □ 録音・文字起こし・AIでの整理を、参加者に会議の前に伝えたか
- □ 社外の人が参加する会議か（取引先の情報が入るなら、より慎重に扱う）
- □ 議事録の保存場所と、配る範囲は決まっているか

録音や文字起こしの可否は、勤務先のルールと参加者への説明で決めます。この記事では、法律上の判断はしません。

この記事は、録音をしない職場を想定し、手元のメモから作る方法を中心にしています。文字起こしの道具の比較や紹介はしません。会議ツールのAI要約を使う場合も、プロンプト3と配る前のチェックリストは使えます。

### AIに入れない情報（社外秘・個人の評価・未発表の数字）

- 社外秘の内容：未発表の数字、取引の条件、交渉中の話
- 個人の評価や人事：評価、異動の予定、健康や家族の事情
- 参加者や取引先の名前：A・Bなどの記号か役職に置き換える

置き換えの例：「山田課長（営業部）が来週中にまとめる」→「C（営業）が来週中にまとめる」。手順は次の記事にまとめています。
「生成AIに入力してはいけない情報と、マスキングのやり方」（【オーナー確認待ち：106の記事URL】）

## 議事録の型（そのまま使える見出し）

```
議事録：（議題）
■日時：
■参加者：（役職か記号。例：A（総務課長・司会）、B（経理））
■目的：
■決定事項：
■ToDo（担当・期限）：
■保留事項：
■報告・共有：
■次回：
```

要点は、決定事項・ToDo・保留事項を分けることです。決まったこと、やること、まだ決まっていないことが混ざると、配った後に「決まったはず」の食い違いが起きやすくなります。

「報告・共有」は、検証の結果で足した見出しです。決定の印がない報告（例：締め日は変えない）の置き場がないと、AIがそれを決定事項に入れることがありました。

## プロンプト1：箇条書きメモから議事録を作る

```

【守ること】
・メモに書かれていないこと（目的・理由・数字・期限・担当・方針）は書かない
・目的は、メモの議題と現状の言葉で書く
・決定事項には、メモで「決定」「合意」とあるものだけを入れる。それ以外の報告や発言は「報告・共有」に入れる

（ここにメモを貼る）
```

## プロンプト2：文字起こしから決定事項とToDoを抜き出す

オンライン会議の文字起こしなど、長い記録から要点を抜き出すときに使います。社内ルールで認められ、参加者に伝えてある場合だけにしてください。

```
次の会議の文字起こしから、決定事項・ToDo・保留事項・報告・共有を抜き出してください。

【守ること】
・決定事項は、その場で決まった内容だけにする。司会のまとめがあれば、それと照らし合わせる
・ToDoは「担当：内容（期限）」の形にする。期限は発言の言葉のまま書く。期限の発言がなければ「期限なし」と書く
・保留事項には、「まだ決まっていない」「考えさせて」「あとで決める」とされた内容を入れる
・各項目の最後に、根拠の発言を「（話者：発言の一部）」の形で添える
・議題と関係のない話は、最後に「議題外」として1行で書く
・文字起こしにないことは書かない

（ここに文字起こしを貼る）
```

入力例（文字起こしの抜粋。全文は約1,900字）です。

```
B：税込みで5,000円以上、ですね。
（中略）
D：毎月第2水曜はどうでしょう。
A：うーん、締め日との関係もあるので、そこはもう少し考えさせてください。
```

## プロンプト3：配る前に抜けと食い違いを点検させる

```
元の記録と議事録の案を比べて、配る前の点検をしてください。

【点検すること】
1. 元の記録にない記述（目的・理由・数字・期限・担当・方針）
2. 元の記録にあるのに、議事録の案にない決定事項・ToDo・保留事項
3. 決定事項と、提案・報告の取り違え
4. 数字・日付・曜日の食い違い
5. ToDoの担当と期限の抜け
【出し方】
・食い違いごとに「該当箇所」「元の記録では」「直し方の案」を書く
・問題がない観点は「問題なし」と書く
・議事録の書き直しはしない

【元の記録】
（メモか文字起こしを貼る）
【議事録の案】
（議事録の案を貼る）
```

入力例は、メモと、最初の依頼文で作った議事録（食い違い8か所）です。出力例（1回目の実行。抜粋）を示します。

```
## 1. 元の記録にない記述
**(1) 目的**
- **該当箇所**：「## 目的　備品購入ルールを見直し、重複購入と領収書紛失を減らす。」
- **元の記録では**：会議名「備品購入ルールの見直し」だけです。「重複購入と領収書紛失を減らす」という目的は書かれていません。重複購入と紛失は、B の現状報告として出ているだけです。
- **直し方の案**：見出しを「議題」にして、会議名だけを書きます。目的として残す場合は、A に確認してから書きます。
**(2) 消耗品の範囲「など」**
- **該当箇所**：決定事項4「文房具・コピー用紙**など**の消耗品は」
- **元の記録では**：「消耗品（文房具・コピー用紙）」です。「など」はありません。
```

点検の依頼文は、2回とも7か所以上を挙げました。直した版の議事録でも、「1件」と「税込」を別の行から合わせて書いた箇所などを指摘しています。

ただし、点検もAIの出力で、1回の結果では見落としがないとは言えません。最後は、次のチェックリストで人が確かめます。

## 配る前のチェックリスト

- □ 発言者：発言と担当者の名前（記号）が、メモと合っているか
- □ 決定と提案：決定事項に、提案や報告が混ざっていないか
- □ 数字：金額・件数・日付がメモと同じか（「約」が消えていないか）
- □ 期限：「来週中」などが、勝手に日付に直されていないか。曜日はカレンダーで確かめたか
- □ 担当：すべてのToDoに担当と期限があるか（ないものは「未定」と書いてあるか）
- □ メモにない文：目的・方針・まとめの文に、誰も言っていないことが入っていないか
- □ 言い換え：「など」を足したり、言葉を言い換えたりして、意味が広がっていないか
- □ 仕上げ：AIが付けた確認のメモを消し、記号を元の名前に戻して、配る相手を確かめたか

## まとめ：メール・報告・依頼の頼み方は20場面のテンプレ集へ

議事録は、AIに清書と整理を任せ、決定・期限・担当を人が確かめると、配れる形になります。3本の依頼文は、メモと文字起こしのどちらにも使えます。

議事録のあとには、ToDoの依頼メッセージや日報・週報、電話の伝言メモが続きます。これらの依頼文は、有料の「事務のAI依頼文20場面」に収録しています。
