# B2に入れる数式（Excel・スプレッドシート共通）

Microsoft 365のExcelでもGoogleスプレッドシートでも、同じ数式が使えます。

マスタが別シート（シート名を「取引先マスタ」とした場合）：

```
=XLOOKUP(A2,'取引先マスタ'!$D$2:$D$11,'取引先マスタ'!$A$2:$A$11,"未登録")
```

マスタが同じシートにある場合：

```
=XLOOKUP(A2,$D$2:$D$11,$A$2:$A$11,"未登録")
```

※ シート名が違う場合は、`'取引先マスタ'` の部分を実際のシート名に変えてください。

## 数式の読み方

`XLOOKUP(探す値, 探す範囲, 返す範囲, 見つからないとき)`

| 部分 | 意味 |
|---|---|
| `A2` | 探すメールアドレス |
| `$D$2:$D$11` | マスタのメール列から探す |
| `$A$2:$A$11` | 見つかった行の取引先コードを返す |
| `"未登録"` | 見つからなければ「未登録」と表示する |

つまり「A2のメールをD列から探し、同じ行のA列（取引先コード）を表示する。なければ『未登録』」という意味です。

## 補足

- **探す列が右にあっても大丈夫です。** XLOOKUPは探す範囲と返す範囲を別々に指定するので、VLOOKUPのような「左の列しか返せない」という制限がありません。
- **`$`（絶対参照）の理由**：B3以下にコピーしても、マスタの範囲がずれません。
- **うまく見つからないとき**：メールの前後に余分なスペースが入っている可能性があります。その場合は `A2` を `TRIM(A2)` に変えてください。なお、大文字と小文字は区別されません。
