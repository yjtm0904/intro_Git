# B2に入れる数式（Excel・スプレッドシート共通）

Microsoft 365のExcelとGoogleスプレッドシートのどちらも`XLOOKUP`に対応しているため、**同じ数式が使えます**。

取引先マスタが「取引先マスタ」という名前の別シートにある場合は、次のとおりです。

```
=XLOOKUP(A2, 取引先マスタ!$D$2:$D$11, 取引先マスタ!$A$2:$A$11, "未登録")
```

同じシートにある場合は、シート名を外します。

```
=XLOOKUP(A2, $D$2:$D$11, $A$2:$A$11, "未登録")
```

※シート名が違う場合は、「取引先マスタ」の部分を実際のシート名に変えてください。

---

## 数式の読み方

| 部分 | 意味 |
|---|---|
| `A2` | このメールアドレスを探す |
| `$D$2:$D$11` | マスタのD列（メール）の中から探す |
| `$A$2:$A$11` | 見つかった行のA列（取引先コード）を表示する |
| `"未登録"` | 見つからなければ「未登録」と表示する |

つまり「**A2のメールをD列から探して、同じ行のA列を返す。なければ『未登録』**」という意味です。

- `XLOOKUP`は、探す列（D列）が表示したい列（A列）より右にあっても使えます。`VLOOKUP`では、この並びのままでは取り出せません。
- `$`を付けて範囲を固定しているため、B2をB3以下にコピーしても範囲がずれません。

---

## 補足

**メールの前後に余分な空白が入っていると、「未登録」になります。** 受信メールからコピーした値で起こりやすいです。気になる場合は、空白を取り除く`TRIM`を加えた次の数式を使ってください（どちらのソフトでも使えます）。

```
=XLOOKUP(TRIM(A2), 取引先マスタ!$D$2:$D$11, 取引先マスタ!$A$2:$A$11, "未登録")
```

なお、大文字と小文字は区別されないため、`Test-Foods@example.com`でも見つかります。

**古いバージョンのExcelでも使いたい場合**は、次の数式にしてください。

```
=IFERROR(INDEX(取引先マスタ!$A$2:$A$11, MATCH(A2, 取引先マスタ!$D$2:$D$11, 0)), "未登録")
```

この数式は`XLOOKUP`が使えないExcel 2019以前でも動き、スプレッドシートでも使えます。
