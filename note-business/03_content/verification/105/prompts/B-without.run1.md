# メールアドレスから取引先コードを検索する数式

## 前提(例)

**取引先マスタ(シート名:`マスタ`)**

| | A列 | B列 |
|---|---|---|
| 1 | メールアドレス | 取引先コード |
| 2 | tanaka@abc.co.jp | C001 |
| 3 | suzuki@xyz.com | C002 |

**検索したいシート**:A2にメールアドレスがあり、B2に取引先コードを表示します。

## ① メールアドレスで完全一致検索する

### XLOOKUP(Excel 2021 / Microsoft 365)
```excel
=XLOOKUP(A2, マスタ!$A:$A, マスタ!$B:$B, "該当なし")
```

### INDEX + MATCH(古いバージョンでも使えます)
```excel
=IFERROR(INDEX(マスタ!$B:$B, MATCH(A2, マスタ!$A:$A, 0)), "該当なし")
```

### VLOOKUP
```excel
=IFERROR(VLOOKUP(A2, マスタ!$A:$B, 2, FALSE), "該当なし")
```

## ② ドメイン(@以降)で取引先を判定する

同じ会社の担当者が複数いる場合は、マスタにドメインだけを登録しておくと管理しやすくなります。

**マスタ例**:A列に `abc.co.jp`、B列に `C001`

```excel
=XLOOKUP(MID(A2, FIND("@", A2) + 1, 100), マスタ!$A:$A, マスタ!$B:$B, "該当なし")
```

- `FIND("@", A2)` で「@」の位置を求めます。
- `MID(..., 100)` で「@」より後ろのドメイン部分を取り出します。

Microsoft 365 では `TEXTAFTER` を使うと、より簡単に書けます。
```excel
=XLOOKUP(TEXTAFTER(A2, "@"), マスタ!$A:$A, マスタ!$B:$B, "該当なし")
```

## 一致しないときの対処

前後のスペースや大文字・小文字の違いがあると一致しないことがあります。その場合は検索値を整えてから検索してください。
```excel
=XLOOKUP(LOWER(TRIM(A2)), マスタ!$A:$A, マスタ!$B:$B, "該当なし")
```
※ XLOOKUP・VLOOKUP・MATCHは、もともと大文字と小文字を区別しません。主な原因はスペースや全角文字の混入です。
