# VLOOKUPが #N/A になる原因と直し方

他の行では社名が出ているので、数式の範囲や列番号は正しいと考えられます。C4のセルの中身が、見た目は「C-003」でもマスタの「C-003」と別の文字列になっている可能性が高いです。CSVから貼り付けたデータでは、よくあることです。

## まず全体を切り分ける

空いているセルに次の2つを入れてください。

| 確認用の数式 | 正常なら | 異常なら |
|---|---|---|
| `=C4=取引先マスタ!A4` | TRUE | FALSE（目に見えない違いがある） |
| `=LEN(C4)` | 5 | 6以上（余分な文字がある） |

※ マスタのC-003が4行目（A2から数えて2社目）にない場合は、`A4` を実際の行に変えてください。

---

## 考えられる原因（可能性の高い順）

### 1. 前後に空白が付いている（通常の空白、またはノーブレークスペース）

CSVでは「C-003 」のように末尾に空白が残ったり、Webシステムの出力でノーブレークスペース（CHAR(160)）が混じったりします。ノーブレークスペースは `TRIM` では消えません。

**確かめ方**
- `=LEN(C4)` が6以上になる
- `=UNICODE(RIGHT(C4,1))` の結果を見る。32なら通常の空白、160ならノーブレークスペース、12288なら全角空白です。
- 先頭の文字は `=UNICODE(LEFT(C4,1))` で確認します。67（C）以外なら先頭に何か付いています。

### 2. ハイフンや英字が別の文字になっている（全角・マイナス記号など）

見た目が同じでも、次のように別の文字の場合があります。
- 全角ハイフン「－」（65293）
- マイナス記号「−」（8722）
- 全角英字「Ｃ」

**確かめ方**
- `=UNICODE(MID(C4,2,1))` が **45** なら正しい半角ハイフンです。それ以外なら別の文字です。
- `=UNICODE(LEFT(C4,1))` が 67 でなければ、「C」が全角などになっています。

### 3. 改行や見えない制御文字が混じっている（またはマスタ側のC-003に問題がある）

CSV由来の改行（CHAR(10)・CHAR(13)）やゼロ幅スペース（8203）が入っていることがあります。マスタのC-003の行だけに空白が入っている可能性もあります。

**確かめ方**
- `=LEN(C4)` が6以上なのに、1・2の確認で原因が見つからない場合は、`=UNICODE(MID(C4,n,1))` のnを1〜LENまで変えて、余分な文字の位置を探します。
- マスタ側は `=LEN(取引先マスタ!A4)` が5かどうかを確認します。

---

## 直した数式

### 原因1（空白）の場合
```
=VLOOKUP(TRIM(SUBSTITUTE(C4,CHAR(160),"")),取引先マスタ!$A$2:$D$11,2,FALSE)
```

### 原因2（全角・別のハイフン）の場合
`ASC` で全角を半角にし、マイナス記号は個別に置き換えます。
```
=VLOOKUP(SUBSTITUTE(ASC(C4),UNICHAR(8722),"-"),取引先マスタ!$A$2:$D$11,2,FALSE)
```

### 原因3を含め、まとめて対処する場合（Microsoft 365向け）
取引先コードには空白が入らない前提で、空白はすべて取り除いています。
```
=LET(
  k, CLEAN(ASC(C4)),
  k2, SUBSTITUTE(SUBSTITUTE(SUBSTITUTE(SUBSTITUTE(k,UNICHAR(160),""),UNICHAR(8203),"")," ",""),UNICHAR(8722),"-"),
  XLOOKUP(k2, 取引先マスタ!$A$2:$A$11, 取引先マスタ!$B$2:$B$11, "コード未登録")
)
```
マスタ側に問題があった場合は、数式ではなくマスタのセルを直接修正してください。

## 補足

- **データ自体を直す方が確実です。** 数式で吸収すると、他のシートや集計で同じ問題が再発します。C列を上の式でクリーニングし、「値として貼り付け」で上書きする方法がおすすめです。CSVを毎回取り込む場合は、Power Queryで「トリミング」「クリーン」を設定しておくと手間がかかりません。
- `IFERROR(...,"")` で #N/A を隠すと、今回のような不一致に気づけなくなります。そのため上の例では、XLOOKUPの見つからない場合の値に「コード未登録」と表示させています。

確認用の数式の結果（LENやUNICODEの値）を教えていただければ、原因を一つに絞り込めます。
