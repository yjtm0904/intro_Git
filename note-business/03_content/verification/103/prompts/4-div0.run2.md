# #DIV/0! の原因と直し方（前月比の数式）

## 結論

D5 と D6 のエラーは、**割る数（前月の金額）が 0 か空欄**であることが原因です。Google スプレッドシートでは、空欄は計算の中で 0 として扱われます。そのため、どちらの行も「0 で割る」計算になり、#DIV/0! が出ます。

## 考えられる原因（可能性の高い順）

### 1. B5 が 0（D5 の原因）

C-004 は今月から取引が始まったため、前月が 0 です。0 では割れないのでエラーになります。

**確かめ方**
- B5 をクリックし、数式バーに `0` と表示されるか見ます。
- 空いているセルに `=B5=0` と入れて、TRUE になれば 0 です。

### 2. B6 が空欄（D6 の原因）

空欄は計算上 0 とみなされるため、原因 1 と同じエラーになります。

**確かめ方**
- 空いているセルに `=ISBLANK(B6)` と入れて、TRUE になれば本当の空欄です。
- FALSE になる場合は、スペースや `=""` を返す数式などが入っています。この場合は原因 3 の確認もしてください。

### 3. 見た目は数値でも、中身が数値ではない（または参照がずれている）

次のような状態だと、思った値で計算されていない可能性があります。
- B 列が別のシートや数式から値を持ってきている。
- 表示形式で値が隠れている。
- 数式をコピーしたときに参照先がずれている。

**確かめ方**
- D5 をクリックし、数式が `=C5/B5` のように**同じ行**を指しているか確認します。
- `=ISNUMBER(B5)` が TRUE になるか確認します。
- `=LEN(B6)` が 0 になるか確認します。0 以外なら、見えない文字が入っています。

## 直した数式

D5 に次の数式を入れ、下の行へコピーしてください。

```
=IF(OR(B5="", B5=0), "", C5/B5)
```

- 前月が空欄または 0 のときは、空欄を表示します。
- それ以外のときは、これまでどおり前月比を計算します。
- 表示形式は今までどおり「%」のままで大丈夫です。

### 補足：IFERROR を使う方法もありますが、おすすめしません

```
=IFERROR(C5/B5, "")
```

この数式は短く書けます。ただし、参照ミスや文字の混入といった**ほかのエラーまで空欄に隠してしまう**ので、上の IF 版をおすすめします。

### 補足：列全体を 1 つの数式で済ませたい場合

D5 に次の数式を 1 つだけ入れると、下の行まで自動で計算されます。

```
=ARRAYFORMULA(IF(C5:C="", "", IF((B5:B="")+(B5:B=0), "", C5:C/B5:B)))
```

- 今月の金額（C 列）が空の行は、空欄になります。
- この数式を使う場合は、D6 以降に入っている数式を消してください。残っていると結果を書き込めず、エラーになります。
