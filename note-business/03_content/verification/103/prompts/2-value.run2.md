# J7が #VALUE! になる原因と直し方

## 考えられる原因（可能性の高い順）

### 1. G7に「個」という文字が入っていて、文字列になっている（最有力）
Excelは「5個」を数値ではなく文字列として扱います。文字列に掛け算をすると #VALUE! になります。ほかの行が「1」「2」のような数字だけで正しく計算できているなら、まずこれが原因です。

**確かめ方**
- 空いているセルに `=ISNUMBER(G7)` と入力します。**FALSE** なら文字列です。
- G7を選び、数式バーに「5個」と表示されていれば、文字ごと入力されています。

### 2. 「個」を消しても、数字が文字列のまま残っている
次のような場合は、見た目が「5」でも計算できません。
- 全角の「５」になっている
- 前後や途中にスペースがある
- 先頭に「'」が付いている
- セルの書式が「文字列」になっている

**確かめ方**
- `=LEN(G7)` を入力し、「5」なら **1** になるはずです。2以上なら余分な文字かスペースがあります。
- `=ISNUMBER(G7)` が FALSE のままか確認します。
- セルの左上に緑の三角（エラーインジケーター）が出ていないか見ます。

### 3. H7（単価）も文字列になっている
「864円」「¥864（全角）」のように入力されていたり、ほかのシステムから貼り付けて文字列になっていたりする場合です。

**確かめ方**
- `=ISNUMBER(H7)` が FALSE かどうか確認します。

---

## 直し方

### おすすめ：データ自体を数値に直す
1. G7には **5** だけを入力します。
2. 「個」を表示したい場合は、G列を選んで `Ctrl+1` →「表示形式」→「ユーザー定義」を開き、種類に `0"個"` と入力します。

こうすると見た目は「5個」のまま、中身は数値の5になります。J7は元の数式 `=G7*H7` のままで **4320** と表示されます。

### データを直せない場合：数式側で吸収する
**「個」だけ取り除いて計算する**
```
=SUBSTITUTE(G7,"個","")*H7
```

**全角数字・スペース・単価側の文字列もまとめて吸収する（原因1〜3に対応）**
```
=IFERROR(VALUE(SUBSTITUTE(ASC(TRIM(G7)),"個",""))*VALUE(SUBSTITUTE(ASC(TRIM(H7)),"円","")),"")
```
- `ASC`：全角を半角に変換します
- `TRIM`：前後の余分なスペースを取り除きます
- `SUBSTITUTE`：「個」「円」を取り除きます
- `VALUE`：文字列を数値に変換します
- `IFERROR`：それでも変換できない場合は空欄にします

この数式を J7 に入力し、下の行へコピーすれば、数字だけの行（1、2など）もそのまま正しく計算されます。

---

**補足**：「本」「箱」など、ほかの単位も混ざっている可能性があるなら、数式で一つずつ取り除くより、おすすめの方法（数量列は数値だけにして、単位は表示形式で付ける）に統一するほうが確実です。
