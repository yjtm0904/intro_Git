# 原因と直し方

## 原因（可能性の高い順）

### 1. Excel 2019 に XLOOKUP 関数がない（ほぼこれが原因）
XLOOKUP は Microsoft 365 と Excel 2021 以降で使える関数で、**Excel 2019 には入っていません**。知らない関数名があると、Excel は `#NAME?` を表示します。同僚の Microsoft 365 では動き、あなたの Excel 2019 では動かない、という状況とも一致します。

**確かめ方**
- D2 を選んで数式バーを見ます。`=_xlfn.XLOOKUP(...)` のように **`_xlfn.`** が付いていれば確定です。これは「この版の Excel では使えない新しい関数」という印です。
- 空いているセルに `=XLO` と入力してみます。候補に XLOOKUP が出てこなければ、その Excel では使えません。

### 2. 数式を打ち直したときに全角文字が混ざった
自分で数式を入力し直した場合、`"未登録"` のダブルクォーテーションが全角の `”` や `“` になっていたり、関数名の一部が全角になっていたりすると、`#NAME?` になることがあります。

**確かめ方**
- 数式バーで `"` の形を確認します。`"` ではなく `“ ”` のように見えたら、半角で打ち直してください。
- 関数名やカッコ、カンマを半角で入力し直して、表示が変わるか確認します。

### 3. 参照しているシート名が実際と違う
シート名が `取引先マスタ ` のように末尾に空白を含んでいたり、別の表記になっていたりすると、参照が正しく解決されず、エラーや意図しない参照になることがあります。

**確かめ方**
- シート見出しをダブルクリックして名前を確認し、数式中の `取引先マスタ!` と完全に一致しているか見ます。
- 数式を編集して `取引先マスタ!` の部分を消し、マウスでマスタの範囲を選択し直すと、正しいシート名が自動で入ります。

※ 原因1が当てはまる場合、2と3は確認しなくても大丈夫です。

---

## 直した数式（Excel 2019 でも 365 でも動きます）

**おすすめ：INDEX + MATCH**
```
=IFNA(INDEX(取引先マスタ!$B$2:$B$11,MATCH(C2,取引先マスタ!$A$2:$A$11,0)),"未登録")
```

**別案：VLOOKUP**
```
=IFNA(VLOOKUP(C2,取引先マスタ!$A$2:$B$11,2,FALSE),"未登録")
```

### 数式のポイント
- **完全一致の指定を忘れないでください。** XLOOKUP は初期設定が完全一致ですが、MATCH は最後の引数に `0`、VLOOKUP は最後の引数に `FALSE` を指定しないと、近い値が誤って返ることがあります。
- **IFNA を使っています。** XLOOKUP の「見つからなかったら"未登録"」と同じ働きをします。IFERROR でも動きますが、IFERROR は参照ミスなど他のエラーまで「未登録」に変えてしまい、原因に気づきにくくなります。
- D2 に入力したら、下の行へコピーしてください。範囲は `$` で固定されているので、そのままコピーして大丈夫です。

C2 が `C-001` なら「株式会社サンプル商事」が表示されるはずです。

---

## 補足
- **直したあとに「未登録」と出る場合**は、関数ではなくデータの問題です。コードの前後に空白がある、全角と半角が混ざっている（`C-001` と `Ｃ－００１`）、といった違いがないか確認してください。
- **同僚とファイルをやり取りし続ける場合**は、同僚にも INDEX + MATCH か VLOOKUP を使ってもらうと、同じ問題が再発しません。
