# 「#REF!」の原因と直し方

## 考えられる原因（可能性の高い順）

### 1. 参照していたH列を削除したため、参照先がなくなった（ほぼ確実）
`=G2*H2` の H2 を削除すると、Excelは参照先を `#REF!` に置き換えます。**後からH列を挿入し直しても、数式は元に戻りません。**

**確かめ方**
- J2（後述のとおり今はI2の可能性があります）を選び、数式バーに `#REF!` が直接書かれていればこれが原因です。
- Ctrl+Z で削除前に戻せるか試してください。戻せればそれが一番確実です。

### 2. 他のセルや他のシートにも同じ `#REF!` が広がっている
J2を下の行にコピーしていた場合、J3以降も同じ状態です。合計セルや別シートの集計がH列を参照していれば、そこも壊れています。

**確かめ方**
- Ctrl+F →「オプション」→ 検索場所を「ブック」、検索対象を「数式」にして、`#REF!` を「すべて検索」します。
- あわせて列の位置を確認してください。H列を削除するとその右側は1列ずつ左にずれるため、**「金額」は今はI列にある**はずです。見出し行を見て確かめてください。

### 3. （直した後に起きやすい）商品マスタとコードが一致しない
商品マスタから単価を引く形に直した場合、E列のコードに空白や全角・半角の違いがあると、今度は `#N/A` になります。

**確かめ方**
- `=COUNTIF(商品マスタ!$A:$A,E2)` が **0** なら一致していません。
- `=LEN(E2)` が見た目の文字数（P-01なら4）より多ければ、空白が混ざっています。

---

## 直し方

### A. 元に戻せる場合（おすすめ）
- Ctrl+Z で削除を取り消します。
- 保存済みで取り消せない場合、OneDriveやSharePoint上のファイルなら「ファイル」→「情報」→「バージョン履歴」から削除前の版を開き、H列をコピーして戻せます。

### B. 商品マスタから単価を引く場合
金額の列（今のI2、またはJ2）に次の数式を入れ、下までコピーします。

```
=G2*XLOOKUP(E2,商品マスタ!$A:$A,商品マスタ!$C:$C)
```

マスタにないコードを「未登録」と表示したい場合は、次の数式を使います。

```
=LET(単価,XLOOKUP(TRIM(E2),商品マスタ!$A:$A,商品マスタ!$C:$C,""),IF(単価="","未登録",G2*単価))
```

例：E2が P-01、G2が 1、マスタのC列が 33000 なら、結果は **33000** です。

---

## 注意点
方法Bでは、**マスタの単価を変更すると過去の請求明細の金額も変わります**。請求書は発行時点の単価を残すのが普通です。そのため、次のどちらかをおすすめします。

- 方法Aで単価列を復元する
- 方法Bで計算した後、単価をコピーして「値として貼り付け」し、固定する

H列が不要に見えたのは、単価が直接入力されていたからだと思われます。今後は、列を削除する前に該当列を選んで「数式」タブ →「参照先のトレース」を実行すると、使われているかどうかを確認できます。
