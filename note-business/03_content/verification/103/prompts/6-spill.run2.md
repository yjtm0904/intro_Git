# #SPILL! の原因と直し方

## 結論

一番の原因は **F5 の「メモ：要確認」** です。
UNIQUE の結果は10個なので、F2 から **F2:F11** に表示されます。その途中にある F5 に文字が入っているため、結果を表示できずに #SPILL! になっています。

---

## 考えられる原因（可能性の高い順）

### 1. スピル範囲（F2:F11）に F5 のメモがある ← ほぼ確実

**確かめ方**
- F2 を選ぶと、表示されるはずの範囲が点線の枠で示されます。F5 が枠の中に入っているはずです。
- F2 の横に出る「！」マークをクリックすると「**スピル範囲が空白ではありません**」と表示されます。
- 同じメニューの「**妨げているセルを選択**」を押すと、F5 が選ばれます。

**直し方**
- F5 のメモを、別のセル（G5 や F1 など、F2:F11 の外）に移します。数式はそのままで構いません。
- メモを F5 から動かせない場合は、数式を F6 に置き、F6:F15 を空けておきます。

### 2. 空に見えるセルに、見えない値が入っている

半角や全角のスペース、`=""` のような数式、`'`（アポストロフィ）だけのセルなどです。F5 のメモを消しても #SPILL! が残る場合に考えられます。

**確かめ方**
- 上と同じく「妨げているセルを選択」を使い、選ばれたセルの中身を数式バーで確認します。
- `=COUNTA(F3:F11)` を範囲外のセルに入れて、0 以外になれば何か入っています。

**直し方**
- F3:F11 を選んで Delete キーで中身を消します。

### 3. 範囲に結合セルがある、または F2 がテーブル（ListObject）の中にある

**確かめ方**
- 「！」マークの説明が「**スピル範囲に結合セルがあります**」や「**テーブル内のスピル範囲**」になっていないか確認します。
- F2 を選んだとき、リボンに「テーブルデザイン」タブが出ればテーブルの中です。

**直し方**
- 結合セルの場合は、「ホーム」→「セルを結合して中央揃え」→「セル結合の解除」で解除します。
- テーブルの場合は、テーブルの外のセルに数式を置くか、「テーブルデザイン」→「範囲に変換」で通常の範囲に戻します。

---

## 直した数式

メモを F2:F11 の外へ移したうえで、F2 に次のどれかを入れます。

**そのまま使う場合**
```
=UNIQUE(請求明細!C2:C21)
```

**明細に空白行が混ざる可能性がある場合（空白が「0」として出るのを防ぐ）**
```
=UNIQUE(FILTER(請求明細!C2:C21, 請求明細!C2:C21<>""))
```

**コード順に並べたい場合（C-001 から C-010 の順）**
```
=SORT(UNIQUE(FILTER(請求明細!C2:C21, 請求明細!C2:C21<>"")))
```

### 補足
明細の行数が今後増えると、結果も11個以上になることがあります。そのため、F列の下のほうも空けておくと、また #SPILL! になるのを防げます。

明細の範囲を自動で広げたい場合は、`C2:C21` の部分を `C2:C1000` のように広めに取ってください。上の FILTER 版なら、空白行は結果に出ません。
