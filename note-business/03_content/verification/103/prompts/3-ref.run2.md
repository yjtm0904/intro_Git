# 原因と直し方

**H列「単価」を削除したため、参照先がなくなり `#REF!` になっています。** Excelは削除された列への参照を自動で直さないため、数式の中に `#REF!` が残ります。

## 考えられる原因（可能性の高い順）

### 1. 数式が参照していたH列を削除した（ほぼ確実）
- **確かめ方**
  - J2（列削除後は**I2**に移動している可能性があります）を選び、数式バーに `=G2*#REF!` と出ていれば、これが原因です。
  - 削除した直後なら `Ctrl + Z` で元に戻せます。H列が戻り、数式も `=G2*H2` に戻ります。保存して閉じた後は戻せません。

### 2. ほかの数式や設定もH列を参照していた
金額の列以外に、合計・税額・条件付き書式・名前の定義などが壊れている場合があります。
- **確かめ方**
  - `Ctrl + F` で「検索する文字列」に `#REF!` を入力し、[オプション] →「検索対象：**数式**」、「検索場所：**ブック**」にして [すべて検索] を押します。
  - [数式] タブ → [名前の管理] で、参照範囲に `#REF!` を含む名前がないか確認します。
  - [ホーム] → [条件付き書式] → [ルールの管理] で、適用先や数式に `#REF!` がないか確認します。

### 3. 商品マスタから引くように直したあと、コードが一致しない（直した後に起きやすい）
修正後に `#N/A` や想定外の値が出る場合は、商品コードの表記がずれています。前後の空白、全角と半角の違い（`P-01` と `Ｐ－０１`）、ハイフンの種類の違いなどが原因になります。
- **確かめ方**
  - 空いているセルに `=E2=商品マスタ!A2`（対応する行を指定）を入力し、`FALSE` なら表記が違います。
  - `=LEN(E2)` と `=LEN(商品マスタ!A2)` で文字数を比べると、余分な空白を見つけられます。

## 直した数式

H列を使わず、商品コード（E列）で商品マスタから単価を引く方法です（Microsoft 365では XLOOKUP が使えます）。

```excel
=G2*XLOOKUP(E2,商品マスタ!$A:$A,商品マスタ!$C:$C,"")
```

- 商品コードが見つからない場合は空欄を返すため、金額は `#VALUE!` になって気付けます。エラーではなく「未登録」と表示したい場合は、次のようにします。

```excel
=IFERROR(G2*XLOOKUP(E2,商品マスタ!$A:$A,商品マスタ!$C:$C),"未登録")
```

- 空白などの表記ゆれ（原因3）がある場合は、次のように前後の空白を除いて検索します。

```excel
=G2*XLOOKUP(TRIM(E2),商品マスタ!$A:$A,商品マスタ!$C:$C,"")
```

入力したら、セル右下のフィルハンドルをダブルクリックして下の行にコピーしてください。例の数量1、コードP-01、単価33000なら **33000** と表示されます。

### 補足
- シート名に空白が入っている場合は、`'商品 マスタ'!$A:$A` のようにシート名を `'` で囲みます。
- 明細に単価を表示しておきたい場合は、H列を挿入し直して `=XLOOKUP(E2,商品マスタ!$A:$A,商品マスタ!$C:$C,"")` を入れ、金額を `=G2*H2` に戻す方法もあります。後で確認するときに分かりやすくなります。
