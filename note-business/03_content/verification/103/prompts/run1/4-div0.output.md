## 結論

**前月の金額（B列）が 0 または空欄で、0 で割っているため**です。スプレッドシートでは空欄も割り算では 0 として扱われるので、D5 と D6 の両方が `#DIV/0!` になります。

## 考えられる原因（可能性の高い順）

### 1. 前月の金額が 0 になっている（D5）
C-004 は今月から取引が始まったため B5 が 0 です。33980 ÷ 0 は計算できません。

**確かめ方**
- B5 をクリックし、数式バーに `0` と表示されるか確認します。
- 空いているセルに `=B5=0` と入力し、`TRUE` になれば該当します。

### 2. 前月の金額が空欄で、0 として扱われている（D6）
空欄のセルは割り算では 0 とみなされるため、10920 ÷ 空欄 も 0 除算になります。

**確かめ方**
- 空いているセルに `=ISBLANK(B6)` と入力し、`TRUE` になれば本当の空欄です。
- `FALSE` の場合は、別の数式が `""` を返しているなど、見た目だけ空欄の可能性があります。数式バーで中身を確認してください。

### 3. 数式の参照先がずれている
行の挿入やコピーで、数式が意図しないセル（空のセル）を見ている可能性があります。

**確かめ方**
- D5 をダブルクリックし、色付きの枠が B5 と C5 を囲んでいるか確認します。
- 正しく表示されている行（98.0% の行）の数式と見比べて、行番号が揃っているか確認します。

## 直した数式

**D5（下の行へコピーして使えます）**
```
=IF(N(B5)=0, "", C5/B5)
```
- `N(B5)` は空欄を 0 に、数値はそのままの値に変換します。そのため、0 と空欄の両方を空欄表示にできます。
- それ以外の行は、これまでどおり `C5/B5` で計算されます。

**意図が分かりやすい書き方にしたい場合**
```
=IF(OR(B5="", B5=0), "", C5/B5)
```

**列全体を1つの数式で済ませたい場合（D5 にだけ入力）**
```
=ARRAYFORMULA(IF(A5:A="", "", IF(N(B5:B)=0, "", C5:C/B5:B)))
```
- 先に D6 以降に入っている数式を消してから入力してください。消さないと `#REF!` になります。

## 補足
- `=IFERROR(C5/B5, "")` でも空欄にはなります。ただし、文字が混ざったときの `#VALUE!` など、ほかのエラーも隠れてしまいます。原因が 0 除算だけだと分かっている場合でも、上の `IF` を使う書き方をおすすめします。
- 表示形式がパーセントになっていれば、空欄にした行以外はこれまでどおり 98.0% のように表示されます。
