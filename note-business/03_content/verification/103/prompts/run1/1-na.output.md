# VLOOKUPが#N/Aになる原因と直し方

他の行は正しく表示され、C4だけがCSVから貼り付けた値です。そのため、**C4の文字列がマスタの「C-003」と見た目は同じでも、中身が違う**可能性が高いです。数式そのものに誤りはありません。

## まず全体を確かめる方法

空いているセルに次の数式を入れます。C4の文字を1文字ずつ文字コードで表示します。

```
=TEXTJOIN(",",,UNICODE(MID(C4,SEQUENCE(LEN(C4)),1)))
```

- 正常な場合（半角の「C-003」）は `67,45,48,48,51` と表示されます。
- これと違う部分が、下の原因①〜③のどれに当たるかを教えてくれます。

マスタ側と直接比べるには `=C4=取引先マスタ!A4` を使います（C-003はA4にある想定です）。FALSEなら、2つの文字列は一致していません。

---

## 原因（可能性の高い順）

### ① 前後に空白が付いている（通常の空白、またはノーブレークスペース）
CSVの値は「C-003 」のように、末尾に空白が付いていることがよくあります。Webやシステムから出力したデータでは、普通の空白ではなく**ノーブレークスペース（コード160）**が入っていることもあります。

- **確かめ方**：`=LEN(C4)` が **5より大きい**かどうか。文字コードの一覧に `32`（空白）や `160` があれば該当します。

### ② 全角文字や、見た目が似た別のハイフンが使われている
「Ｃ－００３」のような全角文字が混ざっている場合があります。またハイフンが「‐」(8208)、「−」(8722)、「–」(8211)、「－」(65293) など、別の文字になっていることもあります。

- **確かめ方**：文字コードの一覧の2番目が **45以外**になっている。または 67・48・51 の代わりに 65000番台の数字が出る。

### ③ 見えない制御文字が入っている
改行コード（13や10）、ゼロ幅スペース（8203）、CSVの先頭に付くBOM（65279）などです。BOMはCSVの1つ目のセルにだけ付くため、C4がデータの先頭行であれば特に疑われます。

- **確かめ方**：LENが5より大きいのに目に見える空白がなく、文字コードの一覧に `13`、`10`、`8203`、`65279` が含まれている。

---

## 直した数式

C4を整えてから検索する数式です（Microsoft 365向けにXLOOKUPを使っています）。

```
=LET(
  k, ASC(C4),
  k, SUBSTITUTE(k, UNICHAR(160), " "),
  k, SUBSTITUTE(SUBSTITUTE(SUBSTITUTE(k, UNICHAR(8208), "-"), UNICHAR(8722), "-"), UNICHAR(8211), "-"),
  k, SUBSTITUTE(SUBSTITUTE(k, UNICHAR(8203), ""), UNICHAR(65279), ""),
  k, TRIM(CLEAN(k)),
  XLOOKUP(k, 取引先マスタ!$A$2:$A$11, 取引先マスタ!$B$2:$B$11, "未登録")
)
```

各ステップの役割は次の通りです。

| ステップ | 処理内容 | 対応する原因 |
|---|---|---|
| `ASC` | 全角の英数字・ハイフン・空白を半角にする | ② |
| `UNICHAR(160)` の置き換え | ノーブレークスペースを普通の空白にする | ① |
| ハイフン類の置き換え | 似た記号を半角の「-」にそろえる | ② |
| `UNICHAR(8203)`・`UNICHAR(65279)` の削除 | ゼロ幅スペースとBOMを取り除く | ③ |
| `TRIM(CLEAN())` | 前後の空白と改行などの制御文字を取り除く | ①③ |

LETの中で同じ名前 `k` に繰り返し代入できない環境では、`k1`、`k2` … のように別々の名前を付けてください。

VLOOKUPのままで済ませたい場合、原因が①だけなら次の数式で足ります。

```
=VLOOKUP(TRIM(SUBSTITUTE(C4,CHAR(160)," ")),取引先マスタ!$A$2:$D$11,2,FALSE)
```

## 根本的な対策

毎回数式で補正するより、**貼り付けたC列そのものをきれいにする**ほうが確実です。例えば、作業列に上の `k` と同じ整形を行う数式を作り、その結果を「値として貼り付け」でC列に戻します。CSVの取り込みを今後も繰り返すなら、Power Queryで「トリム」「クリーン」を行ってから読み込む方法もおすすめです。

なお、C4を整えても一致しない場合は、**マスタ側のA4**にも同じ確認（`LEN` と文字コードの一覧）を行ってみてください。
