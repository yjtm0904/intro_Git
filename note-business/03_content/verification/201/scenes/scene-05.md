# 場面5 誤送信・添付漏れのお詫び（メール）

- 実行日：2026-11-08／モデル：Claude（claude-opus-5-5。ライターAが、入力だけを条件に回答を作成）
- 入力：共通の前置きv2（`../preface-v2.txt`）のあとに、下の依頼文を貼った

## 依頼文（入力例を入れた状態）

```
【場面】資料の添付漏れのお詫びと再送
【相手】〔取引先A〕の〔担当B〕様
【何があったか】11月18日（水）15時ごろに送った「〔案件X〕資料送付のご案内」のメールに、資料を添付し忘れた
【対応】このメールに資料（PDF、1点）を添付する
【形式】件名をつける。本文は200字以内。おおげさにしない
```

## 出力（共通の前置きv2）

```
件名：【再送】〔案件X〕資料送付のご案内（添付漏れのお詫び）

〔取引先A〕
〔担当B〕様

いつもお世話になっております。〔自社〕の〔氏名〕です。

11月18日（水）15時ごろにお送りした「〔案件X〕資料送付のご案内」のメールに、資料を添付しておりませんでした。
大変失礼いたしました。
資料（PDF、1点）を添付いたしますので、ご確認をお願いいたします。

どうぞよろしくお願いいたします。

〔自社〕〔氏名〕
```

## NG例：前置きなしの頼み方

```
添付を忘れたので謝るメールを書いて
```

## NG例：出力

```
件名：【お詫び】添付ファイル漏れについて

〇〇様

いつもお世話になっております。〇〇の〇〇です。

先ほどお送りしたメールにつきまして、添付ファイルが漏れておりました。
大変申し訳ございません。深くお詫び申し上げます。

改めまして、資料を添付してお送りいたします。
今後はこのようなことのないよう、送信前の確認を徹底してまいります。
ご確認のほど、よろしくお願いいたします。
```

## 点検

- 機械（check.py）：曜日の誤り0件／入力にない数字なし／消えた記号なし／増えた記号なし／本文145字（上限200）
- NG例の問題：足された：約束「送信前の確認を徹底してまいります」と、添付漏れにしては重いお詫び「深くお詫び申し上げます」
- NG例の問題：空欄：どのメールの、何の資料かが分からない
- 送る前の確認点：添付したファイルが正しいか、開いて確かめる
- 送る前の確認点：宛先を間違えた誤送信で、個人情報や社外秘が含まれていた場合は、このメールより先に社内の報告手順に従う
