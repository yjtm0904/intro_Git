# 場面10 議事録からToDoと依頼文（議事録・記録）

- 実行日：2026-11-08／モデル：Claude（claude-opus-5-5。ライターAが、入力だけを条件に回答を作成）
- 入力：共通の前置きv2（`../preface-v2.txt`）のあとに、下の依頼文を貼った

## 依頼文（入力例を入れた状態）

```
【場面】議事録のToDoを、担当者ごとの依頼メッセージにする（社内チャット）
【差出人】総務の〔氏名〕
【ToDo】
・〔社員C〕：年末調整の書類の未提出者に催促する（11月20日（金）まで）
・〔社員B〕：年末の大掃除の分担表を作る（12月18日（金）まで）
【形式】担当者ごとに1通ずつ。各100字以内。最初に相手の名前を書く
```

## 出力（共通の前置きv2）

```
〔社員C〕さん
お疲れさまです。総務の〔氏名〕です。
議事録のToDoの件で、年末調整の書類の未提出者への催促をお願いします。期限は11月20日（金）です。よろしくお願いします。

〔社員B〕さん
お疲れさまです。総務の〔氏名〕です。
議事録のToDoの件で、年末の大掃除の分担表の作成をお願いします。期限は12月18日（金）です。よろしくお願いします。
```

## NG例：前置きなしの頼み方

```
議事録のToDoを担当者にお願いする文を書いて。Cさんは年末調整の催促、Bさんは大掃除の分担表
```

## NG例：出力

```
件名：会議のToDoについてのお願い

関係者各位

お疲れさまです。先日の会議で決まったToDoについて、ご対応をお願いいたします。

・Cさん：年末調整の書類の催促
・Bさん：大掃除の分担表の作成

それぞれ、期限までにご対応をお願いします。
進捗があれば、共有いただけると助かります。
```

## 点検

- 機械（check.py）：曜日の誤り0件／入力にない数字なし／消えた記号なし／増えた記号なし／本文80・77字（上限100）
- NG例の問題：担当者ごとに分かれず、全員あての1通になった
- NG例の問題：足された：頼んでいない「進捗があれば共有」。期限は「期限までに」で中身がない
- 送る前の確認点：1通に1人・1件になっているか
- 送る前の確認点：期限が議事録と同じか
