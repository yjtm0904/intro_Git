# 106 検証ログ（生成AIに入力してはいけない情報とマスキング）

- 検証日：2026-11-08
- 担当：ライターA（Claude、モデルID claude-opus-5-5）
- 使ったもの：Python 3.13（置き換えと検索）、Claude（プロンプトの実行。ライターAが依頼文と入力だけを条件に回答を作成）
- データ：すべて架空（社名は「サンプル・テスト・見本・ダミー・例示・架空」を含む名前、メールは example.com、電話番号は市外局番のあとが0で始まる形）

## 1. 置換表の検証（企画書 §5 の1つ目）

架空の文書3種（`docs/`）に置換表を当て、置き換えたあとに「元の語・名字・略称・下の名前・社外秘の語」と「連絡先・金額などの形」が残っていないかを、正規表現で検索した（`mask_check.py`）。

- 文書：請求書の送付メール（`doc1`）、顧客リスト10行（`doc2`）、議事録の抜粋（`doc3`）
- 実行のしかた：`python3 -I -B mask_check.py <置換表> [--patterns] [--edits manual-edits-v2.csv] [--drop-cols 住所,振込名義] [--order long|short]`

### 1回目（v1）：`replace-table-v1.csv`（26語）→ `result-v1.txt`

- 作り方：宛名・署名・参加者欄・表の「会社名」「担当者」の列に書かれた会社名と人名を、書かれている表記のまま入れた（本文だけに出てくる呼び方は拾っていない）
- 結果：置換表の語そのものはすべて置き換わったが、3文書で **77か所** が残った
  - 本文の名字・略称 10（「佐藤でございます」「山田様」「サンプル商事さん」「森部長」など）
  - 振込名義の半角カナ 11
  - 連絡先 35（メールアドレス11、電話番号12、住所11、郵便番号1）
  - 金額 13
  - 口座の情報 3（銀行名・支店名・口座番号）、健康・家族の情報 1（産休）、社外秘・機密 4（予算額と「社外未発表」、仮パスワード、社内URL）

### 2回目（v2）：`replace-table-v2.csv`（33語）＋形の置き換え＋人の修正 → `result-v2.txt`

- 追加したこと：名字だけ・略称・役職つきの呼び方（1字の名字「森」は「森部長」で登録）／作業に要らない列（住所・振込名義）を削除／メール・URLは記号、電話番号・郵便番号・金額・口座番号は数字をXにして形だけ残す／口座・産休・予算・仮パスワードの文は人が消すか言い換える（`manual-edits-v2.csv`）
- 結果：**残り0か所**
- 途中で起きたこと：v2の1度目の実行では、`manual-edits-v2.csv` の書き方の誤り（文中の「3,200」のカンマが区切りとして読まれた）で、予算の文を消す修正が正しく当たらず、「社外未発表」が2か所残った。最後の検索で見つけ、CSVを直して再実行した（`result-v2-run1-edit-failed.txt`、`masked/v2-run1-edit-failed/`）
- 置き換えの順番の確認：同じv2の表を「短い語から」当てると、「〔担当A〕　太郎」「〔社員1〕　花子」のように下の名前が **7か所** 残った（`result-v2-short-first.txt`）。長い語から当てると0か所

## 2. プロンプトの検証（企画書 §5 の2つ目）

### プロンプト1：架空のサンプルデータを作らせる（`prompts/p1-*.md`）

- v1（「実在の会社名や人名は使わない」とだけ書いた）：社名・電話番号・メールのドメインが、実在してもおかしくない形で出た。金額は「円」つきの文字、日付は5種類
- v2（形を指定）：`check_p1_v2.py` で10行×7列の全条件を満たした（`check_p1_v2-result.txt`）

### プロンプト2：個人情報らしきものを先に指摘させる前置き（`prompts/p2-*.md`）

- 入力：v1で置き換えた議事録（検索で15か所の残りがある文書）
- v1（「個人情報が含まれていたら指摘して。そのうえで整えて」）：15か所のうち **8か所** を指摘（人名5・電話番号・産休・仮パスワード）。取引先名・金額・社外秘の予算・社内URLの7か所は指摘せず、指摘した情報も含めて議事録に整えた
- v2（4つの群を列挙、見つかったら作業しない、〔 〕は対象外）：**15か所すべて** を13項目にまとめて指摘し、作業をしなかった
- 限界：1回ずつの実行の結果。毎回同じように指摘するとは言えない。前置きは送信したあとで働くもので、送信そのものは防げない

### 元に戻す手順（`prompts/p3-*.md`、`restore_check.py`）

- AIは入力の〔 〕の記号13個（8種類）をすべて変えずに残した
- 置換表で戻したあとに残ったもの：置換表にない記号4種類（振込先・口座名義・住所・メールアドレス）と、Xで伏せた数字2つ（金額・電話番号）。元の書類を見て人が入れる必要がある
- 名字だけだった箇所（「山田様」「佐藤までお問い合わせ」）が、正式な表記（フルネーム）に戻った。戻したあとに読み直して直す必要がある
