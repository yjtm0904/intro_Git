# note参入ジャンル比較評価（genre-scoring）

- 作成日：2026-11-07
- 作成者：参入ジャンル比較評価担当（AIエージェント）
- 目的：note（note.com）での副業コンテンツ販売について、事業責任者が参入ジャンルを決めるための比較材料
- ステータス：初版（一次データの取得に制約あり。「1. 調査方法とデータの制約」を参照）

---

## 0. エグゼクティブサマリー

### 結論

1. **推奨は「会社員の業務効率化」領域**
   - 次の2ジャンルを、同じ読者に向けた**1つの事業ドメインとして統合運用**する。
     - ジャンル3「Excel/スプレッドシート/GAS/ノーコード自動化」（79.3点）
     - ジャンル2を分割した2A「生成AI×バックオフィス（事務・経理・総務・人事採用）」（78.6点）
   - ジャンル4「AIコーディング入門」（74.3点）は、読者を引き上げる上位商品に使う。
   - 2C「生成AI×小規模事業者・営業」（73.6点）は、第2段階の横展開先とする。

2. **推奨の根拠**
   - note社の分析（2026年1月発表）では、売上の伸び率が最大だったのは「テクノロジー・AI活用」（前年比+268.6%）。
   - 売れている上位20%の記事の平均価格は、実用ノウハウ系が1,842円で、読み物系983円の約1.9倍。
   - 上位ジャンルには次の共通点があり、「AIエージェントが制作の大半を担う」前提に最もよく合う。
     - 体験談・顔出し・資格が要らない
     - 成果物を動作テストで検証できる
     - 規制業法と無縁
   - 重みを4通りに変えても、上位4ジャンルの顔ぶれは変わらない（第5章）。

3. **伸び率が高くても見送るジャンル**
   - SNS運用（+258.7%）と副業・収益化メタ（+179.0%）は需要が大きい。しかし、売れる根拠は販売者自身の実績とSNSでの集客にあり、収益額を前面に出す訴求が常態化している。
   - これは「顔出しなし・フォロワーゼロ・誇大な稼げる系は避ける」という前提と根本的に合わない。
   - 投資は金商法、美容・健康は薬機法・景表法のリスクがあるため除外する。

4. **最大の構造リスクは2つ**
   - **検索流入の弱まり**：Google検索でAI概要が表示されると、クリック率が大きく下がる。AI概要が出る情報収集型キーワードでは、日本の検索1位のCTRが−62.7%になった（Ahrefs調べ）。2026年3月のコアアップデートでは、UGCプラットフォームの露出も下がった（米国データ）。無料のHow-to記事でSEO集客する戦略は、以前より弱い。
   - **AIで作れるものは誰でも作れる**。
   - **対策**
     - AIの回答では代わりにならない「検証済みの完成品」（テンプレ・業務パッケージ）を売る。
     - シリーズ化してnote内で回遊させる。
     - 更新履歴を明示する。

### 最初に検証すべきサブニッチ（推奨）

1. 1人経理・総務の「月次ルーティン」自動化パック（3×2A）
2. Googleフォームでの受付業務の自動化テンプレ（3）
3. 総務・庶務・兼務採用担当のAI文書キット（2A）

### 本資料の制約（必読）

- **note.comの一次データは取れていない**
  - このセッションからnote.comにはDNSが解決できず、到達できなかった（WebFetchを4回試行し、すべて `ENOTFOUND`）。
  - そのため、記事ページからのスキ数・価格分布の一次データは取得できていない。
  - note APIは一切使っていない。
  - 再取得するには、セッションのネットワーク設定でnote.comを許可する必要がある。
- **検索は途中で打ち切り**：WebSearchを49回実施したところで、ターン全体の共有検索上限に達した（その後の2回は実行されていない）。追加検索ができず、一部の事項（noteの販売手数料体系、検索ボリュームの実数など）は未確認のまま。
- **点数の性格**：点数はジャンル間の相対比較。推定を含む項目には確度（高/中/低）を付けた。

## 1. 調査方法とデータの制約

| 項目 | 内容 |
|---|---|
| 主な手段 | WebSearch（standardモード、49回。その後は共有の検索上限に達して実行不可）。`allowed_domains: note.com` を使い、ジャンルごとにnote記事の顔ぶれ（タイトル・クリエイター・有料かどうか・検索結果に出た価格）を確認した。外部の公式情報（決算資料、ヘルプ、財務局など）も確認した |
| note.com | WebFetchを4回試行（序盤1回、方針更新後2回、終盤1回）。すべてDNS解決に失敗した。APIへのアクセスや、ヘッダー偽装などの回避は一切行っていない |
| 未取得のデータ | ジャンル別の有料記事の価格・スキ数の分布、競合記事のスキ数、Google検索ボリュームの実数 |
| 需要（A）の推定方法 | note公式分析の伸び率、検索で見えた有料記事の数と価格、販売者が自己申告した販売実績を組み合わせて推定した。絶対額の比較はできないため、確度は原則「中」以下とした |
| 二次情報の扱い | 検索ツールは結果を要約して返すため、PDFなど本文を直接読めていない出典は「検索要約経由」と明記した |

## 2. note市場の全体像（全ジャンル共通の根拠）

### 2.1 市場規模と成長

- **GMV（流通総額）**
  - FY2024通期：17,064百万円（前年比+24.4%）[S8]
  - FY2025（2025年11月期）の四半期推移は、成長が加速している [S5][S6][S7]。

    | 四半期 | GMV | 前年同期比 |
    |---|---|---|
    | 2Q | 5,205百万円 | +24.7% |
    | 3Q | 5,537百万円 | +27.4% |
    | 4Q | 5,608百万円 | +29.1% |

  - 確度：中〜高。決算説明資料を検索要約で確認したもので、PDF本文は未閲覧。
- **会員登録者数**：1,052万人（FY2025 3Q、前年同期比+23.3%）[S6]
- **最新期の業績**：FY2026 3Qの売上高は40.58億円（前年同期比+33.2%）と報じられている [S9]。金額の規模から、3Qまでの累計と推定。確度：中。
- **示唆**：プラットフォーム全体が年25〜30%で伸びており、新規参入には追い風。

### 2.2 note社の有料コンテンツ分析（2026年1月7日発表）

- **対象**：約30万件の有料記事とメンバーシップ [S1][S2]
- **カテゴリ別の売上成長率**：2025年1〜10月に売買された有料記事のハッシュタグを14カテゴリに分類した結果 [S3][S4]

  | カテゴリ | 売上成長率 |
  |---|---|
  | テクノロジー・AI活用 | +268.6% |
  | SNS・コンテンツ運用 | +258.7% |
  | 複業・在宅ワーク | +179.0% |
  | 育児・子育て | +155.4% |

- **急成長ハッシュタグTOP3**：#Threads、#YouTube収益化、#資産形成 [S1]
- **平均価格**（各分類で売れている上位20%の記事）：実用ノウハウ系は1,842円、読み物系は983円（約1.9倍）[S1]
- **売上の伸び**
  - メンバーシップは前年同月比+81.3%（2025年11月時点）、有料記事は+26.8% [S1][S2]
  - メンバーシップで伸びたカテゴリは、子育て・政治/時事・IT [S1]
- **注意**
  - これらは「伸び率」であり、ジャンル別の売上額や構成比は公表されていない。
  - 規模の小さいカテゴリほど伸び率は大きく出やすい。
  - 確度：数値そのものは高。ただし、規模の比較には使えない。

### 2.3 集客環境（「SNSなし」戦略に直結）

- **AI概要によるクリック率の低下**
  - Ahrefsの調査では、AI概要が表示される情報収集型キーワードで、日本の検索1位のCTRが2025年12月時点の約−38%から、2026年6月には−62.7%まで下がった [S10][S11][S12]。
  - 確度：中。1社のデータと推計による。
- **コアアップデート**
  - 2026年3月のコアアップデート（3月27日〜4月8日）について、米国の2,000超のドメインを分析した結果が出ている [S13][S14]。
    - 露出が下がった：UGCプラットフォーム、アグリゲーター、SNS
    - 露出が伸びた：公式サイト、原典となるサイト
  - 5月にもコアアップデートがあった（5月21日〜6月2日）[S15]。
  - 確度：中。米国のデータで、noteへの影響は推測。
- **note側の姿勢**
  - SEOに関する問い合わせには回答しない方針 [S16]。
  - 2026年8月から、noteの記事がNAVERの生成AI検索で引用元として表示されている [S17]。
- **量産運用のリスク**
  - AIツールやブラウザの自動操作で多数の記事を一括更新したところ、noindex（検索に載らない状態）が付いた、という個人の報告がある。運営に問い合わせたところ、翌日に解除されたという [S18]。確度：低（体験談1件）。
  - ガイドラインはスパム行為を禁止している [S19]。
- **示唆（推測）**
  - SNSを使わない場合、集客は次の3つに頼ることになる。
    - Google検索のロングテール
    - note内の検索と回遊（マガジン・関連記事）
    - 購入者による継続購入（フォロー・メンバーシップ）
  - したがって、AI概要に答えを吸われにくい「完成品」を売り、シリーズ化で回遊させる設計が要になる。

### 2.4 規約・法令（F軸の共通基準）

- **noteのコミュニティガイドライン**：薬機法・景表法・医療法などの広告関連法令に違反する（またはそのおそれがある）投稿を制限している。最上級表示やNo.1表示にも言及がある [S19]。
- **返金ルール**：有料記事は、購入後24時間以内の申請で返金の対象になる（noteの審査あり）。「返金不可」の設定もある [S20]。
- **投資助言**：登録を受けずに投資助言を行うのは法律違反の可能性があり、財務局が警告している。SNS経由の勧誘や、「AI」で有望株を選ぶとうたうサービスへの警告も掲載されている [S21]。
- **特定商取引法・景表法**：有償でノウハウを販売すると、多くの場合、特定商取引法の表示義務が生じる。景表法の誇大広告の禁止も関係する（行政書士の解説）[S22]。noteでの具体的な表記方法は要確認。
- **創作分野**：note系の小説投稿サービスTALESが、生成AI作品を自動判定する仕組みを開発中と報じられた（2025年11月、検索要約経由）[S26]。確度：中。

## 10. 未確認事項と、次に取るべきデータ

1. **noteの一次データ**
   - **前提**：セッションのネットワーク設定でnote.comが許可されること。
   - **取得方法**：通常閲覧（30回以内）で、上位4ジャンルの関連ハッシュタグページと競合記事ページを見る。
     - 対象タグの例：#GAS、#スプレッドシート、#Excel、#経理、#業務効率化、#ClaudeCode、#プロンプト
   - **取得する情報**：有料記事の価格帯、スキ数、記事数の分布
   - **使い道**：A（需要）・C（単価）・D（競争）の確度を「中」から「高」に上げる。
2. **noteの販売手数料体系**：決済手数料とプラットフォーム利用料。商品の種類ごとに違う可能性がある。今回は検索上限のため確認できなかった。価格設計の前に、公式ヘルプで確認する。
3. **検索ボリュームの実数**：上位サブニッチの主要キーワード（例：「GAS 請求書 自動作成」「経理 ChatGPT プロンプト」）を、キーワードツールで確認する。
4. **規約の詳細**：noteの利用規約のうち、AI生成コンテンツと大量投稿に関わる条項の最新版。
5. **個別の法令確認**（該当するサブニッチを選ぶ場合）
   - 採用キット：募集・採用の表現規制、労働条件の明示義務
   - 不動産キット：不動産広告の表示規約
   - 資格対策を扱う場合：過去問の利用条件（試験団体ごと）
